## 入库规则

1. 只放"要上车/要联调"的成品模型；训练中间产物不入库
2. 每新增一个模型在下面登记：文件名 / md5 / 体积 / 来源 / 用途 / 日期
3. 不用同名覆盖：版本变了换名字
4. 单个 < 50 MB
5. hbb 检测器发布必须过泛化门禁：`tools/ml/eval_generalization.py`
   （留出集用 `--images` 指定；基线 `generalization_baseline.json`；紧急绕过
   `--skip-generalization` 须在登记表留标记）
