## 1. 项目概述

智能车**自主竞速 + 云台自瞄打击**系统。小车在格点场地（**A~N 列 × 1~11 行，格边长 0.35 m**）上全自主循迹，途中压"雷"区、过"桥洞"、避"障碍"，并用云台搜索/锁定/击打红蓝靶标，最终抵终点 `N5`。

**三条硬约束（决定路线形状）**：
1. 场地为格点地图，格 0.35 m。
2. **中部挡板**位于第 6/7 行之间、横跨 **D~N 列** → 上下半场**只能从 A/B/C 列缺口过界**。
3. 部分格点有障碍，不可穿越。

**当前运行策略**：`continuous` 模式（边走边扫、全程不停车）；巡航 0.15 m/s；桥洞走廊锁航向直行。

### 2.2 主流程模块职责表

| 包 / 节点 | 语言 | 职责 | 启动 |
|---|---|---|---|
| `car_localization` · **serial_reader** | Python | IMU yaw + 步长死推算 → `/odom/localization`（**格单位**） | localization.launch.py |
| `car_localization` · **path_executor** | Python | 循迹主控：纯追踪 + 桥洞直行 + 越界急停 + 射击停站（≈2614 行） | `python3 path_executor.py`（直跑，无 console_scripts） |
| `dzactuator` · **turn_on_robot** | C++ | 底盘串口：收 `pursuitAngle` → 23 字节帧 → STM32；发 `/odom` `/imu_data` | bringup.launch.py |
| `rknn_pt` · **det_node** | C++/RKNN | 图像推理 → `/offset_center`（靶心偏移+类别+框宽高） | det_node.launch.py |
| `dzrknn_dataprocess` · **turn_on_robot** | C++ | 云台 IDLE/SCAN/TRACK + PD 伺服 + 开火判据 | dzrknn_dataprocess.launch.py |
| `dzjudgment` | C++ | 读裁判串口；`LaserShot_Command` → 6 字节帧 `B5 5B 03 21 01 25` | judgment.launch.py |

### 2.3 核心数据流

```
[相机]/image_raw ─┬─► det_node ─offset_center─► 云台自瞄 ─► /shoot_count,/voice_switch
                  │                                ▲                      │
                  ├─► cam_viewer(网页 8080)    /nav/scan_request   path_executor
                  │                                │                      ▲ │
[编码器/IMU]─► serial_reader─/odom/localization────┴──────────────────────┘ │
                                                                           ▼
                                              /pursuitAngle ─► 底盘 ─► 电机
```
握手：path_executor 用 `/nav/scan_request` 驱动云台；云台回 `/shoot_count`+`/aim_status` 形成走-打闭环。

## 6. 关键说明 / 接手必读

1. **挡板是第一约束**：过界点必须落在 A/B/C 列；改路线必跑 `tools/route_check.py`。
2. **改参数只走 `config/robot.yaml`**，重启节点才生效（节点只在构造时 get 一次）；改完跑 `tools/healthcheck.sh` 验证确实被声明。
3. **`declare_parameter` 必须配 `get_parameter`**（血泪教训：否则"改了不起作用"）。
4. 改 C++ 必 `colcon build && source install/setup.bash`；改 Python 直接生效。
5. **`/odom/localization` 是格单位**（×0.35 得米），原始 yaw 需 +90°。
6. **两个同名 `dzactuator_node`**：底盘在 `dzactuator` 包、云台在 `dzrknn_dataprocess` 包，用"包名+可执行名"区分。
7. **不要用 `pkill`**（实测漏杀导致残留进程事故），用 `./start_all.sh stop`。
8. 网页弹窗占 **8080**；VNC 是 **:1**（非 :0），窗口不可跨屏。
9. ⚠️ **清理后必须重新编译一次**：`cd ~/dzrobot && colcon build && source install/setup.bash`（launch 改动与新包需 build 才生效）。
10. 隔离区 `_quarantine_data/`（navigation2/slam/rplidar/robot_localization/dztrack/fake_amcl/camera_dataset）**误删可恢复**。
11. **保留项**：`models/light_det.v2.3.2.rknn`、`dzrobot/install/`、`dzrobot/src/history/`、`offcenter_table.txt`+`lookup_table`（全 0、预留标定）。
12. 不要删 `.codebuddy/`；共享代码注意脱敏（抓帧/标定/日志/`.bash_history` 可能含场地信息）。
