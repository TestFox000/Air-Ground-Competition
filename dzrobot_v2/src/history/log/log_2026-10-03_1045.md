## 1. 本次更新（Updates）

1. **#75 射击点选择（唯一可代码化的 P1）**
   - 根因：`_rank_shoot_points` 只按"离雷序折线多远"排序，**既没有朝向权重、也没有距离上限**，
     于是把对角点 `H10`(0.495m > 上限 0.45m) 排到了同列点 `G10`(0.35m) 前面。
   - 修：新增 `shoot_alignment_penalty()`（同列 0.0 / 同行 0.8 / 对角 2.4，即 readme 第28条
     权重的代码化）+ 距离硬过滤 `[shoot_distance_min, shoot_distance_max]`；
     阈值经 `load_shoot_limits()` 从 `config/robot.yaml` 读取（**不另写一份真源**）。
   - 结果：射击点 `H10* → G10*`；`route_check` 显示 `G11<-射击点#6(0.35m)`。
2. **C9 单位混淆**：`dzactuator.cpp` 两个回调的 `angular.z` 加单位注释
   （cmd_vel 是 **rad/s**，第78行 `atan()*57.3` 换算；pursuitAngle 是 **度**）。
3. **P2 注释与代码不符**：`path_executor.py` 8 处 20Hz→50Hz（实际 `create_timer(0.02)`）；
   扫描范围注释标注真实值 `-160°~+10°` 并指向 `robot.yaml`。
4. **P2 ros2 run 入口**：`car_localization/setup.py` 注册 `path_executor_node`。
   ★ `start_all.sh` 保持直跑不动（已实车验证）。
