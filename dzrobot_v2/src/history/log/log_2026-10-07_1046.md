## 1. 项目概述

按用户指令重做小车新版本：**旧 `car_localization/path_executor.py`（2622 行单体）弃用**，
以当前工作区为基底新建 **`dzbrain`** 包（Python，单进程多线程）：
**每个任务点一个线程**（循迹 / 云台瞄准+打击 / 误差修正 / 无人机通信 / 安全 / 遥测），
循迹改为**通用可配的纯追踪**（几何/速度/判据全部进配置，可离线仿真验证）。

四个 C++ 硬件层节点（`dzactuator` 底盘 / `det_node` 视觉 / `dzrknn_dataprocess` 云台 / `dzjudgment` 射击）**保留**，
云台节点走"最小补丁"路线（放行门真生效 + 延迟补偿提前量 + 移动靶开火模式），由用户在车上编译。

**铁律**（沿用并有 git 兜底）：本地是唯一真源；车端**只读**探测；改动本地做完 → 用户手动替换/编译。

## 6. 关键说明（本轮坑清单）

| # | 坑 | 说明 |
|---|---|---|
| **K1** | **换纯追踪公式会让过弯略硬** | 旧代码分母是"车→前视点弦长"，新实现用"前视弧长预算 ld"，差一个 cos α：α=10°/ld=0.15/L=0.157 时旧 10.1479° vs 新 10.3012°（+1.5%）。属有意变更，首次实车要保守整定。 |
| **K2** | `self._stop` 遮蔽 `threading.Thread._stop` | 任务里任何 `self._stop` 实例属性都会让 `stop()/join()` 抛 `TypeError`。已改名 `_stop_event`。**这正是"本地可测"抓出来的第一个真 bug**。 |
| **K3** | `arrival_m(0.12) < drift_warn_m(0.30)` 导致漂移永远报不出来 | 若把"漂移告警"绑在"到位吸附"上，能锚定的偏差必然低于告警阈值 → 该事件永远不会发生。已改为独立判据 + 新增 `pursuit.drift_seg_gate_m`。 |
| **K4** | 日志限流的 early-return 把"每拍刹车"也短路了 | 底盘 1 s 看门狗下"只发一次刹车"会被忽略。已改为：限流只包日志，刹车每拍无条件发。 |
| **K5** | Safety 把自己算进"任务停滞"检查 → 永久锁死 | 自己的心跳永远是"上一拍"，首拍为 0 → 判 inf。已改为看门狗不盯自己（自身存活归外层 supervisor）。 |
| **K6** | 冷启动第一拍误刹 + 不自动恢复 = 永久锁死 | 两任务独立起线程，Safety 首拍可能早于 Localization 首次写 `P_ODOM_AGE`。已加 `safety.startup_grace_s` 区分"启动期无数据"与"运行期断流"。 |
| **K7** | `Path.project` 的 `allow_backward=True` 会把投影点夹回 `s_hint` | 当 `window_m` 大于每拍位移时，`s` 会永远停住。正确形状：`allow_backward=False` + `window_m=arrival_m`。 |
| **K8** | `block_to_meters('N10').x = 0.5249999999999999`（1 ULP） | 与十进制字面量 `0.525` 不严格相等，测试必须带容差；几何是禁改底座。 |
| **K9** | `RouteBuilder.build()` 的朝向是"离开段方向" | 构造测试姿态必须按它算，否则桥洞对齐的 `e = ang_diff(段方向, yaw)` 会整体差 180°。 |
| **K10** | 本仓库**没有 pytest** | 测试一律写成纯脚本（`python src\dzbrain\tests\test_x.py`，打印 PASS/FAIL，全过 exit 0），与项目既有 `test_coords.py` 风格一致。 |
