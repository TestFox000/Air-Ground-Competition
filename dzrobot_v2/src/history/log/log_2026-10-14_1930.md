## 六、坑清单（本轮新踩/新确认）

1. **`git status` 的 `M config/map.yaml` 一开始被我当成噪声**——实际是第六张图接入，20 点位变 19 个。**教训：整理档案时不能只信"我记得上次的状态"，必须重新 `git diff`。**
2. **用 PowerShell 正则整块替换 Markdown 表会破坏 UTF-8 编码**（`agent_archive.md` 一度显示乱码）。改用 `read` + `edit` 工具做精准替换后恢复。**教训：改中文 Markdown 一律用文件编辑工具，不用 shell 文本替换。**
3. **两个后台子智能体因模型切换中断**（`failed before it finished`）——本轮改为主智能体自己查，未重复派发。
4. **PowerShell `Get-Content` 在控制台显示中文乱码 ≠ 文件坏**（`$OutputEncoding` 设置问题），先用 `read` 工具核实再下结论。
