## 10. 关键说明 / 坑清单（本轮实测踩到或复核到的）

1. **`config_selfcheck.py` 的"0 warn"与"8 条非 info 问题"并存**：它打印 `[配置校验] 8 条非 info 问题：⚠️ planner.auto_plan_enabled … planner.obstacle_margin_m: 未知配置段`，但结论行仍是 `error 0 / warn 0 ✅ 通过`。**这 8 条是既有现象，不是换图引入的**：这 8 个 `planner.*` 键在 **HEAD 的 `config/robot.yaml` 里就已存在**（t4 用 `git show HEAD:config/robot.yaml` 实测含 `obstacle_margin_m`/`auto_plan_enabled`/`pivot_penalty`），`config_selfcheck.py` 本轮**未被任何卡改动**，且 t3 换图**之前**的那份 selfcheck 落盘输出里同样有这 8 行（t4 按 ASCII 骨架核对：该文件含 `planner.auto_plan_enabled`/`planner.obstacle_margin_m`，且与 `8 … info …` 同一段）。根因 = 该工具的 SCHEMA 未登记 `planner.*` 段。记录为 info，勿当成本轮新增 warn。
2. **编码/落盘是"假结论"制造机（本轮实测两次踩到）**：
   - ① **Windows PowerShell 5.1 的 `Get-Content`/`Select-String` 默认按 ANSI(GBK) 解码 UTF-8 无 BOM 文件**：同一份 `docs/上下文快照.md`，`Get-Content` 报 **54 行**（且末 4 行被"合行"、中文全乱），`[System.IO.File]::ReadAllLines` 与 read 工具报 **73 行**，加 `-Encoding UTF8` 后一致 **73 行**。⇒ **行数、grep 命中、内容都可能假**；读文件一律显式指定编码（或直接按字节读），搜索用 ripgrep 系工具。
