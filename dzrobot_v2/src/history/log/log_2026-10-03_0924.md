## 1. 项目概述（沿用旧日志，仅补当前状态）

智能车自主竞速系统。底盘串口 + 轮速计/IMU 定位，网格地图（A~N 列 × 1~11 行，格 0.35m）循迹，途中压"雷"区、过"桥洞"、避"障碍"，并用**云台自瞄**搜索/锁定/击打红蓝靶标。

**本次整理后，主流程实际使用的包只有 5 个**（其余均为历史遗留，已移出）：

```
dzactuator(底盘) → car_localization(定位/循迹) → rknn_pt(视觉)
                                        → dzrknn_dataprocess(云台自瞄) → dzjudgment(射击)
```

## 5. 待办事项

### 🔴 P0（建议优先，影响实车行为/精度）
1. **C1 底盘标定参数可能静默失效**：`bringup.launch.py` 用字符串 `LaunchConfiguration` 传 `ticksPerMeter/ticksPer2PI`，而 `dzactuator.cpp` `declare_parameter` 是 double（默认 1000/3200）→ 类型不匹配静默回落。**里程计比例可能一直在用错的值**，直接影响循迹精度。建议第一个查这个。
2. **C4 弹药口径冲突**：`SHOOT_COUNT_TARGET=10`（打满 10 发才收站）vs 单靶上限 3 发 → 每个射击点必然耗满 30s 超时才走。
3. **C8 地图三份真源冲突**：`mission_blocks` 路线途经 `H10/D9/G4`，而这 3 格被列为 `obstacle_blocks` → 路线踩障碍。需现场确认并重新生成。
4. **硬件弹药复位**（非代码，需裁判系统侧操作）。

### 🟠 P1

### 🟡 P2
