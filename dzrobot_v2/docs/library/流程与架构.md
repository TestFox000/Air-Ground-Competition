# 流程与架构（团队图书馆）

> 核实日期：2026-10-19｜代码基线：`cfb7767`｜真源：`src/dzbrain/dzbrain/main.py`、`docs/新版架构设计.md`、`docs/工作流v2.md`、`docs/空地指挥链路_协议与运行手册.md`

## 1. 一页数据流

```text
无人机感知/链路                小车 dzbrain（单进程 8 线程）                  底盘/云台
  /dzlink/drone_to_car  ──►  DroneTask ──► 场地布局/桥洞情报
        (BEST_EFFORT)                        │
                                             ▼
  /nav/waypoint (RELIABLE) ──► MissionTask ──► 路线/阶段/停站
                                             │
  route tokens ──► parser ──► Path(弧长) ──► LocalizationTask ──► P_POSE / P_ROUTE_S
                                             │
                                             ▼
                                       TrackerTask(50Hz, 纯追踪) ──► pursuitAngle ──► dzactuator
                                             │
  SafetyTask(20Hz) ◄── 看门狗/越界/故障 ─────┘   （唯一强制停车者）
  AimTask(50Hz) ──► 云台/开火门 ──► dzrknn_dataprocess / dzjudgment
```

一句话：**无人机给情报 → 任务层定阶段 → 定位层算弧长/位姿 → 循迹层出舵角 → 底盘执行；安全层随时可一票停车。**

## 2. 决策层 8 线程（`main.py:1348-1356`）

| 线程 | 频率 | 职责 | 源码 |
|---|---:|---|---|
| LocalizationTask | 20 Hz | 定位投影、到位吸附、漂移/边界护栏、航向完整性守卫 | `tasks/localization.py` |
| SafetyTask | 20 Hz | 唯一强制停车者：看门狗、故障闩锁 `SAFE_STOP` | `tasks/safety.py` |
| TrackerTask | 50 Hz | 循迹（纯追踪）→ `pursuitAngle` | `tasks/tracker.py` |
| MissionTask | 10 Hz | 阶段机、路线装载、停站三段式（SETTLE→ACQUIRE→FIRE）、桥洞择格 | `tasks/mission.py` |
| AimTask | 50 Hz | 云台扫描/跟踪与射击门 `/nav/scan_request`、`/aim/fire_gate` | `tasks/aim.py` |
| FixTask | 10 Hz | 系统性误差修正、尺度估计 | `tasks/fix.py` |
| DroneTask | 5 Hz | `/dzlink` 情报收发与 ack、场地布局 | `tasks/drone.py` |
| TelemetryTask | 2 Hz | 遥测/状态快照（面板、赛后复盘） | `tasks/telemetry.py` |

> 另有 4 个 ROS executor 线程；8 个任务线程共享同一黑板（Blackboard），跨线程只通过黑板键通信。

## 3. 黑板键（跨线程契约）

| 键 | 写入者 | 消费者 | 说明 |
|---|---|---|---|
| `P_POSE` | Localization | Tracker/Mission/Safety/Aim | 当前位姿（block/yaw） |
| `P_ODOM` / `P_ODOM_AGE` | 定位/IO | Safety/Localization | 里程计与新鲜度；启动契约检查 |
| `P_ROUTE_S` | Localization | Tracker/Mission | 路线弧长进度 |
| `P_MISSION_PHASE` | Mission | Tracker/Safety/遥测 | IDLE/DRIVE/PIVOT/FINISH/SAFE_STOP 等 |
| `P_CAR_STATE` | Mission/主循环 | DroneTask/Safety | 段级状态；D1b 起含 `done`/`done_seq` |
| `P_MOTION_LIMIT` | Localization/安全 | Tracker | 航向/安全限速；T-HEAD 后可恢复 |
| `P_DRONE` | DroneTask | Mission/Telemetry | 无人机情报、ack、布局 |

> 键名真源在 `main.py` 顶部常量；新增键必须同时登记写入者/消费者，否则跨线程会出现“永远读不到/永远不更新”。

## 4. 启动与发车门禁

1. 车端 `bash ~/dzrobot/start_all.sh`：**7 步**启动（底盘→相机→定位→视觉→云台→射击→循迹）。
2. dzbrain 起栈后有 **10 s 准备窗口**（`mission.auto_start_delay_s=10`）：就绪日志、定位/安全初始化、出发前路线校验。
3. 启动契约（T-AE，commit `752ee1a`）：
   - 位姿必须新鲜；无有效位姿不进入 DRIVE；
   - 布局必须新鲜；过期布局默认 `WAIT_INFO`；
   - D-022 例外：布局过期但**完整**（`known≥154` 或 `coverage.complete`）允许规划，只说明一次；partial 仍等。
4. 发车开关：
   - dzbrain：`mission.auto_start: false`（robot.yaml:701）——默认不自动走；
   - legacy：`path_executor.auto_start: true`（robot.yaml:334）——只有 `LEGACY_PATH=1` 才走，**危险**；
   - 部署/联调一律 `--force-no-autostart`，并把轮子架空。
5. 段完成回报（D1b，commit `238f6ce`）：`done`/`done_seq` 闩锁，WAIT_INFO 期间 1 Hz 重发；同格 0 token 停站也记有效段。

## 5. 部署与测试流程（本地唯一真源）

```powershell
# 1) 本地：目标测试 + 门禁
python src\dzbrain\tests\test_<target>.py
python tools\wf\check.py

# 2) 上车：探车 → 备份 → 推送 → 车端编译（默认不碰 auto_start）
python tools\deploy_to_car.py probe
python tools\deploy_to_car.py all --force-no-autostart

# 3) 车端：起栈/停栈/看日志
bash ~/dzrobot/start_all.sh restart
tail -f ~/robot_logs/7_path.log
```

- **不推 `config/map.yaml`**：地图真源在车端；布局由无人机 `field_layout` 下发。
- 推送后必须做 sha256 清单比对；不一致即中止编译（防“假部署”）。
- 全量回归只在里程碑跑一次，且先备份 `_tmp_full_regression/`（台账 D-023 引用的基线不能覆盖）。

## 6. 空地链路契约

| 项 | 值 | 出处 |
|---|---|---|
| 无人机→车 | `/dzlink/drone_to_car`，`std_msgs/String`，**BEST_EFFORT** depth 10 | 空地链路:15 |
| 车→无人机 | `/dzlink/car_to_drone`，**BEST_EFFORT** depth 10 | 空地链路:16 |
| 路线命令 | `/nav/waypoint`，**RELIABLE** depth 10 | 空地链路:17 |
| 域号 | 118（两端） | 空地链路:18 |
| 心跳超时/情报过期 | 3.0 s / 30.0 s | 空地链路:19-20 |
| 桥洞情报重发 | 2.0 s | 空地链路:22 附近；`dzlink_supervisor.py` |

> BEST_EFFORT + VOLATILE 首包会丢（实测 39/40），机侧必须周期重发；车侧等情报窗口 `bridge_info_wait_s=2.0`，桥前 HOLD 每洞上限 `min(12.0, 预算余量)`。

## 7. 团队工作流（一账三闸）

```text
决策台账（防重开）
  ├─ 复用闸：新建前先检索（目录索引 → 复用清单 → grep）
  ├─ 冻结闸：config/**、src/dzbrain/** 只能走 卡→in_flight→回归→部署
  └─ 收口闸：可复跑命令 + 证据 + 回滚点，缺一不关闭
```

- 任务卡：三行（写域/验收命令/回滚点）；一个写域一个 owner；Lead 收口。
- 代码按里程碑提交；每卡只跑目标测试 + smoke；全量回归只在里程碑跑。
- 文档：本图书馆 + 决策台账 + 37 套回归台账；`check.py` 管断链/冻结区/复用门禁。
