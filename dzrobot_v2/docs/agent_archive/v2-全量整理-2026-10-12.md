## 3. dzrobot_v2 · 核心算法与架构

### 3.1 8 线程决策层（`docs/新版架构设计.md` §3.1）

```
dzbrain 进程（Python 单进程多线程，主线程 rclpy MultiThreadedExecutor）
├─ T1 LocalizationTask  20 Hz  定位与锚定
├─ T2 TrackerTask       50 Hz  循迹 → pursuitAngle（唯一底盘驱动写入者）
├─ T3 MissionTask       10 Hz  任务调度 / 航点推进 / 停站事件 / 超时兜底
├─ T4 AimTask           50 Hz  云台瞄准+打击
├─ T5 FixTask           10 Hz  误差修正（scale 估计）
├─ T6 DroneTask          5 Hz  无人机通信
├─ T7 SafetyTask        20 Hz  安全看门狗（唯一有权强制停车者）
└─ T8 TelemetryTask      2 Hz  遥测
```
线程间**只**经 Blackboard（高频）+ EventBus（低频），禁止直接互调。`tick()` 必须非阻塞。

### 3.2 规划器两套引擎（`route/planner.py` 3262 行）

| 引擎 | 入口 | 搜索 | 代价 |
|---|---|---|---|
| `tour`（历史默认） | `plan_route()` L2073 | 每点一次**朝向感知 Dijkstra 洪泛**（状态 `(row,col,head[,prev_head])`，616~2464）+ 最近邻 + 2-opt + 朝向坐标下降，交替 ≤3 轮 | `COST_FORWARD 1.0 / BACKWARD 2.2 / TURN 1.4` + 势场 0.9/0.4/0.15 |
| `tracker-safe`（现役） | `plan_route_tracker_safe()` L3116 | 单格正交 + 禁 180° / 禁紧凑 U / 雷直线穿心 + **Held-Karp 位压 DP**（`_ts_phase` L2982，多候选共享 `_ts_search_multi` L3032） | `0.35/格 + TS_TURN_W 0.10/90° + 雷拐罚 1.5/90°` |

- **位压 DP 只在 tracker-safe**，tour 不用。
- 软惩罚默认全关（缺键→0.0，保「与历史逐 token 一致」）：折返 5.0 / 雷拐 2.0 / 隔板转 8.0 / 过门 6.0 / 外雷转 6.0 / 障碍转 6.0。
- 无倒车（`allow_reverse=false`）⇒ 不产 `R:` ⇒ `mark_pivots` 打 `:PIVOT`（阈值 `PIVOT_MARK_DEG=135°`）⇒ `assert_legal_no_reverse` 四条不变量。
- U 形是**结构约束**：`_u_shape_order` L2022 把 `cross_lower` 钉为下半场第一跳，3 个顺序候选依次编译+自检，全败才抛 `PlannerError`（绝不静默降级）。
- 压雷真判据 = 车心 r3.5cm 圆 ↔ **0.12×0.12 方形垫片**（`physics.mine_pressed` L199，贴边时车心离雷心可到 0.095 m），且需雷前 **≥2 格共线**（`straighten_mines` L2619）。
- 复杂度：tour = O(n) 次洪泛 + O(n²) 建表；tracker-safe ARM 实车 **settled 200811 / 2788 ms** ⇒ `TS_MAX_SECONDS=10.0`。
- **tour 引擎不跑双门禁**（`mission.py` L725/L728-731），只有 tracker-safe 跑 `route_check` + `validate`。

### 3.5 云台三状态机与开火链（`dzrknn_dataprocess.cpp` 1332 行）

**状态机** `AimState{IDLE=0, SCAN=1, TRACK=2}`（`.h:134`），主实现 `CaremaMontorControl`(:695-810)：

| 状态 | 行为 |
|---|---|
| **IDLE** | 每帧主动归位到「扫描行程中点 + 基准俯仰」（旧版直接 return 导致冻结在任意姿态，改俯仰参数看不出变化） |
| **SCAN** | 先进归位段（`scan_home_timeout_ms`=1500ms 兜底）→ 连续匀速往复；到位判据 `scan_arrive_tol`=30 刻度或 `max(3×dwell, 1.5×整程)` 超时；一轮=左+右 2 趟，连续 **3 轮**上限后回 IDLE |
| **TRACK** | 视觉伺服：EMA(α=0.55) → 死区(4px) → 增量式 P + 单帧预判(`predict_gain`=0.5 帧) → PD 速度(kp8/kd3，精调档 kp×0.5/kd×2) → 钳位 |

**迁移条件**：任意→IDLE 收 `scan_request=0`；IDLE/SCAN→SCAN 收 `≥1`（`≥2` 连续，已在 SCAN 时只改模式不重置进度）；TRACK 期间忽略 scan_request；TRACK→SCAN/IDLE 丢帧 ≥`lost_frames_to_rescan`(部署 180≈6s) 或视觉静默 >`vision_timeout_ms`(1s)。

**开火链 7 个 AND 条件**（`cpp:180-280`）：① 目标确认 ≥8 帧；② 在动态开火框内（`fireDeadzonePx` 随框宽 30→6px 插值，零点取激光落点 `laser_offset_x/y`）；③ 瞄准稳定（`fire_use_image_stable` ? \|vx\|,\|vy\|≤1.5px/帧 : 电机 realV<20）；④ 弹药允许（全程 10 发硬上限 + 单目标 10 发）；⑤ 类别允许（仅蓝靶）；⑥ 冷却 500ms；⑦ 连续保持 5 帧。任一不满足即清零保持计数。

**发射动作**：先 publish `LaserShot_Command=1` 再立刻 `=0`（`cpp:253-257`）；`/shoot_count` 只在开火与重置时发；无目标时该话题被 ~30Hz 持续发 0。

**手动接管**：`nav/manual_gimbal`=1 ⇒ 主循环**不再 publish `CameMo_Conl`**（只停位置下发，开火/`aim/status`/`shoot_count` 照常）；发布方 `tools/rc_control.py` 同时自己发 `CameMo_Conl`。⚠ SCAN 状态仍推进扫描索引，释放接管后从推进后的索引继续，不是原地续接。

**底盘→下位机映射**（`dzactuator.cpp`）：速度 `|clamp(v×23/0.33, ±255)|`；舵角 `+60` 后夹 `[25,95]`，×10 大端 16 位下发；`cmd_vel` 的 `angular.z` 是 **rad/s**（`atan(CARL·w/v)×57.3` 换算），`pursuitAngle` 的 `angular.z` 是 **度**——同名不同单位（C9 坑）。

### 8.5 ★ 最大缺陷：定位链路整体是死的

`global_localization.py` / `global_map_publisher.py` / `transform_fusion.py` 三个定位节点 **import 即崩**（`ImportError: cannot import name 'transformations' from 'tf2_ros'` / 缺 `open3d`）⇒ `/localization` 话题**从不存在** ⇒ 按原手册默认 `mode=localization` 启动的 `px4_odom_convert` **永远不发外部视觉且不报错**。因 RViz 点云照常显示而长期未暴露。

### 11.3 铁律（踩过的坑，照做）

- **本地唯一真源**；车端只读；改动经「测试→仿真→部署脚本」三道门禁；最终上车由人类执行；C++ 编译确认属人类。
- **改地图只改 `config/map.yaml`**，但必须同步 `robot.yaml` 的 `path_executor.obstacle_blocks`（**当前已不同步，见 §5 #1**）与 `route.cross_*_candidates`。
- **改规划器后硬门槛 5 条**：重出路线 + 落盘 `route.tokens` + 四处逐 token 恒等 + `--check` 六层 0 error + 全回归 + sim 复跑。
- **规划类调用必须显式传 `max_seconds=`**，不得吃 `DEFAULT_MAX_SECONDS` 默认值。
- **全量回归红项先查 `docs/回归守护_known_reds.md`**，台账外红必须定位，不得放行；不许改 XFAIL/PASS 洗绿。
- **门禁/复核报告必须记录被复核文件 SHA256**（本工作区存在并发写入者史）。
- **车端 7_path.log 是 UTF-16LE**（grep 用 `-a` 或 iconv）；SSH 远程命令别带双引号；PowerShell 5.1 给 ssh.exe 传参会吃掉双引号。
- **`ros2 run` 跑的是 `install/…/site-packages/` 副本不是 `src/`**（纯 Python 包 colcon build 即逐字节拷贝），只改 `src/` 行为零变化。
- 上电车前先 `git status --short`（并发写入者警告）。
- **`pursuitAngle.angular.z` 单位是度**（ROS 惯例是弧度）；`pursuitAngle` 与 `nav/manual_gimbal` **无前导斜杠**——勿"顺手规范化"。
- `/odom/localization` 发布的位置是**格**不是米。
