## 6. 三档对照结论

1. **速度对时长**：0.15→0.35 一次省 37.6 s；0.35→0.40 再省 3.0 s，边际递减。
2. **速度对精度**：横向 RMS/MAX 仅在 0.15→0.35 抬升（+0.0051/+0.0083 m，拐角段独占总误差），
   0.35→0.40 无变化（0.0489→0.0490 / 0.1183→0.1182）——提速的精度代价一次性付清。
3. **安全性**：三档越界 0、物理碰撞（障/挡板/靶/K 列）全 0 —— 速度旋钮在 0.15~0.40 区间
   **不改变**任何安全指标，只改变时长与横偏。
4. **盖雷与速度无关**：7/8 三档相同，A4 残留是路线几何问题，不能靠调速度解决。
5. **180 s 预算视角**（接 t11）：0.15 档裸驱动已占 142.14 s，加桥前等待/驻留后长路线场必超；
   0.35 档裸驱动 104.54 s ⇒ 留给等待+驻留+射击的裕量 75.5 s（比 0.15 多 37.6 s）。
