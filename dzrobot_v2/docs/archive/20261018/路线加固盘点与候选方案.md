## 3. 机理：为什么 0.15 会压线、0.30 不会（决定 A 族候选的核心）

轴距 0.157 m、最大舵角 30° ⇒ **最小转弯半径 R = 0.157 / tan30° = 0.272 m**，**与格宽 0.35 m 同量级**。行 7 里做 90° 左转时，圆弧最大北缘：

```
北缘峰值 = (x_起转 − R·sin h0) + R + 车身半宽(≈0.085)
```

起转点越靠南（x 越小）、起转角 h0 越大，北缘越小。前视越大 ⇒ 控制器**越早起转** ⇒ 北缘越小。

逐拍证据（现路线 @0.15，`analyze.py` 打印的 t=7.0~11.4 s）：

```
t=7.00  x=1.478 yaw= 9.6° 舵角执行 30.0°（已饱和）
t=9.60  x=1.706 yaw=91.8° 舵角执行 30.0°  ← 北缘 1.706+0.085=1.791 > 1.75（侵入 4.1 cm）
t=10.16 x=1.691 yaw=109.4°                ← 最差：净距 −6.8 cm
t=11.34 x=1.618 yaw=111.6°                ← 离开行 7 时仍有 0.1 cm 余量
```

* 舵角**全程饱和在 30°**（执行侧 120 °/s 斜坡也跟着），说明不是"控制增益不够"，而是**物理上转不过来**。
* 0.30 之所以"0 拍"：同样饱和，但 `ld = 1.2×0.30 = 0.36 m` **是 0.15 时的两倍**，车提前 0.25 m 起转 ⇒ 北缘峰值降到 ~1.74（净距 +0.93 cm）。
* ⇒ **"0.30 的 0 拍"与"0.15 的 352 拍"根本不是路线差异，是前视差异。** 把 0.15 的前视抬到 0.36，两边就等价（§4 A 族已实测）。
