## ⚠️ 三个必须先知道的坑

1. **`own_gimbal: false`** —— 云台与激光当前**不是**由 dzmission 驱动的，
   而是假定由 `dzrknn_dataprocess` 驱动。若要移交，改配置并**不要**启动那个节点。
   → 详见交接文档 §9.2

2. **定位健康依赖"检测到位移"** —— 车完全静止时 `pose_valid_` 永远 false，
   会一直 ESTOP。离线测试时假传感器必须制造微小位移。
   → 详见交接文档 §4.2.3

3. **隔离线行号待现场实测** —— 这一个参数可能决定整张比赛图是否连通。
   → 详见交接文档 §10.3
