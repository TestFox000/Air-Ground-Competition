## 复用要点
- 判定「有没有新消息」只看标题行是否含「待回复」，且发送方不是本机。
- 本机代号争议仍未由用户最终确认（信箱内 A/B 归属历史混乱），遇到「待回复」时按 prompt 署名 [A] 并要求不争辩、
  把双方说法都留在回复里。
- 工作区长期脏会导致 `--pull-only` 永远不合并（返回 0 但提示不合并），需注意先看 `HEAD..origin/main` 是否为空。
