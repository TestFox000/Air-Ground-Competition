## D1 · `listen` 退出崩溃（UnboundLocalError: udp_src）

**根因**：`udp_src = None` 原来写在 `try:` **之后**（旧行 1758），而 `listen` 分支在 `try` 内
`return`（旧行 1739）→ `finally`（旧行 1844）引用该名字时仍未绑定。功能完全正常，
只是退出时抛栈、退出码非 0。

**改法**：把 `udp_src = None` 上移到 `try:` 之前（现 **1733 行**，`try:` 在 1734，`if mode == "listen"` 在 1735），
并加注释说明这一类"try 之后赋值、finally 使用"的坑。

**证据（同一台机器，改动前后）**

| | 命令 | 结果 |
|---|---|---|
| 改前 | `dzlink_supervisor.py listen --duration 3` | `UnboundLocalError: local variable 'udp_src' referenced before assignment` + `LISTEN_EXIT=1`（[`s0_pre_fix_listen.txt`](t12-evidence/s0_pre_fix_listen.txt)） |
| 改后 | 同上 + 小车 `/tmp` 探针发 `ack`+`car_state`（复跑 t4 的 s6 场景） | `[listen] 收到 13 条（ack 1 / car_state 12）` + **`LISTEN_EXIT=0`**，无任何栈（[`s3_drone_listen.txt`](t12-evidence/s3_drone_listen.txt)） |

## D2 · `run --bridge/--target/--mines/--obstacles` 静默忽略

**根因**：`build_argparser()` 在 `run` 子命令上定义了这四个参数，但 `main()` 的 `run` 分支
从未调用 `_add_samples_from_args()`（该函数当时只被 `cmd_dry_run` 与 `once` 调用）→
argparse 照收、真跑 `intel_emitted=0`、**零提示**。

**改法**：`run` 分支在 `dry_run` 之后补 `_add_samples_from_args(core, args)`
（必须放 dry-run 之后：`cmd_dry_run` 内部自己注入一次，不能重复）。

**证据（真机，同一命令形态）**

## D4 · 发送器 `target` / `field` 参数陷阱 + 两处文档

**根因**：
1. `target` 只有位置参数 → `target --blocks G10,H10` 被 argparse 拒（错误提示 exit 2）；
2. `field --mines A3,B4` 的 token 不拆逗号 → 生成**畸形格名** `"A3,B4"`（车侧 `_norm_blocks`
   不拆逗号，会当成一个格名进 `field_diff`），**全程不报错**；
3. 上述两种错用法都写在在库文档里。

**改法**（`dzsmartscout/tools/link/dz_send_waypoint.py`）：
* 新增 `BLOCK_SEP = re.compile(r"[\s,;|、]+")` 与 `split_blocks()`：空格/逗号/分号/竖线/顿号
  一律拆开 → 去空 → 大写 → 按序去重；`None` 不再被 `str()` 成字面量 `"None"`（单测抓到的边界）。
* `target` 新增 `--blocks` 别名（`dest="blocks_opt"`），与位置参数合并；两者都支持。
* `field` 的 `--mines/--obstacles` 走 `split_blocks`；给了 flag 却没有格名 → 明确报错。
* `bridge <half>=` 只允许一个格名：`lower=K9,K4` 现在明确报错并给出正确写法（以前静默发畸形值）。
* 输入里出现逗号/分号时往 stderr 打一行"已拆分为 N 个格名"，**不静默改变用户输入**。

**证据**

| 命令 | 改前 | 改后 |
|---|---|---|
| `target --blocks G10,H10 --dry-run` | `error: unrecognized arguments: --blocks`，exit 2 | `{"type":"target_zone","blocks":["G10","H10"]}`，exit 0 |
| `target G10 H10 --dry-run` | 同上（正确） | 同上（不变） |
| `field --mines A3,B4 --obstacles K7 --dry-run` | `{"mines":["A3,B4"],...}` ← **畸形** | `{"mines":["A3","B4"],"obstacles":["K7"]}` |
| `field --mines A3 B4 --dry-run` | 正确 | 正确（不变） |
| `bridge lower=K9,K4 --dry-run` | 静默发 `"K9,K4"` | 明确报错 + 正确写法提示 |

**文档**：`docs/无人机项目总览.md`（原 276–277 行）与 `fc-audit/无人机技术文档.md`（原 636–637 行）
的错误示例已改为正确写法，并把错用法标注为"历史坑"（保留可检索性）。
