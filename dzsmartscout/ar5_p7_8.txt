2.3.2 SSH 远程终端 
 
1. 按照交付信息将 Windows 计算机连接到无人机使用的网络。 
2. 确认无人机已经上电，机载电脑已经完成启动。 
3. 在 Windows 中打开“终端”或“Windows PowerShell”。 
4. 输入交付信息中提供的登录命令。 
ssh 用户名@机载电脑 IP 地址 
5. 首次连接出现确认提示时，核对地址后输入 yes。 
6. 按提示输入密码。输入密码时终端不会显示字符，这是正常现象。 
7. 登录成功后，终端提示符中应显示机载电脑的用户名和主机名。 
无法登录时，先检查无人机供电和网络连接，再参照第 6 章处理。 
2.4 终端使用规则 
本手册使用多个终端分别运行不同功能。建议为各项功能分别使用独立终
端。 
每次打开新终端后，先依次输入： 
source /opt/ros/humble/setup.bash 
source ~/dzpx4/install/setup.bash 
如果终端没有显示错误，即可继续输入本手册指定的启动命令。 
本手册中的“终端 1” “终端2”等表示不同的终端窗口或远程登录标签
页。运行期间建议保持这些终端打开。 
使用 Ctrl+C 可以停止当前终端中的程序。执行地图保存或路径保存时，建
议等待终端显示保存成功后再关闭终端或断电。

3 创建保存和加载地图 
3.1 建图前准备 
建图用于记录固定环境结构，不需要无人机飞行。开始建图前： 
1. 将无人机动力电池断开。 
2. 拆下全部螺旋桨和桨叶螺母，并妥善保管。 
3. 检查四个机臂和激光雷达均已牢固安装。 
4. 确认雷达表面清洁、无遮挡。 
5. 确认飞控处于未解锁状态，遥控器各开关处于安全位置。 
6. 规划步行采集路线，移除沿途障碍物。 
7. 确保采集过程中环境内没有大量移动人员和移动物体。
