## 3. 文档规则（新增/移动必看）

1. **一次性过程**进 `_tmp_session/<卡号>/`；**正式结论**才进 `docs/`。
2. **单一真源**：现状只认 `项目现状_20261018.md`（下一版就新建带日期的现状）；决策只认 `决策台账.md`；复用只认 `复用清单.md`。
3. **历史文档不删不覆盖**：过期后移到 `docs/archive/<YYYYMMDD>/`，在该批 `README.md` 登记「原文件/日期/一句话/取代者」。
4. **移动目录/文件后**：改 `docs/索引标注.yaml` → `python tools/wf/repo_index.py --write` → `python tools/wf/check.py`。
5. 报告必须带：可复跑命令、关键输出、回滚点、影响面（见 AGENTS.md 铁律 4）。
