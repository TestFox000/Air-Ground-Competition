## 三条使用纪律

1. **先通读再存入**（`AGENTS.md` §8.2）：不看内容就往库里塞 = 制造下一轮混乱。
2. **一主题一篇**：口径冲突**并列写**（A 版 / B 版 + 各自出处），不合并成一个假结论。
3. **每条结论带证据**：`路径:行号` 或「文件 + 章节」；不确定写「未核实」。
4. **旧路径取文件规则**：正文里出现的旧路径（如 `dzrobot_v2/docs/xxx.md`），原文在 `docs/_archive/<原路径>`。
