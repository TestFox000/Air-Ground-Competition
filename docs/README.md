## ★ 终结论（2026-10-16 训练线收官，先看这个）

**不需要再训练，minecpv2 就是正确答案，直接部署。**

- 训练线深度核查推翻了训练前提：91.60% 的 val-B 口径被**拍摄者入画**污染
  （模型把悬在场地上的手/影子当 mine，78 个 mine FP 中约 74 个是人源），
  比赛是无人场地航拍，真实能力约 **96~97.5%**（详见 `08-训练线会话交接-20261015.md`）。
- 训练包已主动暂停：图案库已删（防止误练"卡≠mine"摧毁 937 个 TP），
  若将来担心赛场有人入画，换人手照片做 patterns 即可做防御训练。
- **现役部署**：`hbb_detector_7cls_minecpv2_20261015.onnx`（在 `07-无人机模型部署包-20261015.zip`）
  + `conf_per_class=[0.5,0.25,0.05,0.25,0.5,0.3,0.5]` + `edge_mine_thr=0.005`，不要动。
- 赛前最优先事项（不是训练）：用比赛同款场地布置 + 实飞高度拍一组**无人入画的干净验证帧**。
- 遗留：minecpv2 还没进 Git 的 `models/release/` 登记册（现役指针还是 10-11 的 distill）——
  由训练线按 `tools/release_models.py` 泛化门禁流程入库，属待办。

检测模型的类别体系本轮从 11 类改为 **10 类（删除 bridge）**，全部细节见 `01`。
