## 4. 新发现：D1b —— SEGMENT_DONE 窗口只有一个 tick

- 现象：车到站后写 `phase=SEGMENT_DONE`，但**同一拍内**就因为没有新布局转入 `WAIT_INFO`；
- 机侧车状态 1.4 Hz（约 700 ms 一帧），**会整帧漏掉 SEGMENT_DONE**（本轮 H8 后的 56 秒干等就是这么来的）；
- 本轮机侧兜底：`WAIT_INFO` 且 `block == target` ⇒ 视为段完成（已验证有效，E9 就是靠它推进的）。
- 更好的修法（二选一，需改车端）：① 车端 SEGMENT_DONE 保持到收到新布局或 1 s 超时；② 车状态里加 `done_seq`（段完成计数）供机侧幂等消费。

## 5. D2 精确定位：不是"差一格就走错"，是"到达后上报的 block 差半格"

- 车端：段 105 F5→E5 **判定到达**（按目标点距离），写 `SEGMENT_DONE`；
- 机侧收到的 `block=E4`（belief 落格），而 target 是 `E5`；
- 机侧判据 `block == target` 不成立 → `keep target` → 不发布新版 → 车 WAIT_INFO 永久卡住；
- 方向：机侧应按 `segment_id / target_cell` 关联完成事件，而不是用 block 字符串匹配；车端则可考虑上报"到达目标格"而不是"信念格"。
