## 6. 本日新增踩坑记录

1. **Windows `str(Path.parent)` 返回反斜杠** → SFTP 远端目录创建静默失效；posix 路径必须纯字符串 `rfind("/")` 处理
2. **ultralytics 会 resolve 软链** → ds 数据集目录软链组装导致标签查找错位；必须 `cp -al` 硬链接目录树
3. **公网 SFTP 逐文件 ~0.85Mbps**：1200+ 小文件极慢；tar 单流 + 云端旧盘复用把 600MB 上传压到 152MB/166s
4. **ultralytics val 数组是压缩序**（只含有实例的类）：按 `m.names` 全类循环打印 `m.box.p[i]` 会错位+越界崩溃——按表格为准
5. **colcon 增量构建陷阱**（定位线实录）：0 字节产物 mtime 未变被当 up-to-date 直接装走；删 0 字节产物 + touch 源码强制重链
6. PS 5.1 再犯：`&&` 不支持、heredoc 不支持——git commit 用 `-F 消息文件`
7. 无人机 journal 每重启清空：追查历史接入需先开 `Storage=persistent`
8. **bash 的 `~` 只在词首展开**：`--saveEngine=~/x` 不展开，trtexec 往字面 `~` 目录
   保存失败（引擎已建好只差落盘）；`=` 后必须用 `$HOME`（remote_run 的
   `_expand_tilde` 是 SFTP 层同款坑的修复）
9. **`set -o pipefail` + `grep -q` = 概率性误报**：grep -q 匹配后提前退出，上游
   ldconfig 收 SIGPIPE(141)，整条管道被误判失败 → orin_build_verify L0 报
   "未找到 TensorRT"（实际在位）；已修为 `grep … >/dev/null` 读完全量
10. **orin_build_verify L3 names 字典是 fe1d9df 漏改项**：旧 7 类映射会使 13 类
    type≥7 时监听器 KeyError；已修为 13 类全表
