## 一、任务与评分（满分 100，限时 3 分钟）

### 1.1 得分项拆解

| # | 评分项 | 分值 | 判定标准 |
|---|---|---|---|
| 1 | 无人车驶离起点 | 5 | **所有轮子**驶出起点方框 |
| 2 | 无人车回到终点 | 5 | **至少两个轮子**进入终点方框 |
| 3 | 无人机自主起飞 | 5 | 无人机驶离地面 |
| 4 | 无人机终点稳定降落 | 10 | 机体中心**垂直投影**在终点方框内 |
| 5 | 排除地雷（共 8 颗） | 5/颗 → 40 | 小车**任意轮中心**进入地雷圆形标识区域内 |
| 6 | 桥洞协同穿梭（2 处） | 10/处 → 20 | 一区域 5 选 1、二区域 6 选 1，每处只计一次 |
| 7 | 打击**敌方**目标 | +5/计数器+1 → 最多 +15 | 累计 **2 次有效命中** → 计数器 +1；计到 3 = 击毁 |
| 8 | 误击**友方**目标 | −5/计数器+1 → 最多 −15 | 同上 |

**满分 = 100 分。** 计时结束条件：无人机与无人车**均**满足终点判定；否则到 180s 自动结束，用时计 180s。

### 1.2 敌我判定（⚠️ 极易搞反）

> 规则原文：**红色面 = 友方人员目标（禁止打击）**，**蓝色面 = 敌方人员目标（实施打击）**

- 移动电子靶标为**双面结构**，朝向随机摆放，正反两侧**各有一个独立计数器**
- 每侧累计 2 次有效命中 → 该侧计数器 +1，靶标向**受击面的反方向**倾倒，灯光熄灭 1s，之后自动直立并继续移动
- 任一侧计数器达到 3 → 该靶标被击毁，整体失效，**另一侧不再接受判定**，后续命中不计分也不扣分
- **激光子弹只有 10 发**；击毁一个目标需 6 次有效命中 → 理论余量 4 发

> 🔍 这意味着"先确认颜色再开火"的价值极高：误击友方的扣分（−5/次）与得分对称，且一旦把某一侧打到 3 就锁死整个靶标。

### 1.3 赛制与流程

- 初赛（院校自组织推荐）→ 复赛 → 总决赛；复赛与总决赛均为**总分排行榜制**
- **每队两次机会，取较高一次**，两次之间**没有调试时间**；同分则用时少者靠前
- 单场节奏：**候场 → 检录（5 分钟未到视为弃权）→ 准备 2 分钟 → 比赛 3 分钟**
- 准备阶段允许：启动程序、调整参数；**禁止**：更换硬件、更改算力单元
- 准备结束前 20 秒须把**航模遥控交给裁判**；**场地（地雷/靶标/障碍/桥洞）在准备结束后才由裁判布置**
- 比赛阶段全程自动模式，禁止人工干预（R16 违规 → 取消本局成绩）

### 1.4 碰撞与判罚要点

- **不设碰撞责任判定**；但小车与固定场地碰撞持续 >10 秒 → 裁判切换该车至手动模式（云台仍自动）直到结束
- R2：候场区**不得自行架设 Wi-Fi 放大器/手机热点/对讲机** → 最高取消比赛资格
- R7：机器人进入候场区后**不得开电调试或维修** → 取消本局成绩
- R11：禁止闪光灯/强光干扰图像识别；R12：禁止穿红、蓝色系衣物入场
- R6：广播检录后 5 分钟内未到场 → 取消本局成绩

## 四、无人机：SmartScout-AR250 / AR5

### 4.1 首次使用（AR250 快速指南要点）

1. 开箱核对 → **未装桨**状态下三校准（**陀螺仪 / 加速度计 / 水平**）→ **断电装桨** → 首飞
2. 桨叶对应（俯视，机头朝前）：**M1 右前 = CCW，M2 左后 = CCW，M3 左前 = CW，M4 右后 = CW**
3. 数传地面端插 Windows USB，COM 口识别不到装 **CP2102 驱动**；绿灯常亮 = 已连接，每秒闪 1 次 = 未连接
4. QGC 5.0.8 自动连接（需开启 SiK Radio 自动连接）；飞行模式选 **Position（定点模式）**
5. 遥控器开关：**SwA = 解锁/未解锁**，**SwB = 紧急停机**，**SwF = 高级飞行功能**
6. 电池 6S 4000 mAh 80C XT60；HOTA D6 Pro 充电器：LiPo / 4.20 V / 6S(22.2 V) / 3.0 A

### 4.2 自主飞行（AR5 高级功能）—— 三种状态

| 状态 | 螺旋桨 | 控制方式 | 用途 |
|---|---|---|---|
| 建图 | **建议拆下** | 飞控未解锁，手持行走 | 采集环境三维点云，保存 PCD |
| 路径录制 | 已装 | Position 手动飞行 | 录制可重复执行的航线 |
| 自主任务 | 已装 | 遥控切 Offboard + 键盘 | 自动起飞→跟随路径→终点悬停→自动降落 |

> ⚠️ **系统不做动态避障**：手册明确"飞行过程中不会自动识别、绕开突然出现的人员、车辆、桌椅或其他障碍物"。比赛场地 4×5 m、桥洞下方净空有限，航线规划必须留足余量。

**关键文件**

  设 `map_file_path`（PCD 绝对路径）+ `pcd_save_en: true`

  - 录制：`record_mode: true`、`output_file: "recorded_path.txt"`、`overwrite_existing: true`
  - 执行：`record_mode: false`、`follow_mode: "waypoint"`、`path_file: "recorded_path.txt"`

**键盘按键**

| 键 | 功能 | 条件 |
|---|---|---|
| `1` | 解锁并自动起飞 | 已进 Offboard 且在地面 |
| `2` | 请求上锁 | 确认已落地 |
| `3` | 自动降落 | 终点保持时 |
| `4` | 开始执行固定路径 | 已进入 HOVER 且位置有效 |
| `5` | 停止路径跟随并保持位置 | 需主动停止时 |
| `W/S/A/D` `Q/E` `L/R` | 调整悬停水平位置 / 高度 / 航向 | 仅 HOVER 且未启用路径跟随 |

**标准流程**：遥控器切 Offboard → 按 `1` 起飞 → 等 HOVER → 按 `4` 跑路径（终端 7 从 LOADED 进 PURSUING）→ 终点 HOLD → 确认下方清空 → 按 `3` 自动降落。

**人工接管**：遥控切回 **Position** → 确认 QGC 显示已切换 → 轻微动杆取得控制权 → 修正并降落。
**结束顺序**：终端 7 → 6 → 5 → 4 → 3 → 2 → 1 依次 Ctrl+C → 关 QGC → `sudo shutdown -h now` → 拔动力电池。

### 5.3 车载裁判系统

- 启动：`roslaunch dzactuator judgment.launch`（OrangePi 通过 **USB 串口**与车尾裁判板通信）
- 上位机可获取：靶子血量、可抢占/已抢占物资队列、己方与对方血量、**靶子是否正在被激光照射**（`0x01~0x04` = 前后左右四个靶子方向，`0x10` = 未被照射）、已射击次数、剩余弹数
- 上位机**只能下发射击指令**
- 按键：1 重置 / 2 切换靶子灯光颜色 / 3 **长按 2 s 切 STA↔AP** / 4 射击
- 网络：上电默认 **STA**，首次用按键 2 切 **AP**；热点 `DZACS` / `dzsmartcar`，配置页 `192.168.4.1`
  - STA 默认：WIFI `TP-LINK_0538` / `duzhong1102`，本机 `192.168.1.115`，服务器 `192.168.1.100:1102`
  - **STA 模式必须连上 TCP 服务端才能与 OrangePi 串口通讯**（服务端程序暂未开放）
  - **测试阶段建议直接用 AP 模式**（可不连服务端通讯）
- 检录项目：激光发射头在 **1 m 处光斑直径 ≤ 0.6 cm**，否则禁止上场

🔍 **`best_new.rknn` 输出 `[1,9,8400]` 的解码布局**（anchor-free，8400 = 80²+40²+20²）：

```
[0:4]   bbox  cx, cy, w, h      （相对 640 输入尺度）
[4:6]   2 个类别分数            blue=0, red=1
[6:9]   1 个关键点 x, y, conf   ← 对应 auto_center.py 生成的 kx, ky
```

这与 `auto_center.py` 输出的 8 列标签 `cls x y w h kx ky 2` 完全对得上。

### 6.3 ⚠️ 与官方模型不兼容

官方 `light_det.rknn` 输出为 **3 个尺度 `1×18×{80,40,20}²`**，18 = 3 anchors × (5+1)，是 **YOLOv5 anchor-based、单类别**布局。

你们的是 **YOLOv8 anchor-free + 2 类别 + 关键点**。**后处理代码不能复用**，必须自己写 anchor-free 解码（无 anchor 乘算，直接对 8400 个 grid 取 argmax）。
