# hybrid 仿真台同源压测（64 图，seed=20261018）

日期：2026-10-18  
性质：**scratch 压测，不是 P2 合入**；未改 planner.py / plan_route.py / mission.py / config/，未改默认引擎。  
口径：仿真台 stressbench.generateMap 的 64 张图（index 0..63，seed=20261018），每张图跑
tools/plan_route.py --emit json --check --quiet --engine tour；hybrid 走 shadow CLI
（运行时安装 P1 _Tour.polish），地图与校验器与 /sim/stress mode=plan 同源。
4 个 worker 并发，总耗时 33.8 s。

## 1. 总表

| 口径 | planned | plan-failed | 成功率 | 端到端 ms/图 | token 均值 | token 范围 |
|---|---:|---:|---:|---:|---:|---:|
| tour | 28 | 36 | 43.75% | 1068.2 | 51.8 | 38~63 |
| hybrid（P1 冠军-挑战者） | 27 | 37 | 42.19% | 1085.7 | 52.1 | 38~71 |
| hybrid + tour 回退（P2 目标形态） | 28 | 36 | 43.75% | 1089.2 | 52.1 | 38~71 |

- 两者 planned 的路线 route_check **全部 exit 0 / 0 error**（28 + 27 条）。
- 端到端 ms 含 CLI 启动与 route_check 子进程；hybrid/tour ≈ 1.02×，远低于 2× 回退线。

## 2. 逐图差异

| 项 | 数量 |
|---|---:|
| 两边都 planned | 27 |
| 路线完全相同 / 仅顺序不同但指标相同 | 26 |
| hybrid 指标更优（按 PIVOT 数、再按长度） | 1 |
| hybrid 指标更差 | 0 |
| tour planned 而 hybrid plan-failed | 1 |
| hybrid planned 而 tour plan-failed | 0 |

**唯一“更优”图 index55**：PIVOT 5→3，但长度 23.45→26.25 m（+2.80 m）、token 63→71。
即“少 2 个 PIVOT、多 2.8 m / 8 token”，**不是免费改善**；P2 若按 (PIVOT, 长度) 字典序选，
会选这条更长路线——这个取舍需要单独裁决。

**唯一回归图 index60**：tour planned（50 token / 19.95 m / 2 PIVOT），hybrid
“上半场应恰好穿洞 1 次，实际 2 次” ⇒ plan-failed。这正是 P1 map6 同类问题的随机图版本：
DP 强制 start→cross_lower→下半场→上半场→cross_upper→end 拓扑，洪泛腿可能在非预期桥洞
再穿一次；route_cost 代理看不到结构自检。hybrid+tour 回退可恢复这条。

## 3. 失败主因（两边几乎同构）

| 主因 | tour | hybrid |
|---|---:|---:|
| 上半场穿洞 1 次、实际 2 次 | 11 | 12 |
| 没有可用射击停站点（绕路代价无穷） | 4 | 4 |
| 下半场穿洞 1 次、实际 2 次 | 3 | 3 |
| 上半场穿洞 1 次、实际 3 次 | 3 | 3 |
| 下半场穿洞 1 次、实际 3 次 | 2 | 2 |

结论：随机图的失败**主要不是顺序层**，而是 U 形拓扑/桥洞穿越与射击停站的结构约束；
DP 换顺序不能解决，反而在 1 张图上多穿一次。P1 在 5 张固定图上的 map7 收益，在随机图上
没有复现。

## 4. 结论与建议

1. **本次压测不支持把 hybrid 设为默认或立即开 P2**：成功率 -1、无净质量改善、
   唯一差异图是“少 PIVOT 但更长”的取舍。D-016（P2 暂缓）继续有效。
2. 若将来开 P2，必须带 **tour 回退 + 编译双候选**；否则随机图上会出现 P1 同款回归
   （index60）。回退后成功率与 tour 相同（28/64），但没有提升。
3. 随机图的主矛盾是结构约束（穿洞 2/3 次、无射击停站），下一步若要提高压测成功率，
   应先修这些（桥洞/停站/拓扑自检），而不是继续调 DP 顺序权重。
4. 压测口径与仿真台 /sim/stress mode=plan 一致（同 generator、同 plan_route --check），
   但**不是**在页面里选择 engine=hybrid——simulator CLI 目前只认 tour/tracker-safe。
   本压测没有写 config/、没有写 artifacts/sim/stress/，产物只在 scratch。
