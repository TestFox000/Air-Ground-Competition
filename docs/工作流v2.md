## 2. 一账三闸

    决策台账（防重开）
        │
        ├─ 复用闸：新建前先检索，找不到才允许造
        ├─ 冻结闸：默认值/判据只能走 卡→回归→部署
        └─ 收口闸：可复跑命令 + 证据 + 回滚点，缺一不关闭

## 3. 复用闸

**触发**：你要新建脚本、模块、工具，或重写已有实现。

**动作**（按序，缺一不可）：
0. 先查 `docs/目录索引.md`（路径/归属/冻结状态）；新增或移动目录后必须补 `docs/索引标注.yaml` 并重跑 `python tools/wf/repo_index.py --write`；
1. 在 `docs/复用清单.md` 检索能力关键词；
2. 在仓库里 grep 该能力的关键词（`glob`/`grep`，不要凭记忆）；
3. 判定：

| 情况 | 怎么做 |
|---|---|
| 已有且够用 | 直接用，卡片里写「复用 X」 |
| 已有但缺一小块 | **扩展它**（加参数/加子命令），不要复制 |
| 已有但确实不适用 | 卡片里写「为什么现有不够」+ 新实现放哪 + 旧的是否废弃 |
| 完全没有 | 新建，并在复用清单登记一行 |

**红灯**：同一个能力在仓库里出现两份实现，且都没标废弃 → 该卡不能关闭。

## 4. 冻结闸

**冻结区**（改动直接影响实车行为）：

    src/dzbrain/dzbrain/**
    src/dzrknn_dataprocess/**
    config/**
    tools/deploy_to_car.py

**允许的改法**：
- 正式改动：挂卡 → 写 `in_flight` 登记 → 跑回归（33 套）→ 部署 → 解除登记；
- 实验改动：**不许进冻结区**。放 `_tmp_session/<卡>/`，或用 feature flag / 配置开关，默认值不动。

**登记格式**（`tools/wf/frozen.json`）：

    {"path": "config/robot.yaml", "card": "aim-tune-1018", "owner": "who",
     "reason": "移动靶 PID 整定", "expires": "2026-10-20"}

**过期** = 收口闸红。不允许无限期挂着。

## 5. 收口闸（完成定义）

一张卡算完成，必须同时给出：

| 要素 | 要求 |
|---|---|
| 复跑命令 | 一条能复制粘贴就跑的命令 |
| 关键输出 | 数字/日志/表，不是「已修复」 |
| 回滚点 | commit、备份路径或 `git checkout` 命令 |
| 影响面 | 动了哪些冻结区文件、哪些回归、车端是否要重部署 |
| 门禁 | `python tools/wf/check.py` 退出码 0 |

**假绿禁例**（都实际发生过）：
- 断言被 `skip` 吞掉仍报 PASS；
- 用「仿真通过」代替「实车通过」却不标注；
- 只跑改动相关的 1~2 套测试就说「全绿」；
- 统计口径中途换过（如把失败项排除出平均）。

## 7. 决策台账：翻案三问

   想推翻 D-xxx：
    1. 新证据？（命令 + 输出）旧结论的哪条依据已不成立？
    2. 影响面？（冻结区文件 / 回归套件 / 车端部署）
    3. 不推翻的代价？（量化）
    结论写回台账：旧条改「已推翻」，追加新条，不删旧条。
