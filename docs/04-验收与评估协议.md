新模型（v2 训练产物）交付前必须过这四关。**指标口径要写清楚，历史教训：val 被污染过一次（"combined 90.53%" 不可信）。**

## ① 基础指标（训练机自报）

- 训练目录 `runs/detect/aerial_field_v2/` 下的 `results.csv`、PR 曲线、混淆矩阵截图留存
- 报告 val 的 mAP50 / mAP50-95，**航拍 val 与地面 val（gcap_ 前缀 27 张）分开报**

## ② 实拍批次新旧对比（关键一关）

在 2026-10-14 采集的 272 张实拍图上（`runs/capture_20261014_1918/images/`，真值标签 `labels_final/`）跑新旧两个模型的推理对比：

- **旧模型**：`models/release/aerial_field_detector.pt`（11 类）
- **新模型**：v2 的 `best.pt`（10 类）
- 必报指标：
  1. **格号→雷误检数**（cell_label 真值位置被标成 mine 的框数）——本轮痛点，旧模型在此批次为约 100 处，新模型应大幅压低
  2. **cell_label 召回**（真值 1467 框的召回率）
  3. **arrow 精确率/召回**（样本少，单独看）
- 对比脚本思路：双模型 `predict` 同一目录 → 与 `labels_final` 真值做 IoU≥0.5 匹配 → 分类别统计 TP/FP/FN。半页 Python 即可，不需要现成工具。

## ③ 互斥规则回归

推理结果里同一物体（IoU>0.5）出现两个不同类框的次数应接近 0。若仍多，把"重叠框取高置信度类"写进后处理再测。
