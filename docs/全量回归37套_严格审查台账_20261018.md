## 3. 关键澄清：「原地掉头扫出 0.635 m」的真实性

这一点必须单独说清，因为它决定 A 类是「修」还是「改判据」。

**已证实的事实**：

1. 路线最北点 = A 行格心 y=4.725 m = MAP_Y_MAX（地图硬边界）——**路线端点本身就在边界上**。
2. 180° 折返点 A1 就在该最北行。
3. sim 不建模 PIVOT（sim.py:108-111 自述），所以「打满舵画圆」是仿真器的纯追踪行为。
4. **但车体压靶板（92 拍）与挡板触线（131 拍）与 PIVOT 无关**——它们在 t=40~41.6 s 的 D6 停站段，
   由 FieldSpec 独立算出。靶板 board_min_clearance_m = 0.0 意味着**车体与 D6 靶板零净空**。

**因此裁定**：

- **压靶板 / 挡板触线 = 真缺陷**，必须修（停站格离靶板太近，或跟踪切内）。这直接影响得分。
- **越界 48 拍 = 仿真器边界 + 真缺陷的叠加**：即使有 PIVOT 状态机，A1 选在地图最北行做 180° 掉头，
  物理上仍可能扫出边界。**应作为路线规划的约束单独立项**（与 D-011「修结构约束」同向）。
