## 4. 接手必读（坑清单，精简）

1. 挡板是第一约束：过界点必须 A/B/C 列；改路线必跑 `route_check.py`。
2. 改参数只走 `config/robot.yaml` + 重启节点；`declare` 必须配 `get`。
3. 改 C++ 必 `colcon build`；改 Python 直接生效。
4. `/odom/localization` 是**格单位**；`pursuitAngle.angular.z` 是**度**。
5. 两个同名 `dzactuator_node`（底盘 vs 云台），用"包名+可执行名"区分。
6. 勿用 `pkill`（漏杀），用 `./start_all.sh stop`。
7. 网页 :8080 / VNC :1（非 :0）。
8. 清理后必须重编译：`colcon build && source install/setup.bash`。
9. 隔离区 `_quarantine_data/` 可恢复误删包；勿删 `.codebuddy/`。
10. 非 git 仓库，动手前备份。
11. 场地要素每局随机，赛前必须重填 `map.yaml`。
