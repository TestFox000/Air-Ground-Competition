## 6. 关键说明（坑清单，本次新增/更正）

1. **`route.tokens` 在 YAML 中并不存在**——它是 Config 别名，真源是 `robot.yaml:407 path_executor.mission_blocks`（60 token / 20.65 m / 1 个射击停站 `C10*` / 0 个 `R:` / 0 个 `:PIVOT` / 末点 `N5,y`）。`config.py:485-490` 还有一批同类别名（`mission.auto_start/auto_start_delay_s/reset/scan_mode` ← `path_executor.*`、`pursuit.cruise_speed_mps` ← `path_executor.linear_speed`）。
2. **`sim.py`/`sim_cli.py` 不在 `tools/`**，在 `src/dzbrain/dzbrain/tools/`；权威入口 `python -m dzbrain.tools.sim_cli`。若有文档按「tools 31 个文件」计数需更正（实测 24）。
3. **`thread_num=8` 是视觉 0.26 s 陈旧的主因**：`rknnPool` FIFO 前 8 拍不取 ⇒ 结果滞后 ≈8×33 ms；且每帧只发一个目标、无目标 ID。
4. **云台开机 IDLE（非"上电即扫"）**；激活时机 = 循迹在发车命令时发 `/nav/scan_request=2`；连续扫描最多 3 轮后自动回 IDLE 归位。
5. **`/move_base/stop_signal` 仍是死线**：`path_executor.py:786-790` 与 `dzbrain/io/ros_io.py:277` 都发，C++ 三包 grep 0 命中。新钥匙 `/aim/fire_gate`+`/aim/fire_ready` **已被云台订阅**（`dzrknn.cpp:998-1006`）但默认 `use_external_fire_gate=false`。
6. **`scan_yaw_min/max`（±150°）同时是 TRACK 的允许范围**（`clampYawToScan`）——改扫描范围会一并改跟踪摆幅。
7. **`offcenter_table` 查表确为死代码**：`compute_comp_pixel_0`/`loadLookupTable` 全树零调用，但构造函数仍在 `:1279` 调用 `loadLookupTable`（有副作用无消费者）。
8. **三套校验三种口径**：上行 34B 的 BCC 校验整段被注释停用（`dzactuator.cpp:958-962`）、下行 23B 用累加和、裁判帧写死 0x25。
9. **单位双轨**：同名 `angular.z` 在 `cmd_vel` = rad/s、`pursuitAngle` = **度**（`dzactuator.cpp:72-74` 自注 C9）。
10. **`dzsmartscout/` 含明文口令**：SSH 登录 = sudo = VNC 同一口令，硬编码在 17 个脚本 + 1 个插件默认值 + 3 份文档；另有 5 个历史 IP、雷达设备序列号、个人邮箱与个人 Windows 路径。**随项目外发前必须脱敏**。
11. **会话归档提取方法**：`session.v4.jsonl` 的用户消息文本在 `data.content[]` 数组里（`{type:text,text:…}` 或裸字符串），且**大量 user/message 是系统提醒/记忆回放噪声**，需按前缀过滤才能拿到真实指令。
