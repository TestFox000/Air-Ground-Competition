## 一句话

- 中间挡板恒在 **6/7 行之间、横跨 D~N**；只有 **A/B/C** 三列能上下穿行 ⇒ 赛道被迫 **U 形**。

## 五个最容易踩的坑
1. **布局模式启动**：`--map` 必须指向**不存在**的文件；`start_all.sh:220` 传的是 `config/map.yaml` ⇒ 车上有图就永远进不了 StepLoop。
2. **`cam_viewer` 抢 `/pursuitAngle`**：20 Hz 发全零 ⇒ 车“收到但不走”。跑车前必须 kill。
3. **非交互 SSH 域号变 0**：ping/SSH/网页全通，ROS 互相看不见且零报错；起栈/调试必须先 `source dzros.env`。
4. **`robot.yaml` 顶层裸键**：会让相机/视觉/云台三节点同时 abort；地图必须放 `config/map.yaml`。
5. **`dzrknn_dataprocess` 的可执行文件叫 `dzactuator_node`**（与底盘包同名，`CMakeLists.txt:91`）——查进程/时间戳别认错。
