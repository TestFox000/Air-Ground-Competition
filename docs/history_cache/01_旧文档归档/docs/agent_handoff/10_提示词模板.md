# 交接提示词模板（可直接复制）

> 目标：让新 agent 在 **1 次对话内**建立正确心智模型，而不是“读了一堆文档还是不知道干嘛”。
> 配套文件：`00_一页纸.md`（L0）、`20_发送指南.md`（发什么/怎么发）。

---

## 0. 先记住三条

1. **提示词是“任务书”，不是“资料堆”**。只贴文件不说要产出什么，agent 只会回一篇泛泛总结。
2. **事实源要“点名字”**。明确“只认这 5 篇，冲突以代码为准”，否则它会拿过期文档当现行。
3. **输出契约写死**。要求：先复述 → 再动手；每条结论带 `文件:行号` 或可复跑命令；不确定标〔未〕。

一个够用的骨架（五段）：

```
① 身份 + 边界     你是【角色】；只读/可写【范围】；不许碰【冻结区】
② 事实源          只认这 N 篇（给绝对路径/附件名）；冲突时以【代码/实测】为准
③ 当前任务        一句话目标 + 本次范围
④ 验收标准        可复跑命令 + 期望输出
⑤ 输出契约        先复述 5 问 → 等我确认 → 再给计划 → 再动手
```

## A. 快速了解（无附件，30 秒版）

**适用**：对方上下文小、只要“知道这个项目是什么”，不干活。
**发法**：把 `00_一页纸.md` 全文贴在下面【项目卡】处，直接发。

```
你是新加入“空地协同侦排挑战赛”项目的 agent。下面这段是项目卡，先读完再回答；不要凭常识补全，不要展开成报告。

【把 00_一页纸.md 全文粘贴到这里】

请用不超过 400 字回答：
1) 这个项目要解决什么？三条最硬的场地约束是什么？
2) 当前主线是什么？最大的三个风险是什么？
3) 哪三件事你绝对不能做？
最后列出你还不确定、需要我补充的 3 个问题。
```

## B. 接管项目（带 L1 包，主力模板）

**适用**：新 agent 要真正接手（读码、排障、写方案）。
**发法**：上传 L1 包里的 6 个文件（或给同机绝对路径），再发这段。

```
你是 dzrobot_v2 / dzsmartscout 项目的接手 agent。角色：【决策层 / 仿真规划 / 无人机 / 文档治理，四选一】。
工作区：D:\User\Desktop\比赛存档\v1（若用附件包，解压后的根目录就是工作区）。

【事实源】只认下面 6 份，其余文档一律当“可能过期”：
1. 00_先读我.md（一页纸）
2. docs/项目总览_AGENT_20261020.md（全量）
3. AGENTS.md（六铁律/冻结区）
4. dzrobot_v2/docs/项目现状_20261018.md
5. dzrobot_v2/docs/决策台账.md（D-001~D-023）
6. dzrobot_v2/docs/TEAM_STATUS.md
冲突时以代码/实测为准，并在回答里标〔实〕/〔档〕/〔未〕。

【红线】
- 不改冻结区：src/dzbrain/dzbrain/**、src/dzrknn_dataprocess/**、config/**、tools/deploy_to_car.py
- 不重开已裁决事项；要翻案先答“新证据 / 影响面 / 不重开的代价”
- 不说“已修复/已优化”；每条结论给 文件:行号 或 可复跑命令+输出
- 不知道就写〔未〕，不要猜

【第一步：先别动手】
用 300 字复述：
a) 车端 8 线程各干什么（至少 5 个）；
b) 当前 3 个 P0；
c) 三套地图口径差在哪；
d) 无人机为什么不可飞；
e) 你接下来准备先读哪个文件、为什么。
我确认后，你再给计划。
```

> 为什么有效：先逼它“输出理解”，你一眼就能看出它读没读懂；比让它直接干活再返工便宜得多。

## C. 单卡任务（在 B 之后追加）

```
承接上面的上下文。本次任务卡：

- 目标：【一句话，可验收】
- 写域：只许改 【路径/文件】，其余只读
- 验收：运行 `【命令】`，必须输出 【期望结果】
- 回滚点：【commit / 备份文件】
- 交付格式：结论 + 证据（文件:行号 / 命令输出）+ 影响面 + 未决问题

先给我 5 行计划（改哪些文件、怎么验、风险点），我点头你再改代码。
```

## D. 代码审查（只读，不写）

```
你是独立审查者，不写代码、不改文件。基于 L1 包审查【模块名 / 提交号】。

逐条输出：问题 / 证据（文件:行号）/ 影响 / 建议 / 置信度（高/中/低）。
重点查五类：
1. 冻结区越界、手工 scp 绕过部署入口；
2. Config 缺键静默默认（现场改参数不生效）；
3. 线程安全（共享状态、stop/join、闩锁不可恢复）；
4. ROS QoS 不匹配（BEST_EFFORT 发 → RELIABLE 收 = 静默 0 条）；
5. 文档与代码不一致（版本号、地图口径、频率）。

最后给一句结论：可以合并 / 必须打回，并列出打回项。
```

## E. DSH 子智能体（给 Lead / 团队用）

子智能体与父会话**共享文件系统**，所以提示词里给路径即可，不要重复贴文档。

```
spawn_teammate(
  name: "【小写-连字符名】",
  description: "【一句话职责】",
  prompt: """
  你是【角色】，只做【一件事】。
  工作区：D:\User\Desktop\比赛存档\v1
  先读：docs/项目总览_AGENT_20261020.md 的 §【章节】；再读【具体文件】。
  写域：只写 _tmp_session/【卡号】/ 和【目标文件】；其余只读。
  禁止：改冻结区、部署上车、提交 git。
  交付：结论 + 证据（文件:行号）+ 可复跑命令 + 回滚点；落盘到 _tmp_session/【卡号】/report.md。
  """
)
```

要点：**一卡一写域**；卡里写清“读什么、写哪里、怎么验收、回滚点”，否则子智能体会到处乱改。

## F. 小上下文 / 小模型（8k 以内）

```
只读下面这一页，不要展开，不要引用外部知识。回答 3 个问题，每个不超过 50 字。

【粘贴 00_一页纸.md】

1. 起点、终点、场地尺寸、时限？
2. 当前最大的技术风险是什么？
3. 哪几个目录绝对不能改？
```

---

## G. 验收：让对方回答这 5 问

发完资料后，先别派活，先测：

| # | 问题 | 及格线 |
|---|---|---|
| 1 | 起点/终点/场地尺寸/挡板约束？ | N10 / N5 / 4×5 m / 6-7 行挡板，只有 A/B/C 能穿 |
| 2 | 8 线程任选 5 个，频率+职责？ | 至少说对 4 个 |
| 3 | 当前 3 个 P0？回归基线几套几红？ | D1b/D2/D3 或 T35/43.75%；37 套 13 红 |
| 4 | 三套地图口径？引用哪套？ | 能说出“仓库第六图 / 车端第七图 / 第二版识读”，并说“引用必写版本” |
| 5 | 哪四个路径冻结？最终部署谁执行？ | 4 个全对 + “由人执行” |

**答错 ≥2 题** → 不要派活，先让它重读 L1 的 §3/§8/§10，再测一次。
**全对** → 可以进模板 C 派卡。

## H. 常见反模式（别这么写）

| 反模式 | 后果 | 改法 |
|---|---|---|
| “了解一下这个项目” | 回一篇正确的废话 | 加“产出什么 + 验收标准” |
| 一次发整个仓库 / 2.6 GB | 上下文爆、读不完 | 只发 L1（约 35k tokens），代码按需 L2 |
| 让 agent 自己找“最新文档” | 它会把 archive 里的旧文当真 | 点名 6 份事实源 + 给绝对路径 |
| 只说“修一下射击” | 它可能去改冻结区 | 写死写域 + 验收命令 + 回滚点 |
| 不给地图版本 | 三套数字互相打架 | 引用必写“第七图 A 版/B 版” |
| 不做复述验收 | 假读懂，动手才暴露 | 先过模板 G 的 5 问 |
