# 发送指南：发什么、走哪条通道、怎么验收

> 配套：`00_一页纸.md`（L0）、`10_提示词模板.md`（提示词）、`packs/`（已打好的包）。
> 结论：**能同机读盘就别发文件；要发就发 L1（7 个文件 / 约 3.3 万 tokens）；L2 只给同机或内网。**

---

## 1. 一句话决策树

```
对方能直接读你这台机器吗？
├─ 能（同机 DSH / Cursor / Claude Code / Codex CLI）
│    → 只给绝对路径，一个文件都不用发（最快、最省 token）
├─ 是 DSH teammate / subagent（共享文件系统）
│    → spawn 时在 prompt 里写工作区 + 要读的路径，不发附件
└─ 不能（网页版 / 另一台电脑 / 手机 / 群里）
     ├─ 只要“了解项目”        → 发 L0（一页纸，1 个文件，约 1.7k tokens）
     ├─ 要“接手干活/写方案”    → 发 L1（7 个文件，约 33k tokens）★推荐
     └─ 要“改代码/深审”        → 同机给路径；异机发 L2（2.9 MB，内部用）
```

## 2. 三档包（2026-10-20 实测）

| 档 | 文件 | 文本量 | ≈tokens | zip | 给谁 | 安全级别 |
|---|---|---:|---:|---:|---|---|

## 3. 五条通道，具体怎么发

### 3.1 同机 agent（最优，零附件）

在对方对话框里粘贴：

```
先读 D:\User\Desktop\比赛存档\v1\docs\项目总览_AGENT_20261020.md，
再按它 §10 的顺序读；只读，不改任何文件。
读完先用 300 字复述：8 线程、3 个 P0、三套地图口径、无人机为什么不可飞。
```

- 优点：不占上传、不丢链接、agent 可自己按需读更多。
- 注意：Windows 路径用反斜杠；路径含中文，让 agent 用引号包住。

### 3.2 DSH teammate / subagent（共享文件系统）

不要贴文档，直接在 `prompt` 里写路径和写域：

```
工作区：D:\User\Desktop\比赛存档\v1
先读：docs/项目总览_AGENT_20261020.md 的 §3/§8/§10
写域：只写 _tmp_session/<卡号>/；其余只读
交付：结论 + 文件:行号 + 可复跑命令；落盘到 _tmp_session/<卡号>/report.md
```

详见 `10_提示词模板.md` 模板 E。

### 3.3 网页版（ChatGPT / Claude / Gemini）

**优先传 .md，不要只传 zip**——多数网页版不会自动解压，附件是二进制它读不了。

| 对方上下文 | 发什么 | 怎么发 |
|---|---|---|
| 8k | 只贴 `00_一页纸.md` 全文 | 直接粘在消息里 |
| 32k | `00_一页纸.md` + `项目总览_AGENT_20261020.md` | 2 个附件 |
| 128k+ | 整个 L1（7 个文件） | 逐个上传，按 00→01→… 命名 |
| 有 Projects/知识库 | 把 L1 全放进去，长期复用 | 一次配置，后续不用再传 |

发送话术（附件之外单独发一条）：

```
这是「空地协同侦排」项目的交接包（2026-10-20 快照）。
请按 00 → 01 → 02 的顺序读，先只读 00_先读我.md。
读完先别动手，用 300 字回答：8 线程、3 个 P0、三套地图口径、无人机为什么不可飞。
```

### 3.4 另一台电脑 / 同事

- 发 **L1 包**（48.9 KB）即可；对方解压后根目录当工作区。
- 对方如果要跑代码/看实现，再发 **L2**（2.89 MB），并附一句“这是内部代码包，别公开”。
- 传输：微信文件传输助手 / 邮件 / 网盘均可；zip 比 7 个散文件不容易漏。

### 3.5 群 / 手机 / 不方便传文件

只发 **L0 一页纸**（2,951 字符），或直接复制 `00_一页纸.md` 的内容。足够让对方知道“这个项目是什么、现在卡在哪”。

## 4. 附件命名与顺序

按阅读顺序加数字前缀，防止对方乱读：

```
00_先读我.md
01_项目总览.md
02_AGENTS.md
03_项目现状.md
04_决策台账.md
05_TEAM_STATUS.md
06_文档索引.md
```

L1 包里已按目录结构放好；如果单发，建议改名。**不要**把 80 多篇 docs 一次性全发——对方会随机读到过期文档。

## 5. 上下文预算怎么算

| 对方窗口 | 能装下 | 建议 |
|---:|---|---|
| 4k–8k | L0（1.7k） | 只问 3 个问题，别派活 |
| 16k–32k | L0 + 总览（≈15.7k） | 可以问方案，不要贴代码 |
| 64k | L1（≈33k）+ 任务卡 | 可以接手单卡 |
| 128k–200k | L1 + 2~3 个源码文件 | 可以排障/审查 |
| 1M | L2 的一部分 | 仍需按目录检索，别整包灌 |

> 估算口径：中文 ≈1.7 字符/token；代码 ≈3.2 字符/token。L2 的 2.2M tokens 是“整包读”的量，实际没人这么用。

## 6. 安全红线（发之前看一眼）

| 不要发 | 原因 |
|---|---|
| `.git/` | 根仓约 **400 MB**，历史含 **15 个明文凭据脚本**（口令 / `sudo -S` / 写 authorized_keys） |
| `_tmp_session/` | 约 **600 MB** 过程草稿，含临时脚本与口令 |
| `models/`、`*.rknn` | 二进制权重（约 51 MB），交接只需模型名与指标 |
| `drone_recordings/`、`src/history/` | 录像 + 2.1 GB 历史附件，读不完也用不上 |
| `backup/`、`artifacts/` | 可再生产物与备份 |

另外：

- **L1 已核验 0 处凭据**（纯文档），可外发；**L2 仅内部**，含内网 IP/账号，公开前必须人工复核。
- 文档里的车/机 IP 会随网络漂移（10-18 `192.168.137.79` → 10-19 `192.168.0.197`），对外分享可先打码。
- 凭据轮换是独立待办（风险清单 #1），别把“发文件”当成已解决。

## 7. 发完怎么验收（别跳过）

1. **复述**：让对方用 300 字回答 `10_提示词模板.md` 模板 G 的 5 问；答错 ≥2 题就退回重读。
2. **引用**：随便挑 3 个结论，要求它给出 `文件:行号`；给不出 = 没真读。
3. **小任务**：给一个只读任务（如“列出 3 个 P0 的证据链”），看它会不会越界改文件。

三步都过，再派真任务。

## 8. 常见问题

**Q：为什么不直接发整个仓库？**
A：根仓 2.6 GB（其中 `src/history` 2.1 GB、`.git` 0.4 GB），任何模型都读不完；而且历史里有凭据。交接要的是“结论 + 索引”，不是“全量数据”。

**Q：对方说 zip 打不开/读不了？**
A：网页版常见。改成逐个上传 `.md`；或把 L0 直接粘进对话。

**Q：L1 里的链接点不开？**
A：总览里的路径是相对工作区的，单发一个文件时链接失效，但文字引用仍可读。要完整链接就发整包并解压。

**Q：能只发一页纸吗？**
A：能。L0 足够“了解”，但不够“干活”；要派活至少 L0 + 总览 + AGENTS。

**Q：怎么更新包？**
A：改完 `00_一页纸.md` / 总览后重跑：

```powershell
python tools/pack_handoff.py --level all
```

产物在 `docs/agent_handoff/packs/`，MANIFEST 里带生成时间与 sha256。
