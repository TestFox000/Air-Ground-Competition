# 历史留存区 · history_cache

## TL;DR（给 agent 和新人看）
- 这里只放「**不再维护、但必须能查原话**」的东西：迁移前旧文档 118 个 + tar 快照包 7 个。
- **只出不进**：新文档一律进四库（00/10/20/30），本区不新增、不修改、不参与门禁。
- 查旧文：按原路径 → `01_旧文档归档/<原路径>`。例：旧路径 `dzrobot_v2/docs/使用手册.md` → [01_旧文档归档/dzrobot_v2/docs/使用手册.md](01_旧文档归档/dzrobot_v2/docs/使用手册.md)。
- 查过程稿/快照：先看 `03_过程稿快照/00_索引.md`，解包到 `_tmp_session/_extract/<包名>/`，用完删；**不要把包内容摊回工作区**（10-22 那次清理就是为这个）。
- 为什么留：库里存的是提炼后的结论，原话（当时的措辞、数字、行号）只有这里还有。删了，「这个结论是不是编的」就无从追溯。

## 2. 三条使用规则
1. **只读**：不改内容、不重命名、不移动。要修正某条结论，写进四库对应册，在册里标「取代: 旧路径」。
2. **引用要带出处**：历史原文写成 `history_cache/01_旧文档归档/<原路径>:行号`，并同时引四库现行结论；只引历史原文不算证据。
3. **解包即用即删**：`tar -xzf 03_过程稿快照/<包> -C _tmp_session/_extract/`，用完清掉，避免又长出一地散文件。
