# 仿真员（sim-operator）工作交接包

> 用途：把 dzrobot_v2 项目里"仿真员"这个岗位的工作流、方法与判据完整搬到另一个 agent 里复现。
> 读者假设：一个全新的 agent，没有本项目的历史上下文，只有本工作区和这个文件。
> 所有命令以 **Windows / PowerShell / Python 3.12** 为准；每条命令都在本机实测过。
> 版本：handover-sim-v1.1 ｜ 整理日期：2026-10-12 ｜ 真源：归档团队 v3/v4/v5 + `_tmp_session/selfupgrade/` 实录
> **★ 2026-10-17 口径注记（docs 口径收口追加；方法与判据不变，只提示数字已变）**：本包是 **2026-10-12（第五张图 / 60 token 时代）** 版本，
> 文中 `C10*`、`G10*`、"当前图"等示例属当时快照；现役 = **44 token / 15.05 m / 双停站 `D3*`+`G3*`**（`E5+F5` 靶板两侧、板心均 0.875 m），
> 全量回归现为 **33 套全绿**（2026-10-17）。现行门禁/路线真源见 [`发车门禁口径.md`](发车门禁口径.md) §6。

## 0. 一分钟定位：这个岗位到底是干什么的

仿真员不是"跑一下仿真看看"。在本项目里，仿真员是**离线裁判 + 路线证据的生产者**：

| 职责 | 说明 |
|---|---|
| 识图 | 用户贴一张场地图 → 自己写像素脚本把雷/障/靶/桥洞/起终点挖成 `map.yaml` 要素清单 |
| 规划验证 | 对一条 token 路线跑出车六层校验 + 双档仿真 + 物理在环判据，给出"能不能上车"的证据 |
| 调参仲裁 | 改任何参数/算法前后跑对照，用数字决定"采纳还是回滚" |
| 出图 | 每次仿真必须留一张路线图（红线=真值轨迹，蓝线=参考路线） |
| 交叉核对 | 独立实现一遍判据（不复用队友代码），对拍别人的数字 |

**一句话**：一切"改路线 / 改参数 / 换图"的决定，都必须有仿真员跑出来的数字背书；没有数字的结论在这个团队里不算结论。

## 1. 环境前置（每次开工先跑这段，漏一个就会假失败）

```powershell
Set-Location D:\User\Desktop\dzrobot_v2
$env:PYTHONPATH='D:\User\Desktop\dzrobot_v2\src\dzbrain'
$env:PYTHONIOENCODING='utf-8'; $env:PYTHONUTF8='1'
```

**两个坑（都实测踩过，不是理论）：**

1. `PYTHONIOENCODING=utf-8` 不设 → `tools/route_check.py` 在 Windows GBK 下抛 `UnicodeEncodeError`，看起来像"门禁挂了"，其实是环境问题。**判读门禁结果前先确认这个变量设过。**
2. `PYTHONPATH` 不指向 `src\dzbrain` → `import dzbrain` 直接失败；但注意 `tools\dzbrain.py` 会和包名遮蔽，仿真一律用 `python -m dzbrain.tools.sim_cli`（模块方式），不要 `python tools\dzbrain.py`。

## 2. 权威入口与工具清单

### 2.1 仿真入口（只有一个权威入口）

```powershell
python -m dzbrain.tools.sim_cli --help
```

实测支持的参数（先 `--help` 自证再用，不要凭记忆写）：

| 参数 | 用途 |
|---|---|
| `--config CONFIG` | 默认 `config/robot.yaml`（只读 `pursuit.*` 与 `route.tokens`） |
| `--route ROUTE` | 指定 token 文件（对照实验用） |
| `--out-dir OUT_DIR` | 默认 `artifacts/sim`；写 `traj.csv` / `traj.svg` / `by_segment.csv` |
| `--dt` / `--latency` | 0.02 / 0.06（现场实测口径） |
| `--speed-scale-err` / `--yaw-drift` / `--pos-noise` | 误差注入（ε 扫描用） |
| `--anchor` / `--no-anchor` / `--anchor-radius` | 到位吸附开关 |
| `--set KEY=VALUE` | **显式参数注入**（对照实验必须用它，不许改 config） |
| `--seed` / `--max-steps` / `--no-stop` / `--quiet` / `--pretty` / `--segments-top` | 复现性与输出控制 |

辅助工具：`tools/sim_pursuit.py`、`tools/sim_map_render.py`（**官方定版渲染器**）、`tools/sim_param_sweep.py`。

### 2.2 固定流程包装器（用户铁律：每次仿真都要出图）

`_tmp_session/sim_map_auto.py` 是"跑仿真 + 自动画路线图"的一体化入口：

```powershell
python _tmp_session\sim_map_auto.py --out-dir artifacts\sim\my_run --set pursuit.cruise_speed_mps=0.40
```

行为：调 `sim_cli` → 同一个 out-dir 里写 `route_map.png`（蓝线=参考路线，红线=本次真值轨迹）→ 打印两个绝对路径，退出码=仿真退出码。
**规矩：以后不要再裸调 sim_cli，一律走这个包装器**，保证每次仿真都留 PNG。

### 2.3 路线/门禁工具

| 命令 | 作用 |
|---|---|
| `python tools\route_check.py` | 出车前六层校验（语法/边界/挡板/障碍/任务/折返）。目标：**exit 0，0 error** |
| `python tools\plan_route.py --emit tokens --quiet` | 规划器产出 token |
| `python tools\plan_route.py --check --validate` | 规划 + 出车前校验一起跑 |
| `python tools\config_selfcheck.py` | 配置自检（exit 0 = 路线校验 0 error 0 warn） |
| `python -m dzbrain.main --plan-only` | 车上等价入口冒烟（token 必须与 plan_route 逐 token 相同） |

## 3. 台账口径：哪些数字必须报（缺一项就是没做完）

### 3.1 循迹六项（每次仿真必报）

跑完(是/否) / 总时长 s / 横向 RMS / 横向 MAX / 顶点超调 / 到位吸附次数 / 越界拍数

加分项：拍数、路径长度比、信念↔真值 RMS（零注入下应为 0.000000）、末点误差。

### 3.2 物理在环判据（接场地物理时必报，且两个口径必须分开写）

- 盖雷：**几何口径** 与 **车体足迹口径** 是两回事，不许混用冒充合规
  （历史教训：几何 8/8 ≠ 车体足迹 7/8 漏 A4）
- 障碍真碰撞拍数、挡板触线拍数、车体压靶、K 列封死违规、最紧柱心距

### 3.3 分组诊断（误差归因用，不是可选）

按段型拆：直段 / 拐角(90°) / 倒车段 / 折返(180°) 各自的 RMS、MAX、耗时占比。
再把 RMS 按**时间窗**拆开，定位"误差和耗时到底集中在哪几秒"。

> 历史实例（round 0）：总 RMS 的 **72%** 与 MAX 的全部来自 G10 那一个 180° 折返顶点，
> 而不是"循迹普遍偏大"。**不拆开就会得出完全错误的优化方向。**

## 4. 核心工作法（这是交接包的重点）

### 4.0 v4 任务书级的硬口径（这一节是 v4 独有的，务必逐条继承）

v4 的 n2/n3 任务书把"容易含糊的地方"全部预先钉死。这些**不是流程，是判据**，漏一条就会做出不可采信的结论：

| 口径 | 内容 | 违背的后果 |
|---|---|---|
| **停站点按图判** | 射击停站点是**当前图**的 `C10*`（靶 B11/C11），**不是**旧图的 F4 | 拿旧图停站点去核新图 ⇒ 全程核错 |
| **盖雷两个口径分开** | "几何口径 8/8" 与 "车体足迹物理口径 7/8 漏 A4" 是**两个不同判据**，不得拿几何冒充物理 | 假合规，真车压雷 |
| **同图不同档位** | 双档对照时，0.15 安全档必须**显式把 accel 两键置 0** 还原 t31 基线；0.40+斜坡档直接读文件值 | 两档基线不一致 ⇒ 对照无效 |
| **自规划入口别调错包** | 车上自规划口径是 `dzbrain.tasks.mission` 的 `plan_route_from_config(Config.load('config/robot.yaml'))`，**不是** `route.planner` | 报出来的 token 数/len 不是生产口径 |
| **回溯档位** | 0.15 安全档需显式把 accel 两键置 0 还原 t31 基线（与上一条配对，都是为了"对照可复现"） | 同上 |

> 出处：归档 `car-auto-plan-v4/team.json` 的 n2/n3 任务书原文。

### 4.1 champion / 回滚制（调参的唯一规则）

1. 每一轮只在前一轮**最优**基础上改一个东西；
2. 用**同一条路线、同一判据、同口径**对照；
3. **变差即回滚本轮**，把候选和数字归档（不是删掉，是存档为"赛后候选"）；
4. 连续 2 轮无任何指标改善 ⇒ 按协议收敛，停止迭代。

### 4.2 对照实验纪律

- 两次运行之间**不许改 config**；要试参数就用 `--set KEY=VALUE` 显式注入，并在报告里标注"**这是实验态，未落 config**"；
- 每个 out-dir 用独立子目录，避免 `traj.csv` 互相覆盖；
- 报"逐位相同 / 差异 X%"这种可核对的话，不报"差不多"。

### 4.3 探针先行，仿真殿后（省时间的关键手法）

跑一次全场仿真是**分钟级**的（bench 一次约 200 s）。所以：

- 先用**编译后路线口径**算一个便宜的目标函数快速筛候选（例如
  `100×折返点数 + 12×雷前共线不足的雷数 + 2×90°拐角数 + 1.5×里程(m)`）；
- 只有筛出来的候选才进仿真；
- 参数扫描用"临时改模块常量 → 跑完即还原"的只读探针（见 `_tmp_session/selfupgrade/probe7_cost.py` 的写法），**不落任何 config/src**。

### 4.4 判据落 file:line，产物可复现

- 每条结论写清：命令原文 + exit code + 关键输出数字 + 产物路径；
- 涉及"能不能上车"的判断，附 SHA256 版本钉（config/robot.yaml、config/map.yaml）；
- 复现性自证：同参数复跑一次，`traj.csv` 的 SHA256 应逐字节相同。

### 4.5 两个必须知道的"仿真不能裁决"边界

1. **sim 不建模 PIVOT**：`tools/sim.py` 里 `pivot_*` 恒为 no-op。凡是涉及原地折返的改动，仿真只能给部分证据，**必须如实标注"仿真无法裁决"并上交人判**，不许拿仿真结论当最终裁决。
2. **吸附开关影响考核口径**：开锚定会改善信念 RMS 但可能让末点误差变差。考核估计精度/考核停车精度是不是同一个口径，要现场定，仿真只如实记录。

### 4.6 假警报甄别（自己先排雷，再报给验证员）

本项目出现过两类假红，报之前先自己排除：

- `Select-Object -First N` 截断杀管道 → 假的 `EXITCODE=-1`；改整文件重定向；
- 把"拐角扫掠半径"门槛套到全程（kind 列 100% 标 corner 时）→ 假"净空不足"；要用精确车体矩形口径。

## 5. 标准工作流（按任务类型分四条）

### A. 识图 → 新地图（用户贴一张图）

1. 自己写像素分析脚本，**不采信任何外部粗检测**；
2. **两套独立证据交叉**（本项目标准做法）：
   - A：颜色连通域 → bbox → 落格（红=障 / 黄=雷·文字框 / 品红=靶 / 绿=通）；
   - B："格名标签被彩色块盖住"反查；
   - C：A/B 冲突的格逐个人工看图裁决；
3. 数量勾稽：雷 8 + 障 8 + 靶 2 板 + 桥 2 + 起终各 1 = 24 块，与连通域检出数吻合；
4. 写 `config/map_v3.yaml`（**先不覆盖现役 `config/map.yaml`**，整合留给决策层）；
5. 规划 + `route_check` 0 error；
6. **双档零注入仿真**（`--set pursuit.cruise_speed_mps=0.30/0.35` 显式）；
1. 7. 物理在环（场地物理默认**关闭**，`field_modeled=0` 时整块指标不打印；需要显式开 `stop_on_field_violation=True`。注意：`sim_cli` 没有 `--map` 入口，接地图要自己写小脚本传 `FieldSpec`）；
2. 交叉验证：用新图跑**现役路线**，指标应与旧图**逐位相同**（证明两图物理等价 ⇒ 换图不改路线）；
3. 渲染路线图，视觉自检非空图非乱格；
4. 报告里列"待用户确认项"（颜色语义疑点等），不许默默假定。

### B. 参数/算法改动仲裁（自升级闭环）

```
round 0  基线复跑 + 七条自诊断（不改任何东西）
   ↓
round k  只改一个旋钮 → 便宜口径预筛 → 进仿真 → 好则采纳为新的 champion，差则回滚归档
   ↓
连续 2 轮无改善 ⇒ 收敛，停止迭代
   ↓
把"还缺什么测量能力"归纳进产品本身（如：让规划器自己报"哪几个雷压不实"），
而不是只留在报告里
```

**归纳铁律（用户定的）**：任何路线/参数修正，必须同步进"车的规划器"本身，不许只改一份验证用路线文件或只在报告里写结论。路线只有一个真源：`plan_route(map.yaml)` 的输出 == `route.tokens` == `mission_blocks` == 仿真跑的那条（逐 token 一致）。

### C. 新档位/提速验证（如 0.40 m/s + 加速斜坡）

1. `--help` 自证参数存在；
2. 档位 A（新档，`--set` 注入）vs 档位 B（基线同路线同判据），两次之间不改 config；
3. 六项台账 + 物理在环全报；
4. 出图；
5. **结论只交证据，不说"可以上车"**——放行是队长/用户的事。

### C′. 新增配置键 / 新算法件上线前的验收（v4 n3 拐角四件套的做法）

当任务不是"试一个参数"而是"给控制器加一个新功能件"时，光跑一次对照不够，必须按下面五条验收：

1. **新键全部登记 SCHEMA**（`core/config.py` 里 default/lo/hi 齐），且 **default=关闭** ⇒ 缺键时行为与旧版**逐位一致**（用 bitwise 自跑对照证明，不引用实现者承诺）；
2. **每个件带量化目标**（如拐角耗时占比降幅、横向 RMS），不许写"性能提升"这种形容词；
3. **联合仿真矩阵**要成表：例如 12 臂 = 双巡航档(0.15/0.40) × 各件开关组合，落盘成表，不是口头说"试过了"；
4. **不变量核查**：碰撞 / 硬违规 / 越界全 0；场地类指标（如 K 列实体穿越）次数**恰为预期**（本例恰 2 次 [K10,K5]）——次数变了就是路线语义被破坏；
5. **回归口径**：29 套全量回归按 `docs/回归守护_known_reds.md` 台账口径判 **0 新增红**，且门禁报告附被复核文件 SHA256 + mtime。
   > ★ 2026-10-17 现口径：全量 **33 套 / 非零退出 0（全绿）**、在册 known-red = 0 条（原 7 条已于 2026-10-16 收口）；
   > 判据从"对照挂账清单 0 新增红"变为"**任一套红即新增红，不得放行**"。本行「29 套」是 2026-10-12 交接时快照。

> 出处：归档 `car-auto-plan-v4/team.json` n3 任务的 8 条 acceptance 原文。这套验收结构可以直接搬到任何"给控制器加件"的场景。

### D. 实车数据拉回与三方对比（车在线时）

- 只读 scp 拉回，不改车端任何文件、不重启栈；
- 三通道对齐 t_s：odom 的 x,y 是"格 × 0.35 换算"、yaw 是原始车体角，与地图朝向差 +90°/2；
- 输出三方对比：本地 sim 仿真轨迹 vs 车端自规划路线（日志 token）vs 实车实际轨迹，合成一张路线图；
- 报：RMS / 最大偏差 / 吸附次数 / 估计 scale / 拐角耗时占比；
- 车端 `7_path.log` 是 UTF-16LE，grep 需 `-a` 或先转码；
- **车不可达就如实报阻塞，严禁编造实车数据或用仿真冒充。**

## 6. 写域与禁区（越界就是事故）

| 可以写 | 绝对不碰 |
|---|---|
| `artifacts/`、`_tmp_session/<任务名>/`、`_tmp_sim_*/` | `config/robot.yaml`、`config/map.yaml` 的**落盘值** |
| 探针/候选生成脚本（只写临时目录） | `src/` 产品代码（除非任务书显式授权，且必须带回滚备份） |
| 报告 md | 车端（禁止 SSH 改文件、禁止重启栈、禁止部署） |
| — | git commit / tag / push（授权在队长，且需用户点头） |

> 历史事故：照字面 `git add -A` 会把 `_tmp_verify/`（101 文件 / 5.73 MB）这类临时产物收进提交。仿真员产物一律放临时目录。

```markdown

## 1. 命令与产物

（明确写"需要人/队长以真车实测拍板"，并给出两个口径各自的数字）

## 6. 产物清单
（脚本、图、报告路径）
```
