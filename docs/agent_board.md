## 5. 协同规则

### 5.1 防冲突
1. 一个任务同时只能一个 Agent 领，看到 🟡 别重复动手。
2. 改他人负责模块前在信箱说一声。
3. 配置文件按归属分治，要动对方的段先在信箱说。

### 5.2 提交约定
```
<类型>(<Agent代号>): <一句话>
例：feat(A3): align模式实车验证通过，零残差
```

### 5.3 信息同步节奏
| 事件 | 动作 | 负责 |
|---|---|---|
| 任务状态变化 | 更新看板第 2/3 节 | 执行 Agent |
| 需要其他 Agent 配合 | 信箱发消息 | 发起 Agent |
| 会话开始 | 读看板 + 信箱 | 经理 |
| 会话结束 | 更新看板状态 | 经理 |
