## 核实标记

- ✅ **已核实**：有文件/配置/实跑日志出处，日期在文内。
- 🟡 **待实车/待复核**：来自会话记录、单次观察或推导，引用前必须复验。
- ⛔ **已废弃/勿用**：保留仅为避免重开旧结论，正文会写替代项。

## 使用与修改规则

1. 先查本馆，再查原始文档/代码。**本馆与代码/config 冲突时，以代码与 config 为准**，并回来修正本馆。
2. 每个数字/结论后面写出处：`文件:行`、config 键、commit 或日志路径。
3. 改本馆不需要开卡；但改 `config/**`、`src/dzbrain/dzbrain/**` 仍走冻结闸（卡 → in_flight 登记 → 回归 → 部署）。
4. 新增页面在本索引登记；提交前跑 `python tools/wf/check.py`（文档 0 断链是硬门禁）。
5. 不复制长篇原文，只留结论 + 链接；细节回原始文档。
