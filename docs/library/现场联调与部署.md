## 2. 部署（本地 → 车）

    cd D:\User\Desktop\比赛存档\v1\dzrobot_v2
    python tools\deploy_to_car.py probe              # 解析车端 IP/状态，先确认连得上

    python tools\deploy_to_car.py verify              # 可选：车上包/入口/云台补丁符号检查

- 绝不在验证阶段起 ROS 栈；起栈前把轮子架空。

## 7. 现场安全红线

1. 第一次/新代码：轮子架空，确认方向、刹车、SAFE_STOP 再落地。
2. 部署/联调 --force-no-autostart；确认 mission.auto_start=false；不要带 LEGACY_PATH=1 试新核心。
3. 任何“已部署/已修复”必须给 sha256 或复跑命令；车端日志与本地提交对不上就停下查。
4. 全量回归先备份 _tmp_full_regression/，别覆盖 D-023 引用的 10-18 基线。
