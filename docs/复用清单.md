# 复用清单（REUSE）

> **唯一作用**：防止重复造轮子。新建任何脚本/模块/工具前先在本表检索；确需新建，在卡片里写「为什么现有不够」。
> 维护：谁新增强制登记谁；Lead 每轮抽查一次。
> **先查目录**：文件/目录在哪、谁负责、是否冻结/历史 → 见 `docs/目录索引.md`（`python tools/wf/repo_index.py --write` 生成）。
