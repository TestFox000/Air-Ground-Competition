# 项目成果汇总

> **Agent-6 成果汇报 出品**。本文档汇总项目所有关键成果，支撑答辩和复盘。

---

## 1. 项目概述

**项目名称**：空地协同侦排挑战赛
**核心目标**：无人机侦察获取目标情报 → 无人车执行排雷和打击任务
**技术栈**：YOLO 检测 + CNN 格号识别 + PnP 定位 + Held-Karp 路径规划 + ROS2 车端

### 2.4 路径规划

| # | 成果 | 说明 |
|---|---|---|
| 1 | Held-Karp 位压 DP | 全局最优路径，避免贪心绕路 |
| 2 | 8 邻域 Dijkstra | 考虑转向代价，路径更平滑 |
| 3 | 桥洞动态推导 + 正交贴门 | 桥洞列由 ARROW 识别推导（不写死），禁止斜穿 |
| 4 | 靶格禁踩 + 停靠射击位 | 正交相邻格停靠瞄准 |
| 5 | 路径点压缩 | 删除同向共线中间格，减少转向 |

### 2.5 车端朝向对齐

| # | 成果 | 说明 |
|---|---|---|
| 1 | align 模式 | 无人机 0x4002 帧真实 yaw 闭环转向 |
| 2 | 根除画圆 | 零残差，消除 68.6° 固定偏差 |
| 3 | 超时保护 | 单一 heading_align_timeout=15s，超时退回最近轴断言继续发车 |
| 4 | 安全停转 | 残差 ≤ 阈值自动停止转向 |

### 2.6 机载端 dzuav

| # | 成果 | 说明 |
|---|---|---|

| 2 | TRT 推理热路径优化 | pinned 缓冲/张量地址一次绑定 |
| 3 | UDP CRC 查表/缓冲复用 | 减少每帧分配 |
| 4 | 0x4002 车位姿帧广播 | 供车端朝向对齐 |
| 5 | Orin 编译脚本 | orin_build_verify.sh，L0~L3 分层验证 |

## 4. 关键技术决策

| # | 决策 | 原因 | 备选方案 |
|---|---|---|---|
| 1 | PnP 自定位替代单应矩阵 H | 官方路径用格号做天然地标，无需人工标定 | 单应矩阵标定（已废弃） |
| 2 | align 模式替代盲目朝向断言 | 车无绝对朝向参考，需外部 yaw 闭环 | 人工摆位（降级方案） |
| 3 | 二进制 UDP 替代 JSON | 与官方 dzuav 字节级对应，效率高 | JSON（已废弃） |
| 4 | 按时间块切分数据集 | 防止数据泄漏 | 随机切分（已废弃） |
| 5 | Gitee 替代 GitHub | 国内访问流畅 | GitHub（卡顿） |
