### 4. 判据陷阱 3（本轮自踩，记账）

比对脚本第一版用 `\node_modules\` 正则过滤「嵌套依赖」，但 **dst 路径本身就含 `\node_modules\`**（`profiles\desktop\node_modules\dsh-dzairground-ssh\...`），把整个实装目录过滤成 0 文件，差点误判「安装失败」。**教训**：过滤嵌套 node_modules 必须用「相对路径前缀」判据（`rel -like 'node_modules\*'`），不能对全路径做子串匹配。与 §7.2 子串陷阱、§7.4 编码陷阱同类：**判据写法本身会造假红/假绿**。
