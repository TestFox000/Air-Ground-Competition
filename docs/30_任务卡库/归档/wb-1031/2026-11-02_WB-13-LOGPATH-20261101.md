# WB-13 · `dzlink_supervisor.default_log_path()` 的 cwd 兜底陷阱

## 读过的台账条目

- WB-10 卡面 §执行报告·遗留：`tools/link/dzlink_supervisor.py:215-218` 的 `os.getcwd()` 兜底**仍在**，WB-10 只切断了自己那条调用路径。
- D-063（本线翻案依据）；铁律 5「证不出来 = 没完成」。

## 为什么必须修（captain 实测踩了两次）

WB-10 修好之后我仍然复现了这条——因为它不在 `dryrun_full_route.py` 里：

```python
# dzsmartscout/tools/link/dzlink_supervisor.py:214-218
def default_log_path() -> str:
    if platform.system() == "Windows":
        return os.path.join(os.getcwd(), "dzlink_supervisor.jsonl")   # ← 陷阱
    return "~/dzlink_logs/supervisor.jsonl"
```

**任何**在 Windows 上从工作区根调用 supervisor 的路径（我实测过 `dryrun_full_route.py` 那条，也会影响 runbook、手工命令、未来任何新脚本）都会在 `v1/` 根掉一个未跟踪 jsonl。这是"临时文件污染工作区"的典型形态，而且它**跨卡**：WB-10 治的是"谁触发它"，本卡治的是"它本身为什么存在"。

我在本轮已两次手工把它移进 `_tmp_session/wb-1031/legacy/`（`dzlink_supervisor_20261101_0045.jsonl`、`..._0130.jsonl`）——手工清理不是机制。

## 两个候选修法与取舍

| 方案 | 做法 | 风险 |
|---|---|---|
| **A 无路径就不写** | `default_log_path()` 返回 `None`；调用方不传 `--log` 时不落盘，stderr 提示一行 | 可能影响依赖"默认写到 cwd"的部署脚本；但**静默不写**比**静默污染工作区**安全 |
| **B 写到固定位置** | Windows 也学 POSIX，落 `~/dzlink_logs/supervisor.jsonl` | 行为变了但更可预期；需要确认 `~` 在 Windows 上解析到哪个目录（可能是 `%USERPROFILE%`），且要保证目录存在 |

**建议 B**（与 POSIX 分支统一，语义最简单），但**实现者必须先查清 `expand()` 在 Windows 上把 `~` 解析到哪里、目录创建逻辑是否已存在**，再把结论写进卡面。选 A 也行，必须给出"为什么宁愿不写日志"的理由。

## 验收（独立复跑）

见 front matter `verify` 三条。**核心判据是"任意 cwd 都不掉文件"**，不是"某一条路径不掉"。这条判据的写法来自 WB-10 的教训：只堵一条入口不等于修好。

### 七、过程中的三个真实发现（都是"不这么查就会假绿"）

1. **★ 负例第一版是伪负例（差点假绿）**
   我最初用「回退式 patch」造负例：把 `return "~/dzlink_logs/..."` 替换成带 `os.getcwd()` 的旧代码。
   **但它命中了 docstring 里那行 `return`（不是函数体）** ⇒ 负例文件语法坏掉、`default_log_path()` 仍返回固定路径 ⇒ 负例**没变红**。
   若我据此下结论，就会得出荒谬的"判据恒真、什么都没测到"。
   ⇒ 正确做法：**直接用 preimage 原始字节**当负例（97224 B，未经任何编辑）。
   这条与 captain 那条 L2 同族：**别用"自己重新拼一遍"的东西当基准**。

2. **`import` 一个带 `@dataclass` 的模块会炸**（验证脚本第一版）
   用 `module_from_spec(...).exec_module()` 而不先 `sys.modules[name]=m`，会触发
   `AttributeError: 'NoneType' object has no attribute '__dict__'`（dataclass 追溯 `cls.__module__`）。
   修法：**先注册再 exec**；或者干脆用 **AST** 取源码正文（本脚本两条都用了——取源码用 AST，取返回值用正确注册的子进程）。

3. **`.orig` 扩展名让 `spec_from_file_location` 拿不到 loader**
   preimage 存成 `.orig`，`spec.loader` 为 None ⇒ 必须先拷成 `.py` 副本再直调。
