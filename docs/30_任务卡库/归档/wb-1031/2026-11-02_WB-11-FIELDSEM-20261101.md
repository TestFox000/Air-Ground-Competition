# WB-11 · 场地语义不自洽：`field_stopped` 在"已建模"时反而不存在

## 读过的台账条目

- 06 册 §2（2026-10-31 wb-7 实测校正版）：**按 `field_modeled` 置灰的只有那 20 个场地键；越界类不许标 null**；`field_stop_t=-1` 是有效值不是 null。
- D-063 判据③（本线翻案依据）。
- WB-2 卡面 acceptance 第 7 条（本卡正是它的口径补正）。

## 实测证据（captain 复跑，两次对照）

| 跑法 | `field_modeled` | `field_stopped` | `field_stop_t` | `out_of_bounds_steps` | `bounds_margin_m` |
|---|---|---|---|---|---|
| `--arm ideal`（建场地） | `1.0` | **键不存在** | **键不存在** | `0` | `0.6` |
| `--arm ideal --no-field`（不建场地） | `0` | `None` | 键不存在 | `0` | `0.6` |

两处不自洽：

1. **建模了反而丢键**。`metrics.py` 的 `BOUNDS_KEYS = ("out_of_bounds","out_of_bounds_steps","field_stopped","bounds_margin_m")` 被两处代码以**相反**目的使用：`put()` 里用它做"`field_modeled=0` ⇒ 强制 null"（正确用法），`sim_rig.py` 的 else 分支又用它做"不建模 ⇒ 全置 null"。但**建场地时** `field_obs.metrics()` 并不返回 `field_stopped`（那是 `stop_on_field_violation` 的产物，不在 `FieldObs` 里），所以 `field_modeled=1` 时这个键根本没人写 ⇒ 静默消失。
2. **`field_stopped` 被塞进 `BOUNDS_KEYS`，于是继承了"按 `field_modeled` 压 null"的语义**。但 06 册 §2 明写它是「两种模式都在」的那一类（与 `field_stop_t` 同句），tier-0 也是无条件写。所以它根本不该在 `BOUNDS_KEYS` 里 —— 放进去的直接后果就是**两种模式下都消失**（建场地时没人写它，不建场地时被 else 分支压 null）。

> **captain 修正记录（02:0x）**：初版卡面写的修法是「把 `field_stopped` 归入场地类、`field_modeled=0` 时置灰」。**那是读错文档**。06 册 §2 原文是「`field_stopped` / `field_stop_t` 由 `stop_on_field_violation` 决定，**同样两侧都在**」，并非归入 20 个场地键。tier-0 源码也是 `if/else` 同级无条件写。正确修法：**移出 `BOUNDS_KEYS` + 两种模式都无条件写**。这条修正已同步改到 acceptance 与负例（负例从"存在性必须改变"翻转为"存在性不变"）。

## 为什么不是"顺手改个元组"

- tier-0 已有权威口径（`sim.py:1595-1596`：`field_stopped=1.0/0.0`、`field_stop_t=float(t)/-1.0`），台架必须**对齐而不是另立一套**；改错方向会让未来 UI 换数据源时静默变语义。
- `test_wb2_rig_invariants.py` 现有断言把"未建模的越界类是 null"钉住了（`:533-547`，用 `out_of_bounds` 当例子）。**这条本身没错**（`out_of_bounds` 在"没有地图边界"时确实无从计算），但它掩盖了 `field_stopped` 被顺带卷进去的问题。修法要**区分**这两类，不是把断言删掉。

## 处置原则

1. 把 `field_stopped` / `field_stop_t` **移出** `BOUNDS_KEYS`，在指标装配处按 tier-0 口径**两种模式都无条件写**（未触发给 `0.0` / `-1.0`；触发给 `1.0` / 触发时刻）。
2. `out_of_bounds` / `out_of_bounds_steps` / `bounds_margin_m` 的处理须独立判定「地图边界是否可知」：`EVIDENCE` 证明它们走 `geo.in_bounds`（纯几何），建不建**场地要素**都不影响。`--no-field` 时若地图本身仍加载，则应保真值；若连地图都没加载，才允许置灰——**判定依据写清在卡里，不许笼统随 `field_modeled` 压 null**。
3. 断言只增：新增"`field_stopped` 存在性**不随** `field_modeled` 改变"的负例；既有断言不删不放宽。
4. 只改台架侧，**tier-0 `sim.py` 一字不动**（它是基线，改了台账历史跑次失去可比性）。

### 4. 为什么对齐 tier-0 而不新立一套语义

唯一权威口径已存在（`sim.py:1594-1596`），且它是**无条件写**：

```python
    else:
        metrics["field_modeled"] = 0.0
    metrics["field_stopped"] = 1.0 if field_stop_t is not None else 0.0
    metrics["field_stop_t"]  = float(field_stop_t) if field_stop_t is not None else -1.0
```
