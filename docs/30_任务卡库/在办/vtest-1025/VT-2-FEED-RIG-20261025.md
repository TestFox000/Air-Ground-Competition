# VT-2-FEED-RIG-20261025

## 1 五必填

- **读过的台账**：D-015（段边界等 layout ≤10 s）· D-022（布局过期只拦新规划）· D-029（不改 ticksPerMeter，先量）· D-031（靶速封死 1.0 m/s）· D-038/D-039（`field_layout` 唯一构造器 = `build_layout`，发射端必须 import）。
- **复用检索**：见本卡 §2；新增文件一律落 `_tmp_session/vtest-1025/`，**不注册进 复用清单**（过程件），进 `tools/` 才登记。
- **新增轮子及理由**：见 §2 末行"为什么现有不够"。
- **验收命令**：见本卡 §4。
- **回滚点**：本卡只写 `_tmp_session/vtest-1025/`；删目录即回滚，不动仓库。

## 2 事实基线

- `dzuav` 三种源：`uvc:<dev>`（GStreamer v4l2src，mjpeg 优先，失败回退 raw）、`argus:<id>`、`<image|video>` 文件。
  相机管线在 `main.cpp:210-240`：`v4l2src ! image/jpeg,width,height,framerate ! jpegdec ! videoconvert ! video/x-raw,format=BGR ! appsink drop=true max-buffers=1` —— **appsink 已 drop**，所以上游只要按 60fps 供流，dzuav 跑不动就自动丢帧（正是我们要测的真实现象）。
- 机上二进制路径：`~/ag_test/dzuav/build/dzuav`；引擎：`~/dzuav/engines/hbb_detector_fp16.engine` + `cell_classifier_fp16.engine`（`orin_run_dzuav.sh` 默认值）。
- 机上 **无 ffmpeg**（技能文档实测），只有 gst。
- 网络：机 192.168.0.5 / 车 192.168.0.4，**当前不可达**。

**为什么现有不够**：全仓 grep `v4l2loopback|videotestsrc|replay_video` **0 命中**；`orin_run_dzuav.sh` 只有 camera/image/video，没有"按 60fps 回放视频当相机"的路径。

## 3 交付物（全部落 `rig/`，.sh 纯 ASCII）

1. `check_rig.sh`：只读探测并打 GO/NO-GO 表——`lsmod|grep v4l2loopback`、`modinfo v4l2loopback`、`gst-inspect-1.0 v4l2sink|videorate|jpegdec`、dzuav 二进制与两引擎是否存在、`df -h ~`、`free -m`、`nproc`、当前 `/dev/video*` 占用（`fuser`/`pgrep gst-launch`）。
2. 路线 A（优先，零改码）：`serve_camera.sh <video> [--fps 60] [--loop]` = `gst-launch-1.0 filesrc ! decodebin ! videorate ! videoscale ! video/x-raw,format=YUY2,width=1920,height=1080,framerate=60/1 ! v4l2sink device=/dev/videoN`，然后 `dzuav uvc:/dev/videoN ...`。
3. 路线 B（次选，需编译）：给 `main.cpp` 加 `file:<path>` 源（GStreamer `filesrc ! decodebin ! videoconvert ! video/x-raw,framerate=60/1 ! appsink sync=true drop=true`），**补丁先写进 `rig/patch/`，不直接改仓内源码**；用 `orin_build_verify.sh` 的方式在机端独立构建目录编译。
4. 路线 C（兜底，零风险）：`dzuav <video> ...` 非节拍跑，采集每帧 `infer_ms`，用"处理耗时分布"折算 60fps 下会丢多少帧（写清这是推算不是实测）。
5. `run_rig.sh <video> <run_id>`：按选定路线起 dzuav + 收 UDP:50000 → `runs/<run_id>/det_udp.jsonl`（用 `dzudp_core.parse_intel/parse_pose`，**不重写解析**），并记录 `t_recv`、帧序号、丢帧。
6. `rig/REPORT.md`：探测表 + 选定路线 + 三条路线的实测/推算对比。

## 4 验收

- 设备不在线时：脚本 `bash -n` 全过；`check_rig.sh --dry` 能在 Windows WSL?否——则用 `sh -n` 语法检查 + 逐条命令本地核对其参数（gst-inspect 的输出字段以本机文档为准，标注"未实机验证"）。
- 设备上线后（Lead GO）：`check_rig.sh` 出表；路线 A 或 B 能连续跑 **≥60 s 不崩**，实收帧率与丢帧率有数；同一视频用路线 C 跑一遍做对照。

## 5 禁止项

不装包（除非用户明确批准 `modprobe v4l2loopback`）；不改仓内 `main.cpp`（补丁只放 `rig/patch/`）；不占用 `/dev/video0`（真实相机）超过必要；无人机管道脚本纯 ASCII。

## 5 禁止项

冻结区、`git add .`、设备写操作、非 ASCII 的机端 .sh 一律禁止；设备当前不可达（车 192.168.0.4 / 机 192.168.0.5 均 100% 丢包，2026-10-25 14:1x 实测）。
