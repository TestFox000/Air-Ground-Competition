- 新模块 `dzrobot_v2/src/dzbrain/dzbrain/pursuit/trajectory.py`：复用 Route 与 Path 投影，连续曲率 clothoid 原语 + 五次 Bezier 精确 pose 连接；Bezier 曲率通过 Bernstein 凸包递归细分保守证明，不夹曲率、不以采样未发现超限冒充证明。无 SciPy/新依赖。
- 保留雷、停站、桥洞前中后点；普通 out-and-back 引导回环可约简。搜索不改 Route 的任务顺序，普通点弧长映射保持单调；显式 R 段仅倒车，非 R 连接允许有界 cusp，车身航向在 cusp 连续且两侧 κ=0。终点车头服从 Route.end.yaw。
- 输入为 `Trajectory(route,cfg,field,pose_valid=gate)`。共享 gate 来自现有 route_check，由调用方注入，不在核心复制碰撞模型。搜索的 1 cm pose 检查仅剪枝，独立验收采用更密采样和全车运动界。
- 输出 sample(s) 包含 x/y/yaw（行进切线）/curvature/v_max/reverse/s/原段号/curvature_rate，另有 body_yaw。提供 sampled_s、sampled_curvature、speed_caps、stop_s、cusp_s；内部 cusp 不可用原段号单独判断方向。
- v_max 包含 δ_s=Lκ_s/(1+(Lκ)^2) 推导的转向速率上界；κ_s 来自 clothoid 及 quintic 的解析导数。该包络不替代最终输出速率钳位。
