## 2 质量契约
- objective：在 N10 格心 (0.525,0.175)、车头 +Y 下，用外部 240 fps 视频测 3 次 C0 接管停距，给出 `max(d_stop)+e+5<35 mm` 的判定。
- acceptance：① 摆位偏差 ≤1.5 cm/≤3°；② 每趟 release 后 1.0 s 置 manual_override=1；③ 3 趟均有可判帧；④ e≤2 mm；⑤ 判据结果与内部 `/odom` 对照表。
- verify：视频逐帧 + 钢尺读数；`/odom` 位移；两次独立读数差 ≤1 mm。
- inScope：`_tmp_session/AG-TEAM-20261023/T/**`、车端 `/tmp/robot_c0.yaml`。
- outOfScope：`src/**`、`config/**`（除临时文件）、`tools/deploy_to_car.py`；不改任何代码。

## 3 现场步骤
1. 车摆 N10 格心、车头 +Y；钢尺沿运动轴贴地；手机 240 fps 垂直俯拍，画面含起点与停车位。
2. 车端临时配置 `robot_c0.yaml`（仅 `pursuit.cruise_speed_mps=0.10`），`ROBOT_CONFIG=/tmp/robot_c0.yaml ./start_all.sh restart`。

4. release 后 1.0 s `manual_override=1`；车停稳后读钢尺。
5. 重复 3 趟；每趟前确认旧任务不恢复。
