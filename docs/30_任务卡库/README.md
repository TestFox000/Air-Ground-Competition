- 这里是**领卡 → 在卡里写 → 整卡归档**的唯一作业台；卡就是报告，不再另起 REPORT.md（`AGENTS.md` §8.5）。
- 截至 2026-10-22 16:50：库内 **13 篇文件**（README 1 + 模板 2 + 在办 5 + 归档 5），可核卡位 **29 张** = **归档 24**（通过 22 / 部分完成 1 / 终止 1）+ **在办 5**（B1 规划器、B5 量测、T12 无人机、R3B 现场补测、D11 打靶验证）。另有 3 个外部交回包（B/D/E）待验、本地无 CARD〔未〕。
- 最大坑：**卡面"完成"≠ 实车通过**。21:2x 的三张新卡（B1/B5/T0）全部写着"离线完成、未部署、未上车"。
- 本库所有"实测"数字都是**卡内自报**，编纂者未复跑〔未〕；引用时按 `路径:行` 回原卡。

## 1 三条使用纪律

| 步 | 动作 | 硬要求 |
|---|---|---|
| 领卡 | 从 `在办/` 选卡 → 填 `owner` → `status: in_progress` | 一张卡一个 owner；同一文件同一时间只一个写者（`AGENTS.md` §1.4） |
| 写卡 | 执行记录/命令输出/结论/证据**追加进同一张卡** | 缺 5 必填不 ready（见 [模板](模板/任务卡模板.md)）；"已修复"不算完成，要可复跑命令 + 退出码 |
| 归档 | `status: 已归档` + 判定（通过/失败/撤销）→ 移入 `归档/` → 更新 [归档索引](归档/00_索引.md) | **失败也归档，不许删卡**：失败卡是最贵的教材 |

## 2 卡长什么样（两套口径并存）

| 口径 | 出处 | 必填项 |

## 6 派工链演进（为什么一轮接一轮）

- **R0（10-20 18:20）**：只读审阅提出"PIVOT/ALIGN 可能绕过 `P_MOTION_LIMIT`"，本轮只复现不修补。13 例 = 9 PASS / 4 REPRODUCED / 0 INVALID（`_tmp_session/TRACK-R0-20261020-01/CARD.md:4-6`）。→ 缺陷成立，才允许开修补卡。
- **R1（10-20 19:0x）**：唯一假设=在所有分支选完速度后、`publish_command()` 前统一钳位。13/13、tracker 136/136、pivot 55/55（`docs/agent_handoff/35_R1验收与R2实车派工.md:8-9`）。→ 离线绿≠车上绿，必须拿现场基线。
- **R2（10-20 19:46）**：目标"最先限制循迹质量的是信号/执行/几何/控制哪一个"。F1b 双路 ~50Hz、漂移 0.2885°；F2 净位移 0.6961 m、内部横偏 5.24 mm；F3 三点共线进 K10 ⇒ 单弯 0 趟有效（`_tmp_session/TRACK-R2-REVIEW-20261020/REPORT.md:11-15`）。→ 报告被判 needs_revision（`_tmp_session/TRACK-FIELD-R2-20261020-01/review.md:6`），现场门未闭 → R3。
- **R3（10-20 21:0x）**：现场门 ①②③④ 全缺 → 实车 0 趟，按"证据不足"收口（`_tmp_session/TRACK-FIELD-R3-20261020-01/REPORT.md:4-6`）。→ 同夜补上**阿克曼硬件证据**（D-027）：差速包络 99.8°/s vs 物理 34.9~36.7°/s ⇒ 转向问题从"调参"改为"先量测"，开出 B5 与 D-028 双卡。
- **R3B（10-21 19:52→20:45）**：C0×3 停距 22.0/24.2/23.3 mm、C1-short 滑行 17.4 mm、C1_1 0.6917 m，5 趟有效后**整机掉电**（`_tmp_session/PROJECT_STATUS_20261021.md:45-62`）；掉电恢复后补采，**C1 收齐 3/3 全过**，仅 C0 外测与 C2b 未闭合。→ 现场时间被硬件打断，不等于失败。
- **B1 / B5（10-21 21:0x）**：来自《三大优化方案》被定为执行基线（D-028，`_tmp_session/PROJECT_STATUS_20261021.md:84`），两张都是**纯离线卡**，不等现场、不占写域。

## 7 最常见失败原因 Top3（从 review 文档归纳）

| # | 原因 | 典型表现 | 出处 |
|---|---|---|---|
| 1 | **结论超出证据**（内部估计当外部真值） | "直线 mm 级未见限制""首个限制因素是单弯几何"，实为 n=1 + 无外测 | `_tmp_session/TRACK-FIELD-R2-20261020-01/review.md:17-19`（blocker） |
