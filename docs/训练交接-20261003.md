### 3.2 关键修复：NVRTC DLL（5070 Ti 必做）

torch 2.7.0+cu128 自带的 `nvrtc64_120_0.dll` 在 RTX 5070 Ti 上会加载失败
（WinError 1114）。用同目录下的 `.alt.dll` 替换：

```powershell
$dir = ".venv\Lib\site-packages\torch\lib"
Copy-Item "$dir\nvrtc64_120_0.dll" "$dir\nvrtc64_120_0.dll.bak" -Force
Copy-Item "$dir\nvrtc64_120_0.alt.dll" "$dir\nvrtc64_120_0.dll" -Force
```

验证：
```python
import torch
print(torch.cuda.is_available())  # 必须输出 True
```

## 六、已解决的坑（换机必看）

1. **NVRTC DLL 加载失败**：5070 Ti + torch 2.7.0+cu128，必须用 `.alt.dll` 替换 `nvrtc64_120_0.dll`
2. **cuDNN 子进程崩溃**：dataloader workers>0 时子进程加载 `cudnn_cnn64_9.dll` 失败，必须 `workers=0`
3. **AMP 不稳定**：Blackwell + cuDNN9 混合精度可能崩溃，默认 `amp=False`
4. **数据泄漏**：必须用时间块切分（split_capture.py），不能随机按帧切分
5. **.gitignore 陷阱**：排除目录必须用 `dir/*` 而非 `dir/`，否则子目录否定规则不生效
6. **桥洞标注粒度**：只框入口段（arrow 外扩 3 倍），不框整条桥
