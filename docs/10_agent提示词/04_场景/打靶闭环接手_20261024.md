# 场景卡 · 打靶闭环 → 循迹整体框架 接手（2026-10-24）

## TL;DR（给 agent 看的）

- 用在「换一个 agent 接着做自瞄打靶，打完接着接进循迹框架」时：**整段复制 §3 的提示词**发过去，它自己知道读什么、写哪、做到哪停。
- 提示词是**两阶段**的：阶段一（提前量）做完必须停下等拍板，阶段二（整体框架）另说。**别让它一口气全干**。
- 前提：**同一个工作区、同一个 git 仓库**。所以提示词里给的是**路径**，不发附件、不贴长文。
- 现状一句话：链路已通（裁判板 1:1 记账 2 发），瓶颈是 `/aim/lead_x` 无发布者 ⇒ 匀速段必然落后 33 px > 开火框 25~26 px。
- **最容易搞错的第二条**：今天车上**没有 AimTask 在跑**，开火权在 C++ 内部判据手里（手册 §1.5 三处证据）。不知道这条，会去改一个根本没上车的模块。

```

工作区 W = D:\User\Desktop\比赛存档\v1（Windows 11 + PowerShell + Python 3.12）

开工第一件事：cd W 然后 git status --short。工作区里可能有另一个会话没提交的活，一律不碰、不清理、不格式化。

先读三份，按序，别跳：
1) W\docs\00_项目总览\交接_20261024_打靶闭环.md   —— 交接手册：全部事实、边界、两阶段路线（这是主文件，§6 是阶段二）

3) W\_tmp_session\aim-p0\T5_summary.md              —— 上一轮设计包的 5 条结论

这条线分两阶段。本轮**只做阶段一**，阶段一验收通过后停下等我拍板，不要自己进阶段二。
阶段一 = 让云台打得中（提前量 + 判据）；阶段二 = 把打靶接进循迹的整体框架（到站打、离站走、全程不卡死）。

一句话现状：开火链路已经通了（实车 2 发，裁判板射击 5→7、弹药 5→3，1:1 记账），但提前量通道 /aim/lead_x 没有任何发布者。靶速 126.5 px/s × 延迟 0.26 s ≈ 33 px 的固定落后，而开火框只有 25~26 px，所以匀速段必然打偏，只有靶子换向的拐点能中。

另一条别搞错的事实：今天车上**没有 dzbrain 的 AimTask 在跑**，开火权在 C++ 内部判据手里。证据三条（手册 §1.5）：/aim/fire_ready 全程 0 条消息（AimTask 若在跑每拍都会发）、云台全程 TRACK（AimTask 默认会锁止成 0）、有 2 发开火但两键门控的 ready 恒空。所以不要假设"本地 aim.py 里有 lead 逻辑，车上就会用"。

硬约束（违反即返工）：
- 只写 W\_tmp_session\aim-lead\ 下你自己的文件 + 你的任务卡。冻结区一律不碰：config\**、src\dzbrain\dzbrain\**、src\dzrknn_dataprocess\**、tools\deploy_to_car.py
- 不重启整栈、不发车、不碰无人机、不动别人的未提交文件；不 git add .；不 force push
- 车端只读：所有验证在 _tmp_session 里离线做；要上车的东西先交出来给人看
- 一轮只改一个变量

阶段一步骤（按序，任何一步卡住就停下报告，别硬推）：
1) 复现数字：python artifacts\aim-mv-20261024\analyze.py，核三行：off_frames=1897 / target_speed_px_per_frame.median=5.0 / frac_frames_speed_le_1.5≈13.77%。对不上先报告，不要继续往下做。
2) 探活：ping duzhong.local；通了再 ssh dzrobot（密码认证，口令问人，不要写进任何文件），查三样：
   ros2 node list 里 dzjudgment 在不在；
   ros2 topic hz /aim/fire_ready（0 ⇒ 确认 AimTask 没跑，与手册一致）；
   ros2 param get /dzrknn_dataprocess use_external_fire_gate（看车上真实值，别信本地 yaml）。
   车不在线就停在这里报告，不要猜 IP。
3) 写节点：在 W\_tmp_session\aim-lead\ 下新建一个节点脚本，订阅 /offset_center、发布 /aim/lead_x（std_msgs/Float32，单位 px）。
   最小实现即可：EMA 估横向速度（窗口约 0.2 s），lead = v_px_per_s * 0.26 * k，k 默认 1.0、命令行可调；必须有 --dry-run（只打印不发布）。
   离线自测：把 artifacts\aim-mv-20261024\mvlog.csv 回放进去，逐帧打印 dx / lead / (dx+lead)，证明匀速段 |dx+lead| 中位明显小于 |dx|。符号必须先用 dry-run 确认，反了会把云台越推越偏。
4) 交付：_tmp_session\aim-lead\PLAN.md（设计 + dry-run 证据 + 回滚 + A/B 方案：k=0 vs k=1 各 2 发怎么比），然后停下等我拍板，不要自行上车发布。

阶段二（等我说「进阶段二」再做，现在先别动）：路线在手册 §6。两个前置都要我点头：
一是定开火权（A 保持 C++ 内部只喂 lead，还是 B 启用 AimTask 两键）；
```
