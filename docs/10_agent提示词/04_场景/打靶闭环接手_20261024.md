## 4 这份提示词刻意没写什么

| 没写 | 为什么 |
|---|---|
| 阶段划分 / 步骤 / 先后顺序 | 方案是用户要另定的，写死顺序等于替用户做决定 |
| 交付物（节点脚本、PLAN.md、验收单） | 同上；要不要写代码、写到哪一步，由用户和它谈 |
| 优先级与时间预算 | 没有依据，编出来的计划比没有计划更糟 |

只留三类内容：**事实**（已证实的数字与结论）、**路径**（文件在哪、在哪能查到什么）、**项目规矩**（冻结区、不发车、弹药 3 发这类与进度无关的硬边界）。
