# 发送指南：发什么、走哪条通道、发完怎么验收

## TL;DR（给 agent 看的）

- **能同机读盘就别发文件**；要发就发 L1（≈33k tokens），L2 只给同机/内网。
- 绝不能发：`.git`、`_tmp_session`、`models`、`drone_recordings`、`src/history`（原因见 §5，全有体积/凭据依据）。
- 最大坑：以为「发完就完了」——不验收，对方会拿着过期文档当现行（§6 五问）。

## 1. 一句话决策树

```
对方能直接读你这台机器吗？
├─ 能（同机 DSH / Cursor / Claude Code）→ 只给绝对路径，一个文件不发
├─ 是 DSH teammate/subagent（共享文件系统）→ prompt 里写工作区 + 要读的路径
└─ 不能（网页版 / 另一台 / 手机 / 群）
     ├─ 只要"了解项目" → 发 L0（一页纸，1 个文件 ≈1.4k tokens）
     ├─ 要"接手干活"   → 发 L1（7 个文件 ≈33k tokens）★推荐
     └─ 要"改代码/深审"→ 同机给路径；异机 L2（2.89 MB，仅内网）
```

## 2. 三档包（数字标明来源与时效）

| 档 | 文件 | 文本量 | ≈tokens | 打包体积 | 给谁 | 安全级别 |
|---|---|---:|---:|---:|---|---|
| L0 速览（旧包） | 1 | 2,951 字符 | ≈1,736 | 4.4 KB | 小上下文 / 探路 | ✅ 可外发 |
| **L0 新版（本库一页纸）** | 1 | **2,457 字符** | **≈1.4k** | 无需打包 | 同上 | ✅ 可外发 |
| L1 接管 | 7 | 56,331 字符 | ≈33,138 | 48.9 KB | 接手干活 | ✅ 已核 0 处凭据 |
| L2 代码 | 682 | 6.09M 字符 | ≈2.22M | 2.89 MB | 同机/内网深挖 | ⚠️ 仅内部 |

- 数字来自 `docs/agent_handoff/packs/L0_MANIFEST.md`、`L1_MANIFEST.md`、`L2_MANIFEST.md`（生成时间 2026-10-20 17:40）。
- ⚠️ **包未重打**：L1 里仍是旧 7 篇（含已收敛为指针的 `项目现状_20261018.md`/`TEAM_STATUS.md`），**不含 30–37 派工文与四库新文档**。发给新 agent 时优先「给路径」而不是发旧 zip。

## 3. 上下文预算（先算再发）

### 3.1 对方窗口能装多少

| 对方窗口 | 能装下 | 建议 |
|---:|---|---|
| 4k–8k | L0（1.4k） | 只问 3 个问题，别派活 |
| 16k–32k | L0 + 项目总览 | 可以问方案，别贴代码 |
| 64k | L1（33k）+ 一张卡 | 可以接手单卡 |
| 128k–200k | L1 + 2~3 个源码文件 | 可以排障/审查 |
| 1M | L2 的一部分 | 仍要按目录检索，别整包灌 |

### 3.2 别忘了宿主自己已经吃掉多少（实测）

| 项 | 量 | 出处 |
|---|---|---|
| 系统提示词合计 | **185,636 字符 ≈ 51.6k tokens** | `_tmp_session/PC-01-提示词压缩/账本.md` §1 |
| 其中 ToolArgsMap | **73.6%**（≈37.9k） | 同上 |
| 首轮注入 | **33,452 字符**（memory 24,973 + AGENTS 4,644 + skills 2,639 …） | 同上 §3 |
| 第二轮起注入 | **13,261 字符**（memory 4,855 + AGENTS 4,644 …） | 同上 §3 |

⇒ 给 64k 窗口发 L1（33k）时，**实际只剩不到 20k 干活空间**；预算紧就只发 L0 + 路径。

## 4. 五条通道怎么发

| 通道 | 发什么 | 注意 |
|---|---|---|
| 同机 agent | 只给绝对路径 + 一句「先读 X 再按 §Y」 | Windows 路径反斜杠；中文路径加引号 |
| DSH 子智能体 | prompt 里写工作区 + 写域 + 回报文件 | **共享文件系统**，别贴文档 |
| 网页版 | 传 `.md`，**不传 zip**（多数不自动解压） | 按 00→01→ 命名，逐篇传 |
| 另一台电脑/同事 | L1（48.9 KB） | 附一句「内部资料，别公开」 |
| 群/手机 | 只发 L0 全文 | 足够知道「是什么、卡在哪」 |

## 5. 能发什么 / 绝不能发什么

| 不发 | 体积/原因（实测） | 依据 |
|---|---|---|
| `.git/` | 根仓 ≈400 MB；历史含 **15 个明文凭据脚本**（口令、`sudo -S`、写 `authorized_keys`） | `.../history.md` §7.1；`packs/L0_MANIFEST.md` |
| `_tmp_session/` | 旧指南写 ≈600 MB，10-20 实测 **1031 MB / 39 目录**，含临时脚本与口令 | `.../history.md` §4 |
| `models/`、`*.rknn` | ≈51 MB 二进制，交接只需模型名与指标 | `packs/L1_MANIFEST.md` |
| `drone_recordings/`、`src/history/` | 录像 + **2.1 GB** 附件，读不完也用不上 | 同上 |
| `backup/`、`artifacts/` | 可再生产物（artifacts/sim 227 MB） | `.../history.md` §6.4 |
| 任意 `.env` / 车机口令 | 车 IP、域号、账号属内网信息 | 原则 |

- **L1 已核验 0 处凭据**（纯文档）可外发；**L2 含内网 IP/账号**，公开前必须人工复核。
- 车/机 IP 会漂移（10-18 `192.168.137.79` → 10-19 `192.168.0.197`），对外可打码。
- 凭据轮换是独立待办（风险清单 #1），**发文件不等于已解决**。

## 6. 发后验收 5 问（别跳过）

先测再派活；答错 ≥2 题 → 退回重读，别急着下任务。

| # | 问题 | 及格的回答 |
|---|---|---|
| 1 | 起点/终点/场地/时限/隔板约束？ | N10 / N5 / 4×5 m / 0.35 m 格 / 挡板在 6-7 行、只有 A·B·C 能穿 / 180 s〔档〕 |
| 2 | 车端 8 线程任说 5 个 + 频率 | 至少 4 个对（定位20/安全20/循迹50/任务10/云台50/修正10/无人机5/遥测2） |
| 3 | 当前三个最大风险 + 回归基线几套几红 | 43.75% / R1 未部署 / 无人机不可飞 或 13 套红；**37 套 13 红** |
| 4 | R1 现在什么状态？ | 本地 `e9bff6f0…` 已过 136/136+55/55+13/13；**车端仍是 `9e9766a1…`，未部署** |
| 5 | 四个冻结区 + 车端最终替换谁执行 | 4 个全对 + 「由人执行，唯一入口 deploy_to_car.py」 |

再加两步：**抽 3 个结论要 `路径:行号`**（给不出 = 没读）；**给一个只读小任务**看它是否越界改文件。

## 7. 一分钟清单

- [ ] 对方能同机读盘？→ 只给路径
- [ ] 不能 → 定档：了解=L0，干活=L1，改码=L2（内网）
- [ ] 网页版传 `.md` 不传 zip，按 00/01 命名
- [ ] 附一句「先读，读完复述 5 问，别动手」
- [ ] 确认没发 `.git` / `_tmp_session` / `models` / 录像 / 凭据
- [ ] 发完做 §6 三步（5 问 + 行号 + 只读小任务）
