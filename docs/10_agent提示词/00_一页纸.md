# 一页纸 · 空地协同侦排（L0 · 可直接贴进对话）

## TL;DR（给 agent 看的）

- 这是**唯一该整段贴给新 agent 的项目卡**（约 2.7k 字符）；要它干活再给路径或 L1，别只发这篇。
- 现状（2026-10-21 21:20）：R0/R1 离线闭环完成，**R1 补丁未上车**；R3B 拿到 5 趟有效数据后 20:45 掉电。
- 最大坑：把「本地已验证」当「车上已生效」——车端 tracker 仍是 R1 前版本（`9e9766a1…`）。

## 这是什么

无人机先侦察（读桥洞顶部箭头、扫全场）→ 把「事实」下发给小车 → 小车在 **4 m × 5 m**、**14 列（A~N）× 11 行（1~11）**、**0.35 m** 格内，**180 s** 完成压雷 8 / 避障 8 / 打移动靶 / 穿 2 个桥洞 / 到终点 **N5**；起点 **N10**。180 s 是队内口径，官方说明书只有场地布置、无计分表〔档〕。

## 三条最硬约束

1. 中间挡板恒在 **6/7 行之间、横跨 D~N** ⇒ 只有 A/B/C 能上下 ⇒ 赛道被迫 **U 形**。
2. 桥洞通行状态只能由无人机读**顶部箭头**（赛规明文），车端必须能消费这条情报。
3. 雷是 **12 cm 彩图平贴地面**（只能视觉），障碍是装水彩桶（遮挡视线）。

## 系统构成（一句话）

车 `dzrobot_v2`：RK3588S + ROS2 Humble（域 118），`dzbrain` 单进程 8 线程（定位20/安全20/循迹50/任务10/云台50/修正10/无人机5/遥测2 Hz）+ 4 个 C++ 节点（底盘/云台开火/裁判激光/RKNN 检测）。
机 `dzsmartscout`：Jetson Orin Nano + PX4 + FAST-LIO + MID-360，回放式路径跟随，向车下发 `/nav/waypoint`（RELIABLE）与 `/dzlink/*`（BEST_EFFORT）。

## 顺手记住两个坑

- `cam_viewer` 会以 20 Hz 向 `/pursuitAngle` 发全零 ⇒ **车「收到了但不动」**；跑车前必须 kill。
- 非交互 SSH（`ssh host 'cmd'`）域号变 0 ⇒ ping/SSH/网页全通、**ROS 互相看不见且零报错**；起栈前必须 `source dzros.env`。
