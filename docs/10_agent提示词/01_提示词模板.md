# 6 套基础提示词模板（可直接复制）

## TL;DR（给 agent 看的）

- 六套模板覆盖 90% 场景：A 速览 / B 接管 / C 单卡 / D 审查 / E 子智能体 / F 小模型。
- 每套只需替换【】里的占位符；**模板里写死的红线与验收不要删**，删了就会返工。
- 最大坑：只发资料不发产出与验收 ⇒ 拿回一篇总结（旧 `10_提示词模板.md` §H 已列）。

## 0. 五段骨架（所有模板都是它的变体）

```
① 身份 + 边界   你是【角色】；只读/可写【范围】；不许碰【冻结区】
② 事实源        只认这 N 篇（给路径）；冲突时以【代码/实测】为准
③ 当前任务      一句话目标 + 本次范围（+ 唯一变量）
④ 验收标准      可复跑命令 + 期望输出 + 回滚点
⑤ 输出契约      先复述 → 等我确认 → 给计划 → 再动手；结论带 路径:行号
```

三条铁规（旧版 §0）：提示词是**任务书**不是资料堆；事实源要**点名字**；输出契约**写死**。

## A. 速览（无附件，30 秒）

**适用**：对方上下文小，只需知道项目是什么、不干活。

```
你是新加入"空地协同侦排挑战赛"项目的 agent。下面这段是项目卡，读完再回答：不要凭常识补全，不要展开成报告。

【把 docs/10_agent提示词/00_一页纸.md 全文粘贴到这里】

请用不超过 400 字回答：
1) 这个项目要解决什么？三条最硬的场地约束是什么？
2) 现在最大的三个风险是什么？R1 修的东西为什么不能算"车已修好"？
3) 哪三件事你绝对不能做？
最后列出你还不确定的 3 个问题。
```

## B. 接管项目（主力模板）

**适用**：新 agent 真要接手（读码、排障、写方案）。同机给路径即可，异机发 L1。

```
你是 dzrobot_v2 / dzsmartscout 项目的接手 agent。角色：【决策层 / 循迹控制 / 规划器 / 无人机 / 文档治理，五选一】。
工作区：D:\User\Desktop\比赛存档\v1

【事实源】只认这 4 处，其余文档一律当"可能过期"（旧路径原文在 docs/history_cache/01_旧文档归档/<原路径>）：
1. docs/10_agent提示词/00_一页纸.md
2. docs/00_项目总览/现状快照.md（先看它头部的日期）
3. AGENTS.md（六铁律 + §8 文档纪律 + 收口门禁）
4. docs/20_资料索引库/README.md（数字/症状/坑）
冲突时以代码与实测为准，并在结论里标〔实〕/〔档〕/〔未〕。

【红线】
- 不改冻结区：src/dzbrain/dzbrain/**、src/dzrknn_dataprocess/**、config/**、tools/deploy_to_car.py
- 不重开已裁决事项；要翻案先答"新证据 / 影响面 / 不重开的代价"
- 不说"已修复/已优化"；每条结论给 路径:行号 或 可复跑命令 + 输出
- 不知道就写〔未〕，不要猜

【先别动手】用 300 字复述：
a) 车端 8 线程各干什么（至少 5 个）；
b) 当前三个最大风险；
c) R1 现在处于什么状态（本地/车端各是什么）；
d) 你准备先读哪个文件、为什么。
我确认后你再给计划。
```

## C. 单卡执行（承 B 追加）

**适用**：已经接管过、发一张有边界的卡。

```
承接上面的上下文。本次任务卡：

- 卡号：【TRACK-XXX-20261021-01】
- 目标：【一句话，可验收】
- 写域：只许写【路径/文件】，其余只读
- 唯一变量：【这一轮只改这一个东西】
- 复用：先查 docs/20_资料索引库 与 dzrobot_v2/docs/复用清单.md，写清复用哪个实现
- 验收：运行 `【命令】`，必须输出【期望结果】（含退出码与失败 ID）
- 回滚点：【备份路径 / 反向 diff 怎么打】
- 交付：在 docs/30_任务卡库/在办/<卡号>.md 里追加记录（卡即报告，不另起 REPORT.md）

先给我 5 行计划（改哪些文件、怎么验、风险点、回滚），我点头你再改代码。
```

## D. 代码审查（只读）

**适用**：独立审查一份改动/一个模块，**不写代码**。

```
你是独立审查者，不写代码、不改文件、不替执行者修补。审查对象：【模块 / tracker.py 的 R1 补丁 / 提交号】。
事实源：docs/10_agent提示词/00_一页纸.md、AGENTS.md、被审文件与其测试。

逐条输出：问题 / 证据（路径:行号）/ 影响 / 建议 / 置信度（高/中/低）。
重点查五类：
1. 冻结区越界、绕过 tools/deploy_to_car.py 手工 scp；
2. Config 缺键静默默认（现场改参数不生效）；
3. 线程安全（共享状态、stop/join、闩锁不可恢复、SAFE_STOP 语义）；
4. ROS QoS 不匹配（BEST_EFFORT 发 → RELIABLE 收 = 静默 0 条）；
5. 文档与代码不一致（版本号、地图口径、频率、行号漂移）。

最后给一句结论：可以合并 / 必须打回，并列出打回项与"必须附的补充证据"。
```

## E. DSH 子智能体（给 Lead 用）

子智能体与父会话**共享文件系统**，所以给路径，不要重复贴文档；一卡一写域。

```
名称：【小写-连字符】
职责：【一句话】

你是【角色】，只做【一件事】。
工作区：D:\User\Desktop\比赛存档\v1
先读：docs/10_agent提示词/00_一页纸.md → docs/10_agent提示词/03_角色/<角色>.md → 【具体文件/章节】
写域：只写 docs/30_任务卡库/在办/<卡号>.md 和【目标文件】；其余只读
禁止：改冻结区、连车/机、部署、git 提交、装依赖
交付：结论 + 证据（路径:行号）+ 可复跑命令与退出码 + 回滚点；不确定写〔未〕
停止点：交完即停，不自动进入下一轮
```

## F. 小上下文 / 小模型（8k 以内）

```
只读下面这一页，不要展开，不要引用外部知识。回答 3 个问题，每题不超过 50 字。

【粘贴 docs/10_agent提示词/00_一页纸.md】

1. 起点、终点、场地尺寸、时限？
2. 当前最大的技术风险是什么？
3. 哪几个目录绝对不能改？
```

## G. 逐套适用边界

| 模板 | 最小上下文 | 给附件吗 | 什么时候别用 |
|---|---|---|---|
| A 速览 | 4k | 否（内嵌一页纸） | 要它干活时 |
| B 接管 | 32k+ | 同机否 / 异机 L1 | 只问一个事实 |
| C 单卡 | 64k+ | 否 | 目标还说不清时 |
| D 审查 | 64k+ | 被审文件 | 你想让它顺手修 |
| E 子智能体 | — | 否 | 活只有一行（自己做更快） |
| F 小模型 | 4k~8k | 否 | 需要它给证据时（它编不出行号） |

证据：L0/L1/L2 的 token 实测见 `02_发送指南.md` §3；「子智能体共享文件系统、给路径」见旧 `10_提示词模板.md` 模板 E。

## 相对旧版改了什么

1. **事实源换库**：不再点名 `项目现状_20261018.md`/`TEAM_STATUS.md`（已收敛为指针），改为「一页纸 + 现状快照 + AGENTS + 资料索引库」。
2. **产出路径换库**：`_tmp_session/<卡号>/report.md` → `docs/30_任务卡库/在办/<卡号>.md`（卡即报告）。
3. **B 模板复述题更新**：删「三套地图口径」（已进资料库），加「R1 现在什么状态」——这是 10-21 最容易答错的一题。
4. **D 模板第 5 类加「行号漂移」**：多处文档行号已漂（如 `robot.yaml:840` 与手册写的 `:671`）。
5. **新增 G 表**：给出每套模板的最小上下文与禁用场景。
