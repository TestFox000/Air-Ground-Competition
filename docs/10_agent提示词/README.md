# agent 提示词库 · 入口（什么场景发哪份）

## TL;DR（给 agent 看的）

- 这库解决**一件事**：把「要别的 agent 干什么」写成一段可直接复制、贴了就能干活的话。
- 用法：先看 §1 三问决策，再进对应文件照抄；**不要**从零写提示词。
- 最大坑：只贴文件不说产出与验收 ⇒ 回你一篇正确的废话（§5 反模式）。

## 1. 三问决策树

```
① 你只是要对方"知道"这个项目？
   └─ 是 → 00_一页纸.md（L0，2457 字符 ≈1.5k tokens，直接粘）
② 你要对方"接手干活 / 写方案"？
   ├─ 同机或子智能体（能读盘）→ 不给附件，给绝对路径 + 01 模板 B（接管）
   └─ 异机 / 网页版 → 发 L1 七件套（≈33k tokens）+ 01 模板 B
③ 你要对方"改代码 / 深审"？
   └─ 同机给路径；异机发 L2（2.89 MB，**仅内网**）+ 03 角色卡 + 04 场景卡
④ 你要派 DSH 子智能体并行？
   └─ 03_角色/<角色>.md 贴在其 prompt 开头 + 01 模板 E + 05 回报模板
⑤ 你要它按现场/场景干活？
   └─ 04_场景/<场景>.md 整段转交（自带前置检查与验收）
⑥ 你要收它的报告？
   └─ 05_回报模板.md（卡内追加口径，10-21 起）
```

## 3. 三个常用组合（照抄）

1. **最短可用**：`00_一页纸.md` 全文 + 一句「用 300 字复述：起终点/三个风险/四个冻结区」。
2. **派卡干活**：L1 路径（或 7 个附件）+ `01` 模板 B + 模板 C + `03_角色/<角色>.md`。
3. **并行攻坚**：每张卡一份「角色卡 + 场景卡 + 05 回报模板」，写域互不重叠，Lead 只做集成。

## 5. 五条反模式（别这么写）

| 反模式 | 后果 | 改法 |
|---|---|---|
| 「了解一下这个项目」 | 回一篇正确的废话 | 加「产出什么 + 验收命令」 |
| 一次发整仓 / 2.6 GB | 上下文爆、还带凭据 | 只发 L1；代码按需给路径 |
| 「自己找最新文档」 | 它会读到归档旧文 | 点名 4 篇 + 给绝对路径 |
| 「修一下射击」 | 可能直接改冻结区 | 写死写域 + 验收 + 回滚点 |
| 不做复述验收 | 假读懂，动手才暴露 | 先过 `02` §7 的 5 问 |
