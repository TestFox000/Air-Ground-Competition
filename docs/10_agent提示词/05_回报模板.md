# 回报模板（只管跨 agent 转交：摘要 ≤700 字）

## TL;DR（给 agent 看的）

- 本页**只**管「发给上级/别的 agent 的那一段摘要」；**卡内报告结构唯一现行** = [卡库回报模板](../30_任务卡库/模板/回报模板.md) §2 七节，本页不再重复（旧版 8 段表已废）。
- 卡就是报告：在 `docs/30_任务卡库/在办/<卡号>.md` 内追加，不另起 `REPORT.md`（`AGENTS.md` §8.5）。
- 聊天里只放 **≤700 字可转交摘要** + 绝对路径；长日志、逐例表全部留在卡里。
- 最大坑：写「已修复/已优化」而无复跑命令与退出码 ⇒ 按 `工作流v2` §5 直接判未完成。

## 1. 载体口径（一句话，勿展开）

旧三件套 `REPORT.md` + `review.md` + `MANIFEST.json` → 单卡（同一文件走完领卡→写报告→归档）。细则只在一处：`AGENTS.md` §8.5 + [卡库模板](../30_任务卡库/模板/回报模板.md)。

## 2. 可转交摘要（复制填空，≤700 字）

```
【卡号/日期/轮次】
结论：已收口 / 未收口 / 需现场配合（三选一，不许模糊）
本轮唯一假设：
本轮实际改变的变量：无生产改动 / <变量>
基线：HEAD·工作树·被测文件哈希·探针哈希
版本对照：本地 <hash> ｜ 车端 <hash>（不一致必须写）
证据等级：源码 / 离线复现 / 仿真 / 实车 / 历史（选一层，不许混）

核心结果（每条后跟证据）：
- <结论1>（证据：路径:行号 或 命令+退出码）
- <结论2>

复现结论：已复现 / 本用例未复现 / 无效或阻塞
测试：运行 N 套，通过 N，非零 N，未运行 N；失败 ID 及归因（相同/新增/消失/未解释）
门禁：check.py 退出码 + 关键输出
变更：本卡文件清单；冻结区有无；他人改动是否保留
Reviewer：通过 / 打回 + 理由
经验：<现象→处置，一行>（证据：路径:行；无则写〔未〕）
未决问题：
下一轮唯一建议（含需不需要现场配合）：
回滚点：
证据绝对路径：
停止点：已停止，未自动进入下一轮。
```

## 3. 复现结论三态（最容易写糊的地方）

| 态 | 含义 | 反面写法 |
|---|---|---|
| 已复现 | 分支成立 + 契约被违背 + 证据完整（保留非零退出码） | 「测试失败」 |
| 本用例未复现 | 分支成立、断言通过；**不能推广为全部正确** | 「没问题」 |
| 无效或阻塞 | 分支未进入 / 无发布 / 版本不符 / 依赖失败 | 「环境阻塞（其实代码也红）」 |

## 4. 转交什么

| 场景 | 转交 |
|---|---|
| 同机 | 摘要 + 卡文件的绝对路径（对方自行读） |
| 有争议 | 补探针副本、命令、原始 stdout/stderr、相关源码哈希（**不是截图或口头结论**） |
| 异机/网页 | 只传必要证据片段；不发 `.git`、整份 `_tmp_session`、完整历史包 |

## 5. 下一轮派工格式（复核后回填，未填完不自动续跑）

```
继续本项目，但只执行以下新卡：
卡号 / 承接的卡文件路径与 SHA256
复核结论：接受哪些事实 / 驳回哪些推断
本轮唯一目标与假设 / 唯一变量
允许写域与 owner / reviewer 及只读范围
冻结登记要求 / 复用实现与测试
可复跑命令及通过标准 / 回滚点
现场动作：无 / 明确列出动作与人工配合窗口 / 停止条件
完成后仍用本模板回报，并停止，等待下一张卡。
```

## 6. 自检清单

- [ ] 摘要是否 ≤700 字、能否被第三方直接转交？
- [ ] 每条「结论」后是否都有证据？
- [ ] 是否写清了本地 vs 车端版本（最容易混的一条）？
- [ ] 测试是否给了三个分母、未运行项是否列出？
- [ ] 是否出现「已修复/已优化」这类无证据表述？
- [ ] 未决项是否真实（不是「仍有一些问题」）？
- [ ] 回滚点是否可执行（文件路径/反向 diff，而不是「重新部署」）？
- [ ] 是否明确写了「已停止，未自动进入下一轮」？
- [ ] 是否写了「经验」（现象→处置 + 证据），而不是过程流水？
