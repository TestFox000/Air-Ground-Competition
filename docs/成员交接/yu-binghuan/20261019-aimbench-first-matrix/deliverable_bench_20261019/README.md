## 2. 三条定律级发现

1. **延迟×增益 = 失稳边界**：静止/0 延迟下系统优秀（0.18°/1.47°）；注入 267ms 真实视觉延迟后误差爆到 6.5°（RMSE），最大振幅 16-18°——环路增益栈（EMA0.45 + EKF α0.6 + k_sp8）在真实延迟下贴近失稳。**这是「追踪不精准」的定量本质，与云台机构/俯仰（已修）/平滑律概念无关。**
2. **lead 双重补偿实锤**：EKF 内建 267ms 前瞻已吸收约 2/3 注入延迟；叠加 dzbrain lead 0.267 后滞后 455→156ms 但 RMSE 不变（6.49→6.62°）——失稳区里 lead 只改相位不改振幅。**平滑律下 lead_time_s 应降至 ~0.1（只补开火链），或 lead_apply_gain 降 0.3**。
3. **β 影响随延迟翻转**：0ms 时 β0.2 略优（3.11 vs 3.29）；267ms 时 β0.4 减半误差（3.84 vs 6.49）。失稳区的症状管理，非根治。已回滚 β=0.2 保持与日间基线一致。
