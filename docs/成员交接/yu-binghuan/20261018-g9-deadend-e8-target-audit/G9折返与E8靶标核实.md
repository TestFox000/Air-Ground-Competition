## 一、G9 折返为何属"几何死结"

对满舵扫掠硬约束逐拐点实测（`_turn_hits`，模型 R_min=0.243m/0.694 格、半宽 0.10m）：

| 拐点 | 进入 → 离开 | 结果 |
|---|---|---|
| G9 | W → E（掉头/倒车） | 无碰撞 |
| G9 | W → NE / W → N | 撞 **F8** |
| G9 | S → NE / S → W | 撞 **G10** |
| G9 | SW → N / SW → NE | 撞 **F8** |
| D9 | W → N / W → S | 撞 **C9** |
| F9 | W → S | 撞 **E10** |

车从 H9 朝西进 G9 是最省到达朝向，该朝向下除外掉头外所有出口被 F8/G10 挡住；
西绕在 D9 被 C9 封死、南绕在 F9 被 E10 封死；从 H10/F10 侧进入被 G10 切角禁掉。
**因此在不改必经点集合时，G9 掉头是该几何下的最优解。**

已实测并**回滚**的两种尝试（未留下改动）：

- 拼装层折返检测 + 必经点换序（相邻交换 / 任意位置重排）：穷举后所有换序都更差
  （len 44–83、重复格 3–21）。
- `_link_ok` 拒绝 ≥135° 衔接：4 段全面退化（38/39 → 45/49），连干净的两段也新出重复格。

> 二者都在解"如果 E8 是真靶"这一前提下的问题；把 E8 判为误检后问题自然消失。

## 二、E8 靶标核实（实测证据）

1. **形态不符**：从原始视频帧裁出检测框（`evidence/e8_object_*.jpg`）可见，
   E8/E9 一带是一只俯视为同心圆的**蓝色圆桶**，直径 ≈0.74 格 ≈0.26m，
   与场地障碍桶 φ0.25m 吻合；靶标是 0.65m×0.025m 的**立式薄板**。
2. **检测框异常**：283×270 px / 1280×720（占比约 22%×37%），蓝面分类头
   把一大片蓝色物体当成了靶面。
3. **与裁判先验冲突**：`match_params.yaml` 明确「移动靶先验（**全场唯一靶**，
   裁判系统每局固定）… target_track: [D7, E7]」；全场侦察
   （`全场侦察_20261017`，field_scan_2.mp4）检出靶为空。
4. **证据强度弱**：`205245` 的 E8 仅 **2 票**（同帧还散布 E3/D3/G3/H6 单票误检）；
   `091746` 更把官方障碍 **B7/E10 误判为蓝靶** —— 该分类头在本场地上会误检。

## 三、修复（`video_field_recon.py` 靶先验裁决）

裁判固定靶先验优先：视频检出的"静靶"若落在移动靶轨道（D7-E7）一格邻域内，
必属移动靶的误投影/误检 → **剔除并回退移动靶两段式**（`未辨@轨道端 → 确认点`，
车到点近距复判红蓝，`fire_guard` 对未辨靶一律禁火）。
剔除项写入 `route_plan.evidence.targets_reclassified_referee_conflict`，可追溯。

```python
_track_cells = [cell(c) for c in TRACK_DFT]          # D7, E7
def _near_referee_target(name):
    c = cell(name)
    return any(abs(c.col - t.col) <= 1 and abs(c.row - t.row) <= 1 for t in _track_cells)
tgt_reclassified = sorted(c for c in (tgt_blue + tgt_red) if _near_referee_target(c))
```
