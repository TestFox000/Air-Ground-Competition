## 3. 陀螺前馈符号标定（一次性，约 2 分钟）

**为什么必须标**：符号反了前馈会"帮倒忙"——闭环仿真（`aim_ff_calib_sim.py`）
量化过：gain=1 符号正确把画面漂移 RMS 142 → 0，**符号取反则翻倍到 284**。

**规则**（已证）：`gyro_ff_sign = -yaw_deg_sign × sign(rho)`，其中
`rho = d(画面偏差)/dt ÷ 车体角速度`（px/deg）。4 种 IMU/符号组合在仿真中全部匹配。

**步骤**：
```bash
# 车上（前馈先保持关闭 gyro_ff_gain: 0）
python3 gimbal_ff_calib.py
```
1. 让云台锁住一个**静止**目标；
2. 手动/遥控让**车体左右各明显转几秒**（单侧幅度 >30° 最好）；
3. 读日志 `[标定] rho=... ⇒ 建议 gyro_ff_sign=±1`；
4. 写入 `robot.yaml`：`gyro_ff_gain: 1.0` + 该 `gyro_ff_sign`，重启节点；
5. **复核**：前馈已开后再跑一次本节点，`|rho|` 应**显著变小（趋近 0）**＝标定成功；
   若反而变大 → 说明规则方向反了，把 sign 取反。

**回退**：`gyro_ff_gain: 0.0` 即完全关闭。
