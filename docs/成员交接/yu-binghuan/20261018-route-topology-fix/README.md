## 说明

修复现场发现的路线质量问题：路线自交（拐一圈）+ 过心补点重新引入转弯违规。

【问题 1：路线自交】用户实测截图显示 B1 附近来回折返、两段交叉成 X。
- 现象：4 段中 2 段从 38 格膨胀到 51 格、重复踩 5 格；访问行号呈 第8行→第1行→第7行→第3行 的上下折返。
- 根因：plan_route 给未辨靶插确认点时按字母序取第一个候选；靶在 D7 时排序 C7<D6<D8，于是无脑挑中第7行的 C7，把该点硬塞进南北动线中间，逼出折返。
- 修法：确认点改按连通性择优（空闲正交邻格多者优先，同分按格号）。靶在 D7 时选出 D8，正好落在车流来向上。

【问题 2：过心补点制造转弯违规】
- 现象：ensure_mine_center_pass 插入的过心穿越点自身成为新拐点，却从未做转弯可行性检查。实测 205411：装配输出 38 格违规=0，ensure 后 39 格违规=1（C3 补点 C4 后 135° 转向扫到障碍 D5）。
- 修法：把可行性判定抽成单一函数 _turn_hits()，规划层复核、出图复核、补点门控三处共用同一判据；ensure_mine_center_pass 新增 turn_model 参数，补点前先验新拐点，不过则放弃补点（该雷退化为拐点，与既有尽力而为语义一致）。

【效果】
205245 39格 dup=1（前后同）；205411 51格 dup=5 → 38格 dup=0；205906 39格 dup=1（前后同）；091746 51格 dup=5 → 38格 dup=0。
4 段全部：转弯可行性通过、排雷 8/8、零穿障；环路与自交消失。

【入库工具修正】Gitee 对不存在的深层路径返回空列表而非 404，push_deliverable.py 已兼容。
