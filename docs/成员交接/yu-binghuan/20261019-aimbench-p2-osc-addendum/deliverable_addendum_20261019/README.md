## 1. P2 des 连续推进：台架证伪（回滚）

- 改动：smoothTrackStep 内 `des += ekf_v/k_pt·dt`（100Hz 连续推进，消 30Hz 锚定锯齿）
- 实测：rail@267 RMSE **7.33°**（基线 6.49°）——**更差**。机理：ekf_v 是瞄准误差速度（含云台自身运动分量），连续推进 = 给本已失稳的环路再加一级正反馈。源码已回滚并上传车端（待编译）。
- 正确版本（后续项）：世界系速度 v_world = ekf_v + 云台反馈速度（camemo Speed_1×k_pt），且须在环路先稳（P1）之后才有意义。

## 2. 振荡滞后分解（rail@267 基线数据的定量机制）

实测振荡：周期 1.44s（**0.70Hz**），振幅从 ±2°（0-4s，EKF 未收敛）持续增长到 ±15°（slew 限幅兜底的极限环）。0.70Hz 对应总环路滞后 1/(2f) = **0.714s**，账目分解：

| 环节 | 滞后 | 可控性 |
|---|---|---|
| 注入视觉延迟 | 267ms | P0 det 治理可砍 |
| EKF 速度收敛 dt/β（33ms/0.2） | 165ms | **β 旋钮** |
| 内环斜坡 1/k_sp（1/8） | 125ms | **k_sp 旋钮** |
| 执行器+串口+反馈 | ~90ms | 硬件 |
| EMA(0.45) | ~40ms | 次要 |
| 合计 | ≈0.69s ✓ | |

三个推论：
1. β0.4 在 267ms 下更优（3.84° vs 6.49°，矩阵 #5）**有机制解释**：β 抬倍砍 80ms 滞后——失稳区里 β 是减滞后旋钮，不是噪声旋钮
2. **α 0.6→0.45 原计划撤销**：降 α 加滞后，延迟失稳区雪上加霜（幸未上车浪费轮次）
3. 注入的 267ms 只占总账 ~37%——环路自身 ~430ms 滞后全部可攻击
