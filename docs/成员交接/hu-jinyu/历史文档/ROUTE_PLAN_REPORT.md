## 二、规划结果

### 2.1 结构最优路线（格级连通，36 步 = 12.60 m）

```
M11  M10  M9   M8   M7   L7   K7   J7
I7   H7   G7   F7   E7   D7   C7   C6
D6   E6   F6   G6   H6   I6   J6   J5
J4   J3   J2   J1   K1   L1   M1   M2
M3   N3   N4   N5   N6
```

**结构解读**（4 段）：

| 段 | 走法 | 说明 |
|---|---|---|
| ① 北上 | M11 → M10 → M9 → M8 → M7 | 东条带 M 列直上（无人机在 N8 不在 M8，所以 M8 可走） |
| ② **西穿 K7 门** | M7 → L7 → **K7** → J7 | 第一次穿门（东西向） |
| ③ 西场绕行 | J7 → … → C7 → **C6** → … → J6 → J5 … J1 | 在 **col C 越过隔离线**（C 不在 D..N 范围内，边是开的） |
| ④ **东穿 K1 门** | J1 → **K1** → L1 → M1 → M2 → M3 → N3 → N4 → N5 → N6 | 第二次穿门，然后南下到终点 |

**穿门 2 次**（K7 + K1）—— 与拓扑结论"两个门缺一不可"一致。

### 2.2 ★ 8 个转角中，5 个物理不可行

| 转角 | 单圆弧净空 | 原地转向净空 | 判定 |
|---|---|---|---|
| M7 | **+6.9 cm** | +6.5 | ✅ |
| **C7** | **−17.16** | **−1.1** | ❌ 紧邻障碍 C8 |
| C6 | +35.3 | +33.9 | ✅ |
| **J6** | **+0.02** | **−1.1** | ❌ ★ 差 0.48 cm |

## 三、根因（定量）

```
最小转弯半径 R        = 26.0 cm
车体对角半径          = hypot(17.2, 7.0) = 18.6 cm
单圆弧扫掠半径        = R + 对角 = 44.6 cm  → 扫掠圆直径 89.2 cm
原地转向扫掠半径      = 对角   = 18.6 cm  → 扫掠圆直径 37.2 cm
格边长 / 走廊宽       = 35 cm
```

| 冲突 | 需要 | 场地给 | 结论 |
|---|---|---|---|
| 单圆弧转弯 | 89.2 cm | 35 cm（单格） | 除空旷西场外基本不可行 |
| 原地转向 | 37.2 cm | 35 cm（单格） | **只差 2.2 cm** |

**瓶颈转角 J6 净空 +0.02 cm**（要求 ≥0.5 cm）—— **差不到 0.5 cm**。

### 容差敏感度（实测）

| 转弯最小净空容差 | 结果 |
|---|---|
| 0.5 cm（`turn_min_clearance_cm` 默认） | ❌ 不可达 |
| 0.0 cm | ❌ 不可达 |
| 放宽到 −25 cm（允许压边） | ❌ 仍不可达 |

> `field_grid.hpp` 注释明确：**"取 0 → 只要不穿插就通过（正确的能否转判据）"**。
> 但即使取 0，本图仍不可达 —— 说明不是"保守余量"的问题，而是**几何真的不够**。

## 五、工具

| 文件 | 作用 |
|---|---|
| `tools/plan_route.py` | 忠实复刻 `FieldGrid::findPath`：同边模型、同起始航向、A\* + 转弯可行性 + 原地转向判据 + 4 级回退；输出路径 / 转角表 / 校验 / JSON / PNG |

```bash
python3 tools/plan_route.py                    # 路径 + 转角表 + 校验
python3 tools/plan_route.py --png route.png    # 线路图
python3 tools/plan_route.py --json             # 机器可读
python3 tools/plan_route.py --clearance 0.0    # 改转弯净空容差
```

## 六、一句话结论

**结构最优路线是 36 步 / 12.60 m，穿 K7 与 K1 两个桥洞门，在 col C 越隔离线。**
**但按车端现行转弯几何（扫掠半径 44.6 cm vs 单格 35 cm），转弯感知规划在这张图上无解；
最接近通过的是 J6 转角，只差不到 0.5 cm 净空。**

**最可能的症结是隔离线行号**（P0）—— 若它实际在 K7↔K8 之间，
则穿门不需要 90° 转弯，整张图的可行性会完全改变。建议现场量一次。
