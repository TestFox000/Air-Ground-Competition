## 0. 通用约定

| 项 | 约定 |
|---|---|
| Python | **3.10 兼容**（车上 3.10.12，本地 3.12 仅用于跑测试）；用 `from __future__ import annotations` |
| 依赖 | `core/ route/ pursuit/` **禁止** import rclpy（纯 Python + 可选 numpy）；只有 `tasks/ io/ main.py` 碰 ROS |
| 坐标 | 一切几何走 `dzbrain/core/geometry.py`：格↔米、格单位、角度、`Pose`。**禁止**另写一套换算 |
| 配置 | 一切参数走 `Config`（点号键）：`cfg.get("pursuit.wheelbase_m")`。**禁止**硬编码魔法数字 |
| 测试 | `src/dzbrain/tests/test_*.py`，**纯脚本**（无 pytest）：`python src/dzbrain/tests/test_x.py` → 打印 `PASS/FAIL` 行，全过 exit 0，有失败 exit 1 |
| 注释 | 中文，与项目风格一致；不变量用 `★` 标注，坑用 `⚠️` 标注 |
| 风格 | 类型注解齐全；dataclass 用 `frozen=True`（跨线程共享的值必须不可变） |
| 禁止 | 改别人的文件；改 `core/`、`route/model.py` 的既有签名；引入新第三方依赖 |

## 1. `route/parser.py`（A 线）

    例：'k9 ' -> 'K9'；'r:b5*' -> 'R:B5*'；'N5,Y' -> 'N5,y'"""

def parse_token(token: str) -> dict
    """单 token -> {'block','reverse','shoot','scan','heading','group','raw'}；
    非法 token 抛 ValueError（不要静默返回空）。"""

def parse_mission(tokens, *, shoot_planner=None, name="mission") -> Route
    """token 列表 -> Route（route/model.py 的 Route/Waypoint/RouteBuilder）。
    语法（与旧实现兼容，见 survey §3）：
      - `K9`                普通航点
      - `G10*` / `G10:SHOOT_STOP` / `G10:SHOOT`   射击停站
      - `F2:SCAN_STOP` / `F2:SCAN`                纯扫描停站
      - `R:B5`              倒车到位；`R:B5*` 合法（R: 在前、* 在后）

    去重：相邻同格且 reverse 相同 → 合并（射击/扫描标记取并集）；相邻同格但 reverse 不同 → 不合并"""

def parse_reset(spec: str) -> tuple[str, float]
    """'N10,y' -> ('N10', yaw)。yaw 用 geometry.heading_token_to_yaw"""

def format_route(route: Route) -> list[str]
    """Route -> token 列表（回写 robot.yaml 用）。必须能 `parse_mission(format_route(r))` 往返等价（除朝向规范化）"""

## 2. `route/validate.py`（A 线）

```python
@dataclass(frozen=True)
class Issue:
    level: str      # "error" | "warn"
    code: str       # 稳定编号，如 "R005"（测试与文档引用它）
    msg: str

def validate_route(route, *, map_cfg=None, cfg=None, cross_candidates=None) -> list[Issue]
def summary(issues) -> str   # 人类可读汇总（含 error/warn 计数）
```

必查项（每项一个稳定 code，**给证据数值**）：

| code | 检查 |
|---|---|
| R001 | 路线为空 / 少于 2 点 |
| R002 | 含非法 token 或越界格名 |
| R003 | **挡板硬约束**：D~N 列不得跨越第 6/7 行边界（A/B/C 列可跨） |
| R004 | 踩到障碍格 |
| R005 | 雷覆盖 ≠ 8（从 `map_cfg['mines']` 读） |
| R006 | **靶被覆盖**：至少存在一个射击停站点，它到靶格的距离落在 `[shoot_distance_min, shoot_distance_max]`（默认 0.20/0.45 m）。靶格本身不要求是航点（现场是从 G10* 打 G11 靶） |
| R007 | 两个半场各需一次 K 列穿越（下半场 row7~11 向西、上半场 row1~6 向东） |
| R008 | 穿洞格不在候选集合（`cross_candidates`，默认 `cfg` 的 `route.cross_lower/upper_candidates`） |
| R009 | **入洞段必须严格水平直穿**：`L{r}/J{r} → K{r}` 这一段与 K 列的穿越方向夹角 < 10°（斜切会撞侧壁，readme【四】13） |
| R010 | 相邻重复点（应已被 parser 去重） |
| R011 | 单段长度 > 2.5 格（疑似漏点）或 < 0.02 m（重复点） |
| R012 | **U 形绕行**：路线必须经过 A/B/C 列（否则没绕过 D6~N6/D7~N7 隔板） |
| R013 | 射击停站点距靶不在 `[shoot_distance_min, shoot_distance_max]`（缺省 0.20/0.45 m） |
| R014 | 倒车段占比 > 30%（提醒，非错误） |

## 3. `pursuit/path.py`（B 线）

```python
@dataclass(frozen=True)
class Projection:
    seg_index: int; t: float; x: float; y: float
    s: float; dist: float; seg_length: float; seg_heading: float; passed_end: bool

class Path:
    def __init__(self, route: Route) -> None
    @property total_length: float
    @property segments(self) -> tuple[tuple[float, float, float, float, float, float], ...]
        # 每段 (x0, y0, x1, y1, length, heading)
    def project(self, x: float, y: float, *, s_hint: float | None = None,
                window_m: float = 0.60, allow_backward: bool = True) -> Projection
        """★ s_hint 给定时只在 [s_hint-window_m, s_hint+window_m] 内搜索（O(窗口)，防路线自交误锁）；
        未给定时全量搜索。★ allow_backward=False 时索引只前进（旧行为），True 时允许回退（倒车段必需）。
        末点之后投影到末段且 passed_end=True。"""
    def point_at(self, s: float) -> tuple[float, float, int]
    def remaining(self, s: float) -> float
    def segment_is_reverse(self, seg_index: int) -> bool
    def corner_angle_deg(self, seg_index: int) -> float    # 本段与下一段夹角（度，0=共线）
    def heading_at(self, s: float) -> float
```

性能要求：给 `s_hint` 时 `project()` 复杂度只与窗口内段数有关 —— 测试里用 500 点路径断言
每拍投影耗时 < 100 µs（本地 3.12 实测值作参考，测试用宽松上界）。

## 4. `pursuit/lookahead.py` + `pursuit/controller.py`（B 线）

```python
@dataclass(frozen=True)
class LookaheadPoint:
    x: float; y: float; seg_index: int; s: float; clamped_to_vertex: bool

def find_lookahead_point(path: Path, proj: Projection, ld: float, cfg) -> LookaheadPoint
    """① 从投影点沿路径按弧长 ld 前进（可跨段）；② 若本段与下一段夹角 >
    cfg.get('pursuit.lookahead_corner_angle_deg') 且距顶点 < cfg.get('pursuit.vertex_clamp_m')
    → 钳到顶点；③ 接近末点时钳到最后一点（不越界）。"""

@dataclass(frozen=True)
class PursuitCommand:
    linear_x: float; steer_deg: float; curvature: float
    speed_reason: str; reverse: bool

def compute_command(pose, path: Path, proj: Projection, cfg, *, reverse=False,
                    last_steer_deg=None, dt=0.02) -> PursuitCommand
    """★ 舵角（**度**，正=左转，与下位机契约一致）：
        α = 目标点相对车体前向的方位角；δ = atan(gain · 2L·sinα / max(ld, lookahead_floor))
        gain = cfg.get('pursuit.curvature_gain')（1.0=教科书式；0.5=旧行为等价）
        再：限幅 ±pursuit.max_steer_deg、速率限幅 pursuit.max_steer_rate_deg_s × dt、
        倒车段乘 pursuit.reverse_steer_sign
      ★ 速度：min(cruise, sqrt(lat_acc_max/|κ|), 停站减速, 转角减速, speed_scale)
        再 × pursuit.speed_quant_comp；倒车取负并乘 reverse_speed_ratio
        下界 pursuit.min_speed_mps"""

def speed_profile(*, curvature: float, dist_to_stop: float | None, corner_dist: float | None,
                  speed_scale: float, cfg) -> tuple[float, str]
def brake_command(cfg) -> PursuitCommand      # 零速刹车（linear_x=0, steer_deg=0, reason='brake'）
```

## 5. `tools/sim_pursuit.py` + 包内 `dzbrain/tools/sim.py`（C 线）

```python
# dzbrain/tools/sim.py
@dataclass
class SimConfig:
    dt: float = 0.02              # 控制周期（50 Hz）
    cmd_latency_s: float = 0.06   # 指令到执行延迟
    speed_scale_err: float = 0.0  # 里程计比例误差（模拟 ticksPerMeter 偏差，+0.18 = 超报 18%）
    yaw_drift_deg_per_min: float = 0.0
    pos_noise_m: float = 0.0
    anchor_on_arrival: bool = True
    anchor_radius_m: float = 0.12

@dataclass
class SimResult:
    t: list[float]; x: list[float]; y: list[float]; yaw: list[float]
    v: list[float]; steer: list[float]
    truth_x: list[float]; truth_y: list[float]   # 真实轨迹（不含里程计误差）
    metrics: dict

def run_sim(route: Route, cfg: Config, sim: SimConfig = SimConfig()) -> SimResult
    """自行车模型 + 纯追踪闭环：
       truth: x += v·cos(yaw)·dt, y += v·sin(yaw)·dt, yaw += v/L·tan(δ)·dt
       belief: 用 speed_scale_err / yaw_drift / noise 污染后作为控制器输入（模拟里程计误差）
       到位吸附：‖belief-position − waypoint‖ < anchor_radius_m 时把 belief 锚到格心（模拟 FixTask L2）"""

def write_csv(result: SimResult, path: str) -> str
def write_svg(result: SimResult, path: str, route: Route) -> str   # 手写 SVG（不依赖 matplotlib）
```

CLI（`dzbrain/tools/sim_cli.py`，另在工作区 `tools/sim_pursuit.py` 放一个薄包装）：

```
python tools/sim_pursuit.py --config config/robot.yaml --route config_route.txt \
       --out-dir artifacts/sim --speed-scale-err 0.18 --yaw-drift 0.5 --anchor
```
输出：控制台指标汇总 + `traj.csv` + `traj.svg`；**全程无异常，退出码 0**。

指标至少含：完成/未完成、总时长、**横向误差 RMS/max**、到达点超调、最大舵角与最大舵角速率、
路径长度比（实走/路线）、锚定次数、末点位置误差。
