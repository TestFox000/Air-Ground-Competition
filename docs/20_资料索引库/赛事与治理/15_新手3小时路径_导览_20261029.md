# 新手 3 小时上手路径（6 个 15 分钟单元 + 30 题自测卷）

> **这篇给谁看**：刚接手这台车、基础一般，手上只有这三篇新写的门（调参[12](../车端/12_可调参数速查_按场景.md)、链路[13](../车端/13_模块协调与链路展开.md)、日志[10](../运维与排障/10_日志阅读课_新手版.md)）和一个终端，想在 3 小时内做到两件事：**靠调参达成目的**、**靠日志定位问题**。
> **它不是什么**：不教原理（那三篇已写完，本篇只做"读哪节 → 做什么 → 答哪题"的编排），也不是实车 runbook（[09_明早全流程SOP](../运维与排障/09_明早全流程SOP_20261029.md)）。
> **一句话用法**：按单元 1→6 顺着走，每单元 15 分钟：读 7~10 分钟 → 敲一条命令 3 分钟 → 答 5 题 2 分钟。**6 单元走完 = 30 题全部答过一遍**。

## TL;DR

1. 路径是 **6 个 15 分钟单元**，每单元固定四件套：**读哪几节（带行号）→ 做哪个实验（一条命令 + 预期输出）→ 答哪组题（5 题）→ 过关判据（能不看文档说出来）**。
2. 30 题 = **调参 10 / 日志判读 10 / 链路 10**，每题都能回溯到那三篇的正文行号（§3.2 三张答案表逐题给出处）。
3. 全部单元 **只读**：不连车、不改 `config/`、不起 ROS、不 commit。唯一的写动作是"在 DSH 里贴一段试卷 spec 自测"。
4. 顺序不能跳：**先认人（单元 1）→ 再改参数（2、3）→ 再读日志（4、5）→ 最后串链路（6）**。反过来做（先读日志再认模块）会把"对面没发东西"误判成"代码算错了"——这是本月最费时间的误判来源（[10](../运维与排障/10_日志阅读课_新手版.md) §0）。
5. Windows 上所有 python 命令**必须带 `PYTHONIOENCODING=utf-8`**，否则 GBK 控制台把 `⚠`/`↔` 打成 UnicodeEncodeError，看着像程序崩了（[12](../车端/12_可调参数速查_按场景.md):664）。

## 2. 逐单元详表

### 单元 1 · 先认人：谁在车上（15 min）

**为什么第一个读它**：不知道"谁在写、谁在收"，后面所有日志都读不懂——日志里每一行都有一个负责人。

**读**：[13](../车端/13_模块协调与链路展开.md) §1.1 进程内线程表（:37-54）+ §1.2 外部节点表（:56-67）。只读这两张表，别展开 §2。

**实验 E1**（数黑盒键，确认"线程靠黑盒说话"）

```bash
cd D:/User/Desktop/比赛存档/v1
grep -c '^P_[A-Z_]* = ' dzrobot_v2/src/dzbrain/dzbrain/core/blackboard.py
grep -n 'P_FIELD_LAYOUT\|P_POSE \|P_SAFETY' dzrobot_v2/src/dzbrain/dzbrain/core/blackboard.py | head -5
```

**预期输出**（2026-10-29 实跑）：第一行 `21`；下面能看见 `P_POSE`（信念位姿）、`P_FIELD_LAYOUT`（无人机布局）、`P_SAFETY` 三条定义。
**读到什么就算会了**：黑盒键是**字符串常量**，拼错一个字母就是一个"永远读不到的值"——这是线程间"查不到别人的值"的第一嫌疑（[13](../车端/13_模块协调与链路展开.md):32）。

**答哪组题**：第 1 组（`01_link_who.json`，链路 5 题）。

**卡住怎么办**：分不清 Tracker 与 TrackerTask？记住日志名与注册名可能不一致——`SafetyTask` 注册名是 `"Safety"`（[13](../车端/13_模块协调与链路展开.md):52）。

### 单元 2 · 改参数怎么才算生效（15 min）

**为什么读它**：新手第一个动作永远是"改一个键试试"，而最大的坑是**改完没生效还以为生效了**——因为同一含义的键在 yaml 里有两处。

**读**：[12](../车端/12_可调参数速查_按场景.md) §0.1 改完怎么生效（:25-34）+ §0.2 迁移表（:36-54）。重点记一句：**新键在 yaml 里存在 ⇒ 用新键；缺失 ⇒ 才用旧键的迁移值**。

**实验 E2**（G1 配置自检，= V1 验证级）

```bash
cd D:/User/Desktop/比赛存档/v1/dzrobot_v2
PYTHONIOENCODING=utf-8 python tools/config_selfcheck.py --config config/robot.yaml --map config/map.yaml
```

**预期输出**（实跑）：`结论：error 0 / warn 0  ✅ 通过`，退出码 0。
**读到什么就算会了**：判据是 **error 0 ∧ warn 0**，不是"退出码 0 就算过"（[12](../车端/12_可调参数速查_按场景.md):669）。改完不跑这一条 = 拿现场时间当测试。

**答哪组题**：第 2 组（`02_param_effective.json`，调参 5 题）。

**卡住怎么办**：改完现象没变？先回 §0.2 看是不是"该改另一段"（旧核 `path_executor.*` vs 新核 `/dzbrain` 段），再进单元 3 查黑名单。

**为什么读它**：这三篇里**最省钱的一节**。12 条键"改了根本不生效"，每条都给了证据行——省下的是现场反复试错的那半小时。

**读**：[12](../车端/12_可调参数速查_按场景.md) §0.3（:56-73），12 行一张表，一条条看，别跳。

**实验 E3**（亲眼看见"两处真源"）

```bash

```

**预期输出**（实跑 3 行）：:50 `+10.0`（云台段，**真源**）、:64 一条注释、:871 `+10.0`（另一段对齐值）。
**读到什么就算会了**：① 同名键在 yaml 里出现**不止一次**，谁生效要靠"谁被代码读"判；② 行号会漂——**永远现 grep，别背行号**（本篇引的行号只对 2026-10-29 这份树成立，同 [13](../车端/13_模块协调与链路展开.md):19 的口径）。
