## 6. 假绿禁例（谁违反谁返工）

1. 只看 harness 打印的"通过"字样，不看 RC（RC=2/5/6 都算红）。
2. 用 --filter / 单套绿代替全量，然后写"回归通过"。
3. 把"跑不起来"（无 ROS / 缺依赖 / 权限）记成"跳过不算红"。
4. 改断言让套件变绿，却没说清"是断言过时还是代码错"。
