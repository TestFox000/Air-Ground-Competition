每卷结构：

    §1 卷首判读（三句话：发生了什么 / 为什么这么走 / 留下什么）
    §2 分周小节（### W42（10-12~10-18）…）——周是节，不是文件
    §3 大事表（时间 + 事件 + 一句话结论 + 〔条目ID〕/证据）
    §4 留下的东西（提炼进库的篇名 + 反向指针）

**为什么阶段为卷而不是一周一文件**：

| 事实 | 数字 |
|---|---|
| 归档卡总量 | 16 篇，其中新卡 11 张 |
| 分布 | 10-22 ×1、10-23 ×4、10-24 ×6 → **全挤在最后 3 天** |
| 会话日志 | 38 篇，全在 10 月 |
| 早期 | 09 月有些周**零活动** |

按周切 = 一堆空格子 + 几个超厚格子，而且大事件（10-18 并入改名 412 处）会被劈成两半。

**为什么编年体只做索引**：判断值只留 ID，正文在正典。

| 真源 | 编年体写法 |
|---|---|
| 数字速查.yaml（52 条） | 〔数-12〕 |
| 症状索引（52 条） | 〔症-07〕 |
| 决策台账 D-xxx | 〔D-033〕 |

改一个参数只需改 yaml 一处 → **不会产生「史记说 0.26 s、yaml 说 0.067 s」的新异文**。

**时间线.md 必须降级**：拆完后写 status: 历史 + 取代: 编年/00_总纲.md，**不能两个都留现行**。
