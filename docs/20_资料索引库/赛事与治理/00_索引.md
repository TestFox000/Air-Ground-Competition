## 3. 口径纪律（本册强制）

1. **同一事实多版本一律并列**（A 版 / B 版 + 各自出处），不许二选一、不许合并成假结论。
2. **官方文本 vs 队内口径分开**：来自队长澄清/配置文件/队内文档的标〔档〕并写来源；标「赛规」的必须能指到赛规原文行。
3. 查不到就写〔未〕，不编造数字；推导值标〔推导〕。
4. 本册与代码/现场冲突时**以代码和现场为准**，并回来改本册（改完更新本文件日期）。
