# 决策台账摘编（D-001 ~ D-030）

## TL;DR（给 agent 看的）

- 这是**防开倒车**的表：已裁决的事不得重开。要重开先答三问：**新证据 / 影响面 / 不重开的代价**。
- 台账规则：**不得删除旧条目**；推翻时旧条改「已推翻」并追加新条；结论必须 24h 内落账。
- 现状：30 条裁决中 **27 条有效**、**2 条被部分推翻**（D-015②、D-017②）、**1 条已归档**（D-021）。
- 最常被误引的三条：D-012（引擎只认 tour）、D-019（部署唯一入口）、D-023（13 红处置，L2/L3/L5 禁止重钉）。

## 3. 翻案三问（想推翻 D-xxx 时逐条答）

1. **新证据是什么？**（命令 + 输出 / 实测数据 / 新源码）旧结论的哪条依据已不成立？
2. **影响面？**（哪些冻结区文件 / 哪些回归套件 / 车端是否要重新部署）
3. **不推翻的代价？**（量化：多少时间、多少分、多少碰撞风险）

⇒ 结论写回台账：旧条改「已推翻」，追加新条，**不删旧条**。
