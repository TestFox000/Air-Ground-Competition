## 4. 口径与已知局限（不隐藏）

1. **标题 ≠ 内容**：本扫描只看标题归一化后能否在库里搜到，**没有读 489 篇正文**。一篇标题搜不到的文档，正文结论可能已被别的篇覆盖；反之亦然。要真正定「该不该入库」必须读正文 —— 这正是 P3 提炼的活。
2. **归一化会过度合并**：`control_review` 把 3 篇不同日期的评审稿合成一个词，可能掩盖它们之间的差异；`README_` 前缀去除后 `README_驯化指南` → `驯化指南` 是有意为之，但 `00_README` / `docs__README` 会变成 `readme` / `docsreadme`。
3. **英文整词退化**：doc_search 对英文词先做整词边界匹配，0 命中才退化为子串；本扫描沿用了该行为，所以 `airgroundinterface` 这类长词可能因边界不匹配而被判缺口（实际库里可能有 `air_ground_interface`）。
4. **语料只含两处**：只扫了 `20_资料索引库` 与 `00_项目总览/编年`，没扫 `10_agent提示词` 与 `30_任务卡库`（后者是过程区）。若某词只在这两处出现，会被判成缺口。
5. **建议列是启发式**：按词义粗分，未与各册 owner 对齐，**不是裁决**。
