# 沿革：09-27 到 10-18（三段）

## TL;DR（给 agent 看的）

- 三段主线：**摸官方框架（09-27~10-01）→ 循迹 v1/v2/v3 收官（10-02~10-12）→ 空地协同闭环（10-14~10-18）**。
- 最值钱的不是结论而是**两个根因的定位方法**：把"车不听使唤"先拆成**控制环 vs 坐标系 vs 上游帧**，再逐个用实测排除。
- ⚠️ 旧稿的错误结论已纠正：**画圆不是"增益/前视调参问题"**，而是**恒定朝向断言偏置**；调参一路被实测排除（09-30）。
- 三条留下的结构性事实：断言偏置可修（68.6° → 对齐 45°/90°）、标定 3280 冻结、血统切到 dzbrain 才有"单出口限速"结构。

## 三条结构性结论（今天仍在起作用）

| # | 结论 | 为什么重要 |
|---|---|---|
| 1 | **朝向断言偏置是系统性常量**，不是随机抖动 | 解释了"同样的 PID 在两台车上表现不同"；也解释了为何调参永远调不好 |

| 3 | **血统切到 dzbrain（8 线程 + 唯一出口限速）** | 才有 D-025 那处"+14 行钳位"能一次修好限速缺陷的结构基础 |
