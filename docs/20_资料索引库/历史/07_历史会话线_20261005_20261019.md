### 4.1 「0 发与 PID 无关」的判据（方法论，最该复用的）

云台全程 **403/403 帧 `AIM_IDLE`**、开火权限 0 次；两个射击停站在 `s=10.15 / 15.05`，而车在 `s≈1.3` 就跑飞 —— **从未到达停站，`kp12/ki1.1/kd1.8` 一次都没进控制环**（③:54）。

## 7 这四条线今天还能用的六条

1. **先证明"信号进了环"再调参**（§4.1）—— 否则是最贵的时间浪费。
2. **自愈/relock 类机制必须有"可信闸"**，只判"更近一点"会接受 +12.82 m 错腿（§4.2）。
3. **阈值要大于执行器滞后**：3 cm 停车阈值 < 4.4 cm 滑行 ⇒ 必然越界 2.3 cm（§4.2）。
4. **一份代码只能有一个真源**：`file:` + `node_modules` 双副本 = 假绿（§3）—— 与今天"本地唯一真源"同一病根。
5. **"装了"≠"激活"**（bundles）、**"进程在"≠"在算实时数据"**（FAST-LIO 落后 16.6 分钟仍在出图）（§3、§4.3）。
6. **并发改同一文件 = 版本漂移**（§2 的 `f4151410→6389ef2d`）—— 写域独占不是形式主义。
