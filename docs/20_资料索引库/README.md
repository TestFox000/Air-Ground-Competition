# 资料索引库 = 本项目「百科全书」

## TL;DR（给 agent 看的）

- 这里是**查事实**的地方：不知道就翻这里，不要全仓 grep、不要问人。
- **提交规范**：完成任务后按 `type(scope): 中文摘要 [卡号]` 提交并双推 github+gitee，正文带「检查」段；type 限 `feat/fix/docs/test/chore/refactor/perf/build/ci/sync`，禁止裸提交（无前缀）。详见 AGENTS.md §11。
- 四种查法：①**知道名字**（文件/模块/参数）→ §3 专题导航；②**只知道现象**（车不动、激光不亮、ROS 看不见）→ §4 症状索引；③**要数字**（多少 mm、多少 Hz、多少套）→ §2 数字速查；④**只记得关键词/记不清在哪篇** → `python docs/_工具/doc_search.py "激光不亮"`（全库 top-N + 命中片段，2 s 内）。
- 每条事实都带出处（`路径:行号` 或「文件 + 章节」）；标「未核实」的就是**没人验证过**，别当结论用。
- 旧路径原文在 `docs/history_cache/01_旧文档归档/<原路径>`；正文里出现的旧路径一律按此规则取文件。

## 5. 高频坑（Top 12，全量见各分册）

1. `cam_viewer` 以 20 Hz 发全零 `/pursuitAngle`，底盘每帧更新 ⇒ 车不动。跑车前必 kill。

4. `robot.yaml` 顶层裸键 ⇒ 三节点 abort（地图放 `config/map.yaml`）。
5. `det_node` 无 X 时 `cv::imshow` 崩 ⇒ `draw:false`。
6. `dzrknn_dataprocess` 的可执行文件叫 `dzactuator_node`，与底盘包同名。
7. BEST_EFFORT 发 → RELIABLE 收 = 静默 0 条，但端点计数各为 1。
8. 第七图有**两版识读**（差 3 雷 4 障），引用必写版本。
