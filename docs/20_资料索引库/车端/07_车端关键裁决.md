## 三个最常被违反的点

1. **拿 hybrid 当「更快方案」**：D-021 已判无净收益且归档；再说「换成 hybrid 能提速」= 重开 D-021，需新证据（更大图集全绿 + 留出集胜出）。
2. **把 13 红说成「全绿」或把红全重钉**：D-023 明确 A 类 3 项是真缺陷、L2/L3/L5 禁止重钉；重钉 = 掩盖缺陷。
3. **实验直接改 `config/**` 默认值**：D-008 冻结区，实验只能进 `_tmp_session/` 或 feature flag；改默认 = 让车端下次部署即变行为且无法归因。

## 翻案三问（照抄台账模板）

1. **新证据是什么？**（命令 + 输出 / 实测数据 / 新源码）——旧结论依据哪一条已不成立？
2. **影响面**：动到哪些冻结区文件、哪些回归套件、车端是否要重新部署？
3. **代价**：不推翻继续用，损失是什么（量化）？
