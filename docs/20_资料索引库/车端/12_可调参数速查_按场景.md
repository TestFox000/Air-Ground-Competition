# 可调参数速查（按场景）

> **这篇给谁看**：刚接手这台车、想在 `robot.yaml` 里改一个参数，却不知道「改哪个、改了会怎样、改完怎么证明没改坏」的人。
> **它不是什么**：不是原理教材（那是 [02_循迹与控制](02_循迹与控制.md)、[04_定位与安全](04_定位与安全.md) 的活），也不是部署手册（[05_配置与部署](05_配置与部署.md)）。
>
> 两个视图：**视图 A（§1）按段全表** —— 想知道「这个键干什么」时查；**视图 B（§2）场景反查** —— 想知道「我想让车 ___ 该改哪个键」时查。**新手从 §2 进。**

## TL;DR

1. `robot.yaml` 现役 **256 个有效键**（18 段）；另有 **117 个键只登记在 `core/config.py` 的 SCHEMA 里、没写进 yaml**（生效值 = 代码默认，§3 一页看完）。
2. 同一个量常常**两处真源**：`path_executor.*`（旧核）与 `/dzbrain` 段（新核）同名不同段；改一处另处不动 = 改了没用（§0.2 迁移表）。
3. 有一批键**改了根本不生效**（拼写不符 / 无人读取 / 真源在别段）：§0.3 列 12 条并给出证据行号。**动手前先看黑名单。**
4. 验证阶梯：**G1 配置自检 → sim 闭环 → route 门禁 → 实车**（命令见 §4；每个参数表最后一列写清了这个键必须走到哪一级）。
5. 铁律：**一次只改一个变量**，改完留备份（`cp config/robot.yaml config/robot.yaml.bak_<日期>`）。

## 0. 三个必须先知道的事

### 0.1 改完怎么生效

| 动作 | 命令（车端） | 适用段 |
|---|---|---|
| 只重启云台 | `~/dzrobot/tools/restart_node.sh gimbal` | `/dzrknn_dataprocess` |
| 只重启循迹 | `~/dzrobot/tools/restart_node.sh path` | `path_executor`（legacy） |
| 整套重启 | `~/dzrobot/start_all.sh restart` | `/dzbrain`、`/dzactuator`、相机 |
| 体检参数真喂进去了没 | `~/dzrobot/tools/healthcheck.sh` | 全段（含三条硬不变量） |

**为什么不重新编译**：`robot.yaml` 是纯参数文件，节点重启即读新值。但**类型必须对**——`45` 与 `45.0` 在 ROS 里是 int/float 两回事；`core/config.py` 的 SCHEMA 会按类型校验，不符在 G1 直接报 error（这就是它存在的意义）。

### 0.2 一份键、两处真源：迁移表（最容易踩的坑）

`src/dzbrain/dzbrain/core/config.py:721` 的 `_migrate_legacy()` 把旧段的键映射成新段规范键。规则只有一条：**新键在 yaml 里存在 ⇒ 用新键；新键缺失 ⇒ 才用旧键的迁移值**。

当前 yaml 下**真正靠迁移生效的 18 个键**（要改就得改**旧段**）：

| 规范键（谁在读） | 值来自哪一段 | 迁移表位置 |
|---|---|---|
| `route.tokens`（真路线表） | `path_executor.mission_blocks` | `src/dzbrain/dzbrain/core/config.py:724` |
| `pursuit.reverse_speed_ratio` / `reverse_steer_sign` | `path_executor.reverse_*` | `src/dzbrain/dzbrain/core/config.py:730` |
| `mission.settle_eps_m` | `path_executor.shoot_settle_speed` | `src/dzbrain/dzbrain/core/config.py:746` |
| `mission.stable_timeout_s` / `stable_offset_px` / `candidate_retry` / `finish_voice_id` | `path_executor.shoot_stable_*`、`shoot_max_retry`、`finish_voice_id` | `src/dzbrain/dzbrain/core/config.py:747` |
| `aim.fire_box_far_px` / `fire_box_near_px` | `dzrknn_dataprocess.fire_dz_far_px` / `fire_dz_near_px`（**现值 25 / 26**） | `src/dzbrain/dzbrain/core/config.py:754` |

**怎么用这张表**：
- 改**开火框**：改 `/dzrknn_dataprocess` 段的 `fire_dz_far_px`（yaml 里已显式存在）；想只影响 dzbrain 侧判据，才在 `/dzbrain: aim:` 段写 `fire_box_far_px`（写了就以它为准）。
- 改**车体尺寸 / 雷垫片 / 挡板**：改 `/dzactuator` 段的 `vehicle.*` / `field.*`（`/dzbrain` 段根本没写这些键）。
- 改**路线**：改 `path_executor.mission_blocks`（迁成 `route.tokens`）；零地图 + 布局模式下路线是现场算的，这张表只在回退时用。

## 4. 验证命令图例（表里「验」列的含义）

> 全部在 `dzrobot_v2` 下跑。**Windows 本机必须带 `PYTHONIOENCODING=utf-8`**：不带会因 GBK 控制台把 `⚠`/`↔` 打成 UnicodeEncodeError（实测），看着像程序崩了，其实只是编码。

| 代号 | 跑到哪一级 | 命令 | 判据 |
|---|---|---|---|
| **V0** | 只重启节点、看横幅 | 车端 `~/dzrobot/tools/restart_node.sh gimbal` 或 `~/dzrobot/start_all.sh restart` | 启动横幅里该键的值 = 你写的值 |
| **V1** | G1 配置自检 | `PYTHONIOENCODING=utf-8 python tools/config_selfcheck.py --config config/robot.yaml --map config/map.yaml` | **error 0 ∧ warn 0**（不是只看退出码） |
| **V2** | G1 + 仿真闭环 | V1，然后 `PYTHONPATH=src/dzbrain PYTHONIOENCODING=utf-8 python -m dzbrain.tools.sim_cli --max-steps 2000 --quiet` | 退出码 0 + 指标表（RMS/最大偏差/压雷覆盖/越界） |
| **V3** | V2 + 受控短跑 | 判据同 V2，再加一趟只跑前几段的实车 | 短跑日志里无 `SAFE_STOP` / `task_fault_event` |
| **V4** | 车端实车 | 改配置 → 重启对应节点 → 跑一趟 → 看日志 + 视频 | 该参数的现象消失且没有新现象 |
| **V5** | 路线门禁 | `PYTHONIOENCODING=utf-8 python tools/route_check.py --config config/robot.yaml`（+ 必要时 `--simulate`） | **0 error**（warn 逐条判读：急转弯类 warn 多属常驻） |
| **V6** | 车端 ROS 观测 | `ros2 topic info /LaserShot_Command`、`ros2 topic hz /det_result`、相机试帧 | 订阅者数与帧率对得上，不是「看着像在跑」 |
| **—** | 无代码读取 | 改它不改变行为（§0.3） | 只能作注记；真要生效需先改代码 |

**三级判据别混**：`tools/wf/check.py` GREEN 只说明工作流合规，**不是**回归绿、更不是实车通过（[06_回归与测试基线](06_回归与测试基线.md) §1）。

## 5. 改参数的固定六步（照做即可）

1. **备份**：`cp config/robot.yaml config/robot.yaml.bak_$(date +%Y%m%d_%H%M)`。
2. **定位**：§2 找到场景 → §1 用行号定位键；确认它不是 §0.3 黑名单里的、也不是 §0.2 里「该改另一段」的。
3. **只改一行**（一个变量）。类型照抄默认写法：float 键写 `45.0`，不要写 `45`（实测会被 G1 判 `类型不符` 直接 NO-GO）。
4. **跑对应级别的验证**（§4）。V1 都不绿就不要往下走。
5. **记录**：改了哪个键、从 X 到 Y、G1/sim/实车的结果各一句 —— 写进当天的会话日志（`src/history/log/` 目录下，文件名形状 `log_<日期>_<时分>.md`，并更新该目录的 INDEX；只留在会话里等于没做）。
6. **回滚点**：现象变差立刻 `cp` 回来并重启，别在坏参数上叠第二个改动（铁律：连续 2 轮无提升即停）。
