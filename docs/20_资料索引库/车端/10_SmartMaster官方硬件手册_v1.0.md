# SmartMaster 官方硬件手册提炼（V1.0）

> 这份是**厂商硬件手册**（渡众 SmartMaster 比赛用车）。它不含 ROS 话题、不含软件操作（那是同系列《软件操作指南》《裁判系统操作指南》的事）。
> 原件只读，本册**不转贴原图**；引用格式写“PDF p8（印刷 p2）表 1-1”。

## TL;DR（给 agent 看的）

- **能一次拿走的**：① 全部硬件规格数字（表 1-1~1-12）；② 三块板子的接口清单（算法计算单元 / DZVCU / 裁判硬件，接口名来自 OCR）；③ 现场操作口径（自锁开关=电源开关、遥控器按键映射、对频灯语、充电灯、DZVCU 屏字段）。
- **与我们直接相关的三条**：转向舵机中值 **Y=1500**、云台中值 **CV/CH=2047**（PDF p28）；电压 **<10 V 车辆无法控制**（PDF p25）；最大转角 **30±2°**（PDF p8）。
- **轴距/轮距的第三方证据**：手册 **轴距 150 mm、轮距 110 mm**（PDF p8）——这是「0.157 还是 0.15」争论的**外部旁证**，但手册自称“机械测量仅供参考”，**不构成裁决**（见 §9）。
- **旧口径被更正**：官方资料清单（[07_官方资料与物料清单](../赛事与治理/07_官方资料与物料清单.md)）曾记“图片型，全文仅 35 字符”。**实测文本层 11,794 字符可抽**（2026-10-24），只有**图表**是图片。已回改 07。
- **仍然读不出**：40Pin 引脚定义、接线图的线与线连接关系、遥控器 8 通道的实际功能分配（见 §11）。

## 3. DZVCU 电机控制器（PDF p12-p13（印刷 p6-p7））

**职责**（p12）：位于算法计算单元与底盘之间，向各部件供电、收集轮速与 IMU、控电机转速、控舵机角度、控云台转动。自主设计，芯片为高算力 MCU。

**板载 IMU**：三轴 16 位加速度计（量程 ±24 g，零漂 ±20 mg，温漂 ±0.2 mg/K，分辨率 0.09 mg）+ 三轴 16 位陀螺（量程 ±2000 °/s，零漂 ±1 °/s，温漂 ±0.015 °/s/K，分辨率 0.004 °/s），可选输出 **12.5 Hz~2 kHz**（p12）。

**接口（OCR 自图 1-8 / 1-9，p13）**

- 正面：航模遥控接口（预留）、**电机 A / 电机 B**、总线舵机接口、**四路舵机接口**、蜂鸣器、用户按键、复位按键、**主开关**、预留扩展口、**电源输入 12 V**、**电源输出 12 V**、电源输出 5 V（×2）、LCD 电源输出 5 V、通信口、5V 供电口、烧录口、语音烧录口。
- 背面：5V/GND 排、**扬声器（喇叭）接口**（p23 正文点名“红色喇叭接口在 DZVCU 背面”）。

## 7. 现场操作（PDF p25-p28（印刷 p19-p22））

### 7.1 开机 / 关机

1. 开机前确认**云台附近无遮挡物**（避免云台损坏）。
2. 按**自锁开关**（图 3-1，电源开关）→ 进入初始化自检：DZVCU 小屏显示底层状态，HDMI 屏显示算法计算单元启动画面。
3. 算法计算单元启动完成 = 启动结束。关机：再按自锁开关，整车断电。

> ⚠️ 开机后若 §7.4 的电压 **<10 V**，电量不足**将无法控制**（p25 原文）。

### 7.2 遥控器

- **出厂已对频**，开机即接管（p25）。
- **左右分工**：左半 = 云台，右半 = 车辆；两半各有“遥控 / 串口程序驱动”**模式切换开关**（p26）。
- **按键映射（OCR 自图 3-2，p26）**：电源开关（长按开关机）；车辆遥控/程序驱动切换；云台遥控/程序驱动切换；**速度切换**；左摇杆左右 = **云台水平运动 CH**、前后 = **云台垂直运动 CV**；右摇杆左右 = **前轮转向**、前后 = **后轮电机**。
- **对频步骤**（p26-p27）：① 开小车电源（接收机绿灯**慢闪** = 无信号）→ ② 按接收机【BIND】键至绿灯**快闪**（进入对频）后松开 → ③ 开遥控器电源，听到“叮”且接收机绿灯**常亮** = 成功 → ④ 遥控器切“遥控”即接管。
- 遥控器 LCD（图 3-4，p27）：PPM 信号、陀螺仪、定速功能、功能锁定、回传信号、回传电压、遥控电压、VRA/VRB 通道、SWA~SWD 通道、通道参数。**本车极少需要调整**（原话）。

### 7.3 充电（p27）

关闭整车电源 → 接 DC 充电口（图 3-5）→ 充电器接 220 V → 看指示灯：**常红 = 充电中，常绿 = 完成**。充电环境须干燥通风。

### 7.4 DZVCU 小屏字段（PDF p28（印刷 p22）表 3-1）

| 显示 | 含义 | 显示 | 含义 |
|---|---|---|---|
| AKM | 控制模式 / DZVCU 名称 | **Y** | 转向舵机中值 |
| **LN / RN** | 左 / 右轮**当前**编码值 | **LT / RT** | 左 / 右轮**期望**编码值 |
| **H** | 遥控传输杆量值 | **CV / CH** | 垂直 / 水平云台位置反馈 |
| ROS | 是否为上位机控制 | 11.86V | 电池电压 |

**默认值（p28 原文）**：Y 默认 **1500**；遥控器连接、转向摇杆未动时 H 默认 **992**；上电后 CV 与 CH 默认 **2047**（机械偏差属正常）。屏显“仅供参考”（原文）。

## 8. 安全与保养（PDF p29-p30（印刷 p23-p24））

**环境限制**：仅沙盘/封闭区；无照明勿在暗处；勿长期高温停放；勿雨雪冰雹扬尘；地面积水禁启动；冬季低温电池效率低、用后即充；勿崎岖路面。
**使用**：人手驾驶须在视线内；自动驾驶须先清场；制动/转向失效立即停用；上电先看指示灯；按续航充放电；**电量 <10% 及时充**；遥控驾驶须专人负责。
**保养**：严禁带电插拔；勿自行改电路/拆件；线皮破损立即断电；着火用**干粉**灭火器；车身湿布擦、**传感器用湿巾（不沥水、非磨砂）**；禁用酒精/汽油/煤油；清洁前必须断电；长期存放阴凉干燥并防尘；电池勿置于 **>40 ℃ 或 <-5 ℃**，**每月充放一次**，**禁止拆电池本体**。

3. **遥控器 8 通道的实际功能分配**：屏幕有 SWA~SWD、VRA/VRB，但**哪个通道对应舵机/云台/模式切换未给**。
4. **重量**：表 1-1 该格是 “~”，手册未给数。
5. **云台电机“额定重量 30 Kg”**：疑为扭矩/负载单位笔误〔未〕。
6. **文件名 V1.0 vs 修订历史末版 V1.1（2025-03-18，改 2.2 接线示意图）**：载体标注与内文不一致；本册按手上这份（V1.0 命名、含 V1.1 修订记录）转述。
7. **本册不如手册权威**：任何数字冲突，**以手册原件 PDF 为准**；本册用于检索与对照。

## 12. 取证与复跑（本机实测命令）

原料只读、不改原件：

~~~bash
# 1) 文本层（11,794 字符 / 34 页）
python -c "from pypdf import PdfReader; r=PdfReader(r'<pdf>'); print(sum(len((p.extract_text() or '').strip()) for p in r.pages))"
# 2) 渲染 144 dpi（LibreOffice Kit，pdfium）
"<node>" "<libreoffice-kit>/lib/cli.js" render --input "<pdf>" --output-dir <out> --pages "1,2,...,34"
# 3) 图页 OCR（Windows.Media.Ocr，zh-Hans-CN）
powershell.exe -NoProfile -ExecutionPolicy Bypass -File <ocr.ps1> -Base <render> -OutFile <ocr.json> -Pages "11,12,13,14,23,25,26,27,28"
~~~
