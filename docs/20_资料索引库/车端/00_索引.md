# 车端 · 分册索引

## TL;DR（给 agent 看的）
- 车端 = `dzbrain` 单进程 **8 线程**（20/20/50/10/50/10/5/2 Hz）+ 4 个 C++ 节点，跑在 RK3588S + ROS2 Humble（域号 118）。
- 现状一句话：默认引擎 `tour`、自动规划**默认关**、R1 限速补丁**本地有车端无**、全量回归 **37 套 / 13 红**、求解率 **28/64**（新口径 47/64 在途未验收）。
- 最大坑：**同名多版本**。地图 3 份、路线 4 版、航向守卫 3 套；靶速已定口径 **0.3 m/s〔D-033，2026-10-23〕**（曾被 D-031 定为 1.0，已改判；0.04 仅注释残留）——引用前先认版本（§3）。
- 车端代码 HEAD 已到 10-21，但「已实车验证」的事实只到 **10-21 R3B/C1 标定三趟**。

## 4. 三件最容易搞错的事

1. **`check.py` GREEN ≠ 质量绿**：它只查冻结区登记/断链/复用，**不跑回归**。
2. **仿真绿 ≠ 实车绿**：sim 不建模 PIVOT/ALIGN/最终限速/Safety（D-026）。
3. **「本地已修」≠「车上生效」**：R1 补丁本地 `e9bff6f0…`、车端 `9e9766a1…`，未部署即未生效（D-025）。

## 5. 一分钟判断「这条线能不能动」

1. 动的是冻结区（`src/dzbrain/dzbrain/**`、`src/dzrknn_dataprocess/**`、`config/**`、`tools/deploy_to_car.py`）→ 必须登记 `frozen.json` + 独立评审。
2. 动的是引擎/路线/停站 → 先查 07：D-012（tour 唯一）、D-018（求解率主因）、D-023（13 红分类）不许重开。
3. 动的是控制参数 → 先读 02 §7：一次只改一个变量；D-027 的阿克曼前提未证。
4. 要说「已修好」→ 06 §5 门禁 + 06 §2 复跑数字 + 05 §3 复采哈希，三者齐了才算。
