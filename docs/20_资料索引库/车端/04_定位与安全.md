# 定位与安全

## TL;DR（给 agent 看的）
- 定位 = **不带全局重定位的信念投影**：odom 增量 + 地图锚点吸附 + 漂移修正；投影窗口 0.12 m、**允许回退=false**（试出来的，不是推的）。
- 安全 = **唯一强制停车者**：五道看门狗 + `SAFE_STOP` 闩锁；`yaw_untrusted` 已从「永久闩锁」改为 **20 帧自恢复**（10-19 t_d1b）。
- 航向守卫有 **三套历史模型**，引用前必须说哪一版；现役是差速包络 `limit = max(60, 525·v)`。
- 最大坑：**到点 0.12 m 与漂移告警 0.30 m 互相矛盾**；以及 `/odom` 与 `/odom/localization` 位移比 2.7–2.84×，用错流算里程直接差近 3 倍。

## 1. 定位链

| 项 | 事实 | 出处 |
|---|---|---|
| 输入 | `/odom`（DR 航迹推算） | `serial_reader.py` |
| 初始化 | 固定 **N10 / 车头 +y** 初态 | `tasks/localization.py`；现场复位 `reset:...` |
| 投影 | 窗口 0.12 m、**不许回退** | `tasks/localization.py` |
| 到位吸附 | 吸附到格心并记 `P_FIX`；单次吸附上限 `anchor_max_pull_m: 0.12` | `robot.yaml:864`（注释写明「默认 = pursuit.arrival_m，双保险」） |
| 输出 | 修正后 `P_POSE`；RAW 位姿另存 | `tasks/localization.py` |
| 里程计换算 | `ticksPerMeter = 3280`；`ticksPer2PI = 2680 / 2723`（两值待二分） | `docs/library/车体与标定.md:41-43` |
| 口径陷阱 | `/odom` 与 `/odom/localization` 位移比 **2.7–2.84×**，测距只用 `/odom` | R3B 实测 |

**卡死自愈三判据**（删了就重现 4.1 m 级横偏〔档〕）：投影无进展 ∧ odom 有增量 ∧ 偏差持续超阈 → 重锚。

**已知矛盾**：`arrival_m = 0.12`（`config.py:155`）**远小于** `drift_warn_m = 0.30`（`config.py:174`、`robot.yaml:632`）⇒ 车「离格心 0.2 m 就算到点」，却「走到 0.3 m 才告警」。同一坐标系下的容差倒挂，改任一个必须同步另一个。

## 2. 航向守卫三版（必须并列）

| 版本 | 模型 | 阈值 | 结果 |
|---|---|---|---|
| **A 版**（10-18 前） | 阿克曼 + 固定 floor 8 | `limit = max(floor, 525·v)`，A2 段实测 75.8 °/s | 10-18 在 A2 判超限 → **停车**（当场根因） |
| **B 版**（10-18 现场改） | 同上，floor 8→**40** | 低速门限抬高（对应上限具体值**未核实**） | 先救现场，未做整段评估 |
| **C 版**（10-19 至今） | **差速包络** | `limit = max(60, 525·v)`；`yaw_rate_floor_dps: 40.0` | 见 §3；A2/L8 都判**真失控**而非误报 |

- 增益常量：`_DEFAULT_YAW_DIFF_GAIN_DPS_PER_MPS = 525.0`（`tasks/localization.py:108`）；包络计算在 `localization.py:762-767`；复位入口 `reset_yaw_guard()`（`localization.py:831`）。
- 守卫阈值 D-029 明确**不动**：60 / 45 / 30 °/s 分档 + 20 拍窗口。四个阈值的代码真源（2026-10-29 实核）：包络下限 `60.0`（`localization.py:117` `_DEFAULT_YAW_DIFF_SPIN_DPS`；SCHEMA 在 `config.py:539` `localization.yaw_diff_spin_dps`）、增益 `525.0`（`config.py:536` `localization.yaw_diff_gain_dps_per_mps`）、单帧跳变 `30.0`（`config.py:541` `localization.yaw_jump_deg`）、静止期上限 `45.0`（`config.py:547` `localization.yaw_static_dps`）。
- **改阈值/引用阈值一律走 `数字速查.yaml`**：`yaw_diff_spin_dps` / `yaw_diff_gain_dps_per_mps` / `yaw_jump_deg` / `yaw_static_dps`（机器校验，改代码没同步速查表 = 数字守卫判红）。
- **仍缺物理前提**：`max(60, 525·v)` 是「差速可原地旋转」模型的产物，而 D-027 判车是标准阿克曼 ⇒ 包络在小 v 段偏松（T3 报巡航段过松 2.49×，见 §4）。

## 3. 两次航向事故（结论必须分清）

| 事故 | 数字 | 现在判断 |
|---|---|---|
| 10-18 **A2** | 79.8 °/s > 75.8 °/s | **不能判「误触发」**：525 增益由 A2 自身标定（循环论证）；79.8@0.19 需 δ≈49°，超手册 30±2°；原始 5 Hz 帧未见 ⇒ 维持「证据不足，更像航向链跳变 / 打滑 / 被转」 |
| 10-19 **L8** | 111.1 °/s > 60 °/s（v=0.06） | **原始证据已找回**（车端 `3_loc_p1.log` 16122 帧），复算确实 104–131 °/s；但「车没动 yaw 却跳」仍需 IMU gz / 视频判定 |

## 4. 安全任务（五道看门狗）

| 看门狗 | 触发 | 后果 |
|---|---|---|
| pose 超时 | 无位姿超阈 | `SAFE_STOP` |
| 航向完整性 | 超差速包络（C 版） | `yaw_untrusted`，**20 帧自恢复**（10-19 起） |
| odom 断流 | 无 `/odom` | `SAFE_STOP` |
| 云台/链路 | 心跳 > 3.0 s | 降级或停车 |
| 边界护栏 | 越界 / `map_safety_margin_m: 0.60` | `SAFE_STOP` |

- **启动竞态已修**（t_ae_contract）：`startup_grace = 3 s` + `never_had_pose` 判据，修掉「刚起栈就报 pose_lost」。
- **闩锁自恢复**（t_d1b）：`yaw_untrusted` 闩锁由「永久，必须重启栈」改为 **连续 20 帧正常即清**（`_tmp_session/t_d1b/REPORT.md:7-11`）；同时保留 D-022「完整布局例外」路径（`t_d1b/REPORT.md:19-21`）。
- 新到点判据（task-44）：到点后不再以「停在格心」为目标，改用「到点即停 + 滑行容差」口径（`_tmp_session/task-44/REPORT.md:30-37`），支撑 C0/C1 的 17–20 mm 滑行量化。
- 实体证据：C1 三趟滑行 17.4 / 19.8 / 17.5 mm、横偏 13.7 / 21.5 / 2.9 mm（`docs/00_项目总览/现状快照.md` R3B 段）。

## 5. 未解决的物理前提

- 「差速可原地旋转」（`localization.py:97-109/762-767`）与 D-027 阿克曼结论冲突；PIVOT 实际是 0.08 m/s 前进弧。
- ⇒ **S3.0（六项量测）未做前，守卫包络与 PIVOT 到点语义都缺物理前提**；不能拿「仿真不越界」当「实车安全」。

## 6. yaw 漂移与 reset 纪元锁存（2026-10-22 三轮只读归因，补丁未部署）

> 来源：`_archive/20261023/tmp_session/YAWDRIFT-20261022.zip`（漂移归因）、`YAWDRIFT-FIX-20261022.zip`（修复设计）、`RESET-EPOCH-20261022.zip` + `INFRA-RESET-20261022.zip`（锁存根治）。本轮只读复算，**未改 src/config、未部署、未上车**。

**现象两件，根因不同，别混为一谈**

| 现象 | 数值 | 根因 |
|---|---|---|
| 静置 yaw 缓慢漂移 | −0.0705 °/s（118 s 累计约 8.3°） | dzactuator **同一组 Mahony 四元数被两条路径各更新一次**：`dzactuator.cpp:591`（raw 陀螺）与 `:534`（filtered）都调 `Quaternion_Solution`（`Quaternion_Solution.cpp:212-270`），imu yaw = 两路增量平均 |
| reset/重启后 yaw 突跳 → 守卫锁存 | 130.7°（40.4 rad/s = 静止包络 45°/s 的 **51 倍**，v=0、位置不动） | serial_reader 在 reset 时把 **yaw 原点（imu_yaw_init）重锚**，是"授权不连续"，守卫却当**单帧物理跳变** ⇒ `EV_TASK_FAULT` ⇒ Safety **永久闩锁**（代码内无外部 clear 入口） |

**反推的零偏账**：filtered gz 均值 −0.1702 °/s、orientation 斜率 −0.0705 °/s ⇒ raw gz ≈ **+0.0292 °/s**；零偏估计 ≈ **0.1993 °/s**，其中约 60% 被 raw 路抵消——所以"调零偏参数"永远调不到 0（这正是 D-024「信号坏时调参=开倒车」的实例）。

**修复设计（未落地）**
1. 漂移：**分离 q（raw/filtered 各自一套）+ 实测 dt + 静止在线零偏更新**。离线复算 τ=2 s 时 118 s 斜率 −0.00023 °/s（目标 ±0.005）；只把 raw 路分出去**不收敛**（filtered 单独 −0.170 °/s，比现状更差）。
2. 锁存：新增话题 **`/nav/yaw_epoch`**（`[epoch, kind]`，transient_local）；航向守卫**只在 epoch 变化那一帧重基线**，阈值与其余判据一字不改——真正的 130° 旋转（无 epoch 变化）照旧触发故障。
3. `/odom` yaw 恒 71.866° **不是**漂移源（Robot_Pos.Z 只在 |linear_Speed|>0 时更新）。

**状态**：`PATCH.diff` 为草稿未应用；三轮均未上车验证。**先做 §5 的六项量测再谈部署**。
