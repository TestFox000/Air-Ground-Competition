# 空地链路 · 分册索引

## TL;DR（给 agent 看的）

- 两条话题：/nav/waypoint（RELIABLE，机→车路线/段目标）与 /dzlink/*（BEST_EFFORT，情报/布局/心跳/回传）。
- **最贵的坑**：BEST_EFFORT 发 → RELIABLE 收 = **静默 0 条**，而两端端点计数都还是 1 —— 只有 **ack** 是硬证据。
- 现状：v1 情报门控真机跑通（t4/t12/t16/t18）；v2 步进循环（field_layout）**离线 + 1 次段链路验证，未上车**，2026-10-18 审计判 **NO-GO**。
- 三个没堵的洞：SEGMENT_DONE 漏收约 **86%**、到站 block 差半格（D2）、停站 0 发（射击链见视觉与云台册）。
