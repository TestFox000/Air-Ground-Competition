# 外部资料 · 分册索引

## TL;DR（给 agent 看的）

- **这是什么**：资料库「外部资料」分册，收拢**项目之外**的一手材料——外部成员交接（hjy / wtt / yb）、外部团队瓶颈分析、外部接口契约，以及官方交付的 SDK / 源码 / 手册。
- **一句话结论**：本册 6 篇都是**外部来源**的提炼，不是本地实现；引用前认版本，机制教训可用、模型名与指标以本地册为准。
- **关键数字**：来源 3 个 tar（ext_yb_tree / ext_gitee_main_tree / ext_carsnap_tree）+ 官方附加资源（2.1 GB / 11 条目）；外部材料 489 篇中本轮先吃 6 篇。
- **最大坑**：外部契约与本地协议**不兼容**（hjy 14 类二进制 vs 本地 13 类 JSON）；外部模型指标是**对方时点快照**。
- **什么时候读**：要借外部实现、要查官方原件位置、要判断「这条是不是我们做的」时。
