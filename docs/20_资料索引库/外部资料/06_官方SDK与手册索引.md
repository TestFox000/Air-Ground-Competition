## 5. 使用规则（四条，缺一不可）

1. **原件只读**：附加资源/ 是厂商交付物，不修改、不移动、不删除（2.1 GB 不可再生）。
2. **不转贴进库**：二进制与图片不入 docs/；引用写「附加资源/<条目标题>/<文件名> p<页码>」。
3. **图片型 PDF 要人读**：裁判系统指南、雷/通行口图——agent 读不出内容，别假装读过；SmartMaster 硬件指南文本可抽，但 40Pin 引脚图与接线图仍是图片，**不许凭 OCR 残片编引脚定义**。
4. **版本敏感**：场地说明书是 V1.2 / 2026-07-14；官方换版先比 §2 表再改赛事与治理/01。
