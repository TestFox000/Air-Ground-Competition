# 常见拒绝与权限

> 「车/机拒绝了我的命令」「这个操作我到底能不能做」先看这篇。
> 本文是提炼：真源 `无人机/02_飞控与uXRCE域号.md` 与 `空地链路/02_链路联调与已知缺口.md` §6；原文保留，不搬整段。

## TL;DR（给 agent 看的）

- **无人机侧两类拒绝**：① uXRCE 会话死 ⇒ 需**物理断电飞控 5 s 再上电**（改不了、也修不了，只能现场动作）；② 域号分裂 ⇒ ping/SSH 全通但 ROS 静默失联，且**单侧切换比现状更糟**。
- **判据只有一条硬指标**：`/fmu/out/vehicle_local_position` 的 **Publisher count ≥ 1**；`ros2 topic list` 里有 fmu 话题**不是判据**（看门狗订阅也会让它存在）。
- **空地链路侧两类拒绝**：① 布局 `known` 漏了车位姿所在格 ⇒ 车第一拍就 SAFE_STOP（规划器对起点破例、护栏不破例）；② 特征类别与现役真值冲突 ⇒ 该停的靶被当桶、该避的桶被当靶。
- **权限红线**：agent 对机只读；飞控断电、改 PX4 参数、代跑 px4_control/teleop 都必须**人在座**。

## 0. 「拒绝」的两种性质（先分清再处置）

| 性质 | 表现 | 处置 |
|---|---|---|
| **程序拒绝**（配置/判据不满足） | 有日志、有错误码、能定位到参数 | 改配置或改判据，可自动 |
| **权限拒绝**（现场动作/安全边界） | 无日志、命令静默失效或被拒 | **只能现场人执行**，agent 不代做 |

> 判断口诀：**能改配置的是程序拒绝；要人到场的是权限拒绝。** 无人机/链路侧大量「静默失效」其实是后者。

## 1. 无人机：uXRCE 会话死（需飞控断电）

| 项 | 内容 | 出处 |
|---|---|---|
| 症状 | agent 每 ~61 s 被看门狗重启；日志停在 `TermiosAgentLinux init running`；`/fmu/out/vehicle_local_position` **Publisher count = 0** | `无人机/02` §2 |
| 周期成因 | 61 s = 60 s 冷却 + 1 s 杀/起 | uXRCE 恢复手册:169 |
| 根因（指向） | **Orin 重启而飞控未断电** ⇒ 串口会话状态不一致 | 同上 |
| 恢复 | **飞控断电 5 s 再上电** → 等 30 s → 重起 agent（三步卡） | uXRCE 恢复手册:16-80 |
| 10-18 状态 | **已缓解**：8 路 `/fmu/out` 有数据（local_position 102 Hz / attitude 133 Hz / sensor_combined 142 Hz），agent 以 `--dev ttyACM1` 出现 | 交接:43-50、:64 |
| 仍脆弱 | Orin 再单独重启即复发；FC_OFFLINE 自动恢复补丁**已写未部署** | uXRCE 恢复手册:173 |

**恢复后只读验证三件（缺一不算通）**：

| # | 命令 | 通过标准 |
|---|---|---|
| 1 | `ros2 topic info -v /fmu/out/vehicle_local_position` | Publisher count ≥ 1 |
| 2 | `ros2 topic hz /fmu/out/vehicle_attitude` | 稳定 ~133 Hz（不只是「有数」） |
| 3 | `ps -o etimes= -p $(pgrep -f MicroXRCEAgent)` | 启动时间 > 61 s 且持续增长（不在重启循环） |

> **为什么必须物理断电**：无 MAVLink 通道 ⇒ QGC 不可用、PX4 参数不可读不可改（`无人机/02` §1）。所以「会话死」既不能软件修复也不能参数修复，只能靠断电重启串口会话。

## 2. 无人机：域号分裂（静默失联）

| 侧 | 值 | 证据 |
|---|---|---|
| 机侧全部（节点/agent/看门狗） | **0** | grep ~/.bashrc 无 DOMAIN 命中；~/.bash_history 中 ROS_DOMAIN_ID 出现 0 次 |
| 机侧唯一 118 | ~/dzlink_tools/dzlink.env（被 supervisor 在 import 阶段读取并覆盖） | 架构总览:370-380 |
| 车侧 | 118（`dzros.env` / start_all.sh:123） | 车端/05_配置与部署.md §1 |
| PX4 UXRCE_DDS_DOM_ID | **未知**（默认 0，无 MAVLink 读不到） | 架构总览:400 |

- **症状**：ping/SSH 全通、ROS 零报错、彼此看不见。
- **机制**：域号决定 DDS 端口（`7400+250×domain` ⇒ 118 = **36900**，组播 239.255.0.1），跨域连发现包都收不到。
- **为什么没切**：切换单要求 PX4 侧设 `UXRCE_DDS_DOM_ID=118`，而改 PX4 参数必须有 MAVLink/QGC ⇒ **前置闸不满足**。
- **单侧切换比现状更糟**：车在 118 等，机被切到 118 而 PX4 仍在 0 ⇒ 飞控侧直接断。

## 3. 空地链路 §6：四类机端必修坑（对端交叉验证得出）

| ID | 坑 | 后果 / 修法 |
|---|---|---|
| **E1** | `known` 漏了**车当前格**（recon 批次 129 格不含 N10） | 车第一拍就 `SAFE_STOP：belief 连续落在未知格`（`main.py:1034`）。规划器对起点破例、运行期护栏**不破例** ⇒ **每份布局 known 必须含车位姿所在格** |
| **E2** | 特征类别与现役真值图冲突（B7 真值是障碍，recon 报 target_blue） | `_stop_kind_with_spec()` 把 obstacles/targets 都当禁站格 ⇒ **该停的靶被当桶、该避的桶被当靶** |
| **E3** | dry_full 建在**第六图**，车/机部署是**第七图** | 按第六图发的布局会漏压雷、撞桶、停错靶位；机端真值钉 `~/dzlink_tools/map7.yaml`，**不要**用仓库 `config/map.yaml` 当真值 |
| **E4** | `belief` 段完成差一格（B10→B11） | 按 `segment_id` 消费，**不要**用 `block == target` 字符串判据 |

> **判据纪律**：布局拒收（`layout_rejects` 增长）先看拒收原因（version / 内容 / 特征 ⊄ known），**别重启车**（`process_drafts/RUNBOOK_MORNING` §6）。

## 4. 权限与安全红线（照抄执行）

| 类别 | 内容 | 出处 |
|---|---|---|
| 无人机红线 | **禁止 `cat /dev/ttyACM0`**：会把字节从 agent 手里抢走、**自己制造**会话死 | `无人机/02` §5 |
| | **禁止双 agent**：同一串口两个 MicroXRCEAgent = 互抢帧 | 同上 |
| | 禁止代跑 `px4_control` / `px4_teleop`（有执行能力，须人在座、真 TTY） | 同上 |
| | 域号切换窗口内**禁止飞行** | 同上 |
| | 判活**别看日志**：stdout 块缓冲，日志 0 字节 ≠ 进程死 | 同上（R-25） |
| agent 对机权限 | 只读（SSH ls/cat/pgrep/ros2 topic info/hz）；起/停 rosbag（只写 `~/drone_bags`）；经同意拉起感知栈 | `无人机/05` §6 |
| | **禁止**：建改删机端文件、装包、改配置、解锁/起飞/发控制指令、改 PX4 参数、重启飞控、`cat /dev/ttyACM*` | 同上 |
| 车端权限 | 部署必须人工执行（D-007）；冻结区改动须登记 | `车端/05` §3 |

## 5. 失败对照表

| 现象 | 先看 | 处置 |
|---|---|---|
| `/fmu/out` 无数据但车/机 ping 通 | `ros2 topic info -v /fmu/out/vehicle_local_position` 的 Publisher count | =0 ⇒ 飞控断电 5 s 再上电；≠0 再看 hz 稳定性 |
| `ros2 topic list` 里有 `/fmu` 但没数据 | 看门狗订阅也会让它存在 | 只看 Publisher count，别信 topic list |
| ping/SSH 全通但 ROS 互相看不见、零报错 | 域号 | 机侧 0 / 车侧 118；单侧切换比现状更糟，别擅自切 |
| 车第一拍就 SAFE_STOP | `known` 是否含车位姿格 | 补 layout，别改护栏（护栏不破例） |
| 该打的靶不打、该避的桶当成靶 | 特征类别 vs 现役真值图 | 对账真值（B7 真值是障碍），修特征映射 |
| 布局拒收增长 | 拒收原因（version/内容/特征⊄known） | 看 emitter 日志，别重启车 |
| 段完成了车还在段末干等 | 段完成判据（`segment_id` vs `block==target`） | 用 segment_id 消费；D1b 窗口只有 1~2 拍 ⇒ 漏收约 86% |
| 到点报错差半格/一格 | `block` 与 target 差一格（E4） | 按 segment_id/target_cell 关联，不用字面相等 |

## 6. 权限速查：这个动作谁能做

| 动作 | agent 能做 | 现场人必须做 |
|---|---|---|
| 查状态（ros2 topic info/hz、ls、cat） | ✅ | — |
| 起/停 rosbag（只写 `~/drone_bags`） | ✅ | — |
| 拉起感知栈 | ✅（经同意） | — |
| 部署车端代码 | ❌ | ✅（D-007，deploy_to_car.py 对账+备份） |
| 飞控断电重启 | ❌ | ✅ |
| 改 PX4 参数 / 切域号 | ❌ | ✅（且需 MAVLink 通道，当前不存在） |
| 代跑 `px4_control` / teleop | ❌ | ✅（人在座、真 TTY） |
| `cat /dev/ttyACM*` | ❌（**禁止**） | ❌（**禁止**，会自己制造会话死） |
