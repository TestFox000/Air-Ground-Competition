# 运维与排障 · 分册索引

## TL;DR（给 agent 看的）

- 本册 = **现场排障的第一入口**：只知道现象（车不动、激光不亮、ROS 看不见）→ 查 `01_症状索引_52条`；要跑车 → 查 `02_起栈与发车_runbook`；弹药/开火 → 查 `03_弹仓与射击复位`；被拒/权限 → 查 `04_常见拒绝与权限`；**要知道「下一步动作」→ 查 `05_日常动作速查`**；**要从零打出一发（串口归属/两键注入/三条判据）→ 查 `06_实车打靶_runbook`**。
- **发车四门 G1~G4**（本地一致性 / 部署对账 / 车上静态体检 / 起栈与启动契约，每门带判据与红了怎么办）→ 查 `07_发车门禁口径_G1-G4`；**门禁红了先查挂账**（已知红/黄、owner、到期）→ 查 `08_回归守护_known_reds`；**明早这一趟按什么顺序做** → 查 `09_明早全流程SOP_20261029`（第 10 节是一页纸打印版）；**日志已经在手、要看懂某一行** → 查 `10_日志阅读课_新手版`（七份真车日志逐份精读 + 横幅三态 + 退出码表）。
- 症状索引共 **52 条**，与 `20_资料索引库/README.md` §4 逐条对齐（症状文本一致，只扩「机制/位置/处置命令」三列）；README §4 保留指针行，是入口。
- 最大坑：**同名键多段并存**（`robot.yaml` 的 `drift_warn_m` 在 `:454` 与 `:632` 各一份）、**域号非交互 SSH 默认 0**、**`cam_viewer` 抢 `/pursuitAngle`**。
