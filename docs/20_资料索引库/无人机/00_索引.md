# 索引

## TL;DR（给 agent 看的）

- 这是 dzsmart 无人机（Jetson Orin Nano + PX4）资料的**唯一现行入口**，共 7 篇：索引 / 架构 / 飞控与域号 / 感知与视觉 / 路线与回放 / 现场操作 / 已取证。
- **一句话现状**：定位链是**实的**（雷达 10 Hz、FAST-LIO 43~45 Hz、VIO 42~44 Hz、EKF 收 EV 到 3 cm 级），飞行链是**空的**（从未自主飞过一次），视觉侦察是**纸的**（单测 99/99，实拍 det=0）。
- **最大坑**：同一件事有多份互斥结论（飞控板插没插、域号 0 还是 118、桥洞 K9/K4 还是 K10/K5、帧率 13 还是 21）。**先读 §3 冲突表**，两个版本都带着出处引用，不要二选一。
- 系统性质别搞错：**「人手动飞一遍录轨迹 → 机器照轨迹回放」+ 单向情报下发**，不是自主规划无人机（dzsmartscout/docs/无人机项目总览.md:22-28）。

## 4. 三条必读结论

1. **没有自主飞行**：全仓无真机 Offboard/自动起飞/完整飞行记录；px4_path 只是回放（dzsmartscout/docs/无人机项目总览.md:22-28；_tmp_session/agent_overview_20261020/drone.md:161）。
2. **飞控链路断点在 uXRCE 会话**：10-17 起每 61 s 被看门狗重启、Publisher 恒 0；10-18 已缓解但脆弱（uXRCE恢复手册:4-5、:88-94；交接:43-50）。
3. **视觉侦察只有图纸级证据**：官方图逐格 0 差异，实拍帧从未验证通过（CAPABILITY_L1.md:21、:125-127）。
