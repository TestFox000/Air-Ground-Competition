# 架构总览

## TL;DR（给 agent 看的）

- 一句话定位：**「回放式路径跟随」+ 一条单向情报下发链**，不是自主规划无人机。人在 RC 上手动飞一遍 → 录轨迹 → 机器照轨迹回放（dzsmartscout/docs/无人机项目总览.md:22-28 原文；_tmp_session/agent_overview_20261020/drone.md:11-14 复核至今成立）。
- 硬件：Jetson Orin Nano（Ubuntu 22.04.5 / 内核 5.15.185-tegra / 6 核 / RAM 7.6 G、可用仅 2~3 G）+ Livox MID-360 + LRCP AR0234 + Matek NxtPX4，uXRCE-DDS 921600。
- 软件：ROS 2 Humble + 四个自研 C++ 包共 **4742 行 / 0 个测试**；感知是独立的 Python 包（99/99 单测）与独立 C++ 程序 dzuav（**不是 ROS 节点**）。
- 最大坑：**判活顺序错就白折腾** —— ①感知定位 ②飞控通信 ③飞控行为 ④跨机协同，其中 ④ 不需要飞控（dzsmartscout/docs/drone/无人机架构总览.md §1「四条链路」）。先判卡在哪条，再动手。

## 4. 数据流（一张图看完）

    Livox MID-360 ──eno1──► livox_ros_driver2
       ├─ /livox/lidar (CustomMsg 10 Hz, 19968 点) ─► fastlio_mapping ─┬─► /Odometry 43~45 Hz
       ├─ /livox/imu (200 Hz) ──────────────────────────────────────────┘
       │                                    └─► transform_fusion.py ─► /localization ~44 Hz
       └─ /livox/lidar ─► dzlink_pc2_bridge ─► /livox/points 10 Hz + /dzlink/seq 50 Hz ─► 小车

    /Odometry (mode:=odom) 或 /localization (mode:=localization)
        └─► px4_odom_convert ─► /fmu/in/vehicle_visual_odometry 42~44 Hz ─► PX4 EKF2

    px4_teleop_node ──/px4_control/command──┐
    px4_path(follow) ──/px4_control/goto───► px4_control_node ──20 Hz──► /fmu/in/{offboard_control_mode,
        ▲                                        │                       trajectory_setpoint, vehicle_command}
        └──/px4_control/goto_enabled (transient_local 锁存)──┘

    相机 /dev/video0 ─► dzuav(TensorRT) ─► 二进制 UDP:50000 广播 ─► 小车 ag_integrate

- 拓扑出处：dzsmartscout/docs/drone/无人机架构总览.md §2.2；相机链 dzsmartscout/src/uav_camera_code/docs/无人机工作流程.md:19-24、:121-160。
- **反直觉但关键**：px4_odom_convert 是输入驱动（来一帧发一帧），43~44 Hz 的 VIO 频率 = FAST-LIO 频率，不是定时器（drone.md:71）。

## 5. 关键节点要点（给改代码的人）

| 节点 | 要点 | 证据 |
|---|---|---|
| px4_control_node | 状态机 DISARMED→ARMING→TAKEOFF→HOVER→LANDING→LANDED；心跳攒满 20 帧（1 s）才准切 Offboard；起飞目标 z=-takeoff_height（NED） | 架构总览 §2.5；px4_control_node.cpp:119-143、:336-340、:372 |
| px4_teleop_node | 0 Offboard · 1 ARM+起飞 · 2 DISARM · 3 LAND · WASD/QE 平移 · L/R yaw · 4 使能 Goto · 5 撤销；**必须真 TTY** | dzsmartscout/docs/无人机项目总览.md:204-216 |
| path_record_node | 输入 /localization（slam_topic）⇒ 只跑 FAST-LIO 时**录制静默 0 点**；析构才落盘，kill -9 丢整段 | 架构总览 §2.5；R-15 |
| path_follow_waypoint_node | 光标推进只认「距航点 < switch_tol(0.10)」，无越点无超时 ⇒ 一次超调永久卡死 | path_follow_waypoint_node.cpp:265-273 |
| path_follow_trajectory_node | 曲率/动力学受限：max_speed 0.8 / accel 1.0 / jerk 2.5；与 waypoint 版重约 150 行 | drone.md:81 |
| px4_odom_convert | launch 默认 mode=localization（坑），代码默认 odom；jump guard 硬编码在 hpp | launch/px4_odom_convert.launch.py:35；include/px4_odom_convert.hpp:148-150 |

## 6. 四条链路判活（顺序不能反）

| # | 链路 | 判据 | 依赖飞控？ |
|---|---|---|---|
| ① | 感知定位 | /livox/lidar 10 Hz、/Odometry 43~45 Hz、/localization ~44 Hz | 否 |
| ② | 飞控通信 | MicroXRCEAgent 在跑 + Publisher count ≥1（**不是** topic list 里有话题） | 是 |
| ③ | 飞控行为 | /fmu/in 三通道 20 Hz + PX4 回 vehicle_status | 是 |
| ④ | 跨机协同 | /nav/waypoint、/dzlink/* 两端 count ≥1 + ack | 否 |

- **判活唯一硬指标**：ros2 topic info -v /fmu/out/vehicle_local_position 输出里的 Publisher count ≥ 1。看门狗自己订阅会让话题「存在」，即使 0 发布者（uXRCE恢复手册:286）。
