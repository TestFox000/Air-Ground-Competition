# 已取证与未验证

## TL;DR（给 agent 看的）

- 本册唯一职责：**把「真机验证过」和「从来没做过」分开**。任何计划落在右列，按「全新功能」排期，别按「调一调」估工。
- 一句话现状：**定位链是实的，飞行链是空的，视觉链是纸的**。
