> 执笔：trae-glm（agents/trae-glm/pure-pursuit-u2）。
> 依据：《全线升级方案-20261018.md》U2 项——"车端循迹对照标准 pure pursuit
> 前视弧长公式校验；吸收 regulated 思想曲率大处自动限速。验收：台架画圆/
> 切角问题复测；SIL 轨迹误差对比报告"（本文即该报告）。

## 1. 结论速览

1. **标准 Pure Pursuit 已实现并全量达标**：前视弧长公式 κ=2y/d²、
   δ=atan(L·κ) 逐项过单元校验；全链路 SIL 三路线（图缘主证明 / S 弯 /
   雷格过心）与现役 stanley 律同尺达标（雷格过心 ≤6cm 判分圆）。
2. **精度上 stanley 仍占优，PP 不换默认**：严尺场景（全 fillet 路线）
   PP 横向 RMS 3.7~3.9cm vs stanley 2.8~3.2cm——曲率前馈在 tight 网格
   弯道（R=0.272m）上的优势是结构性的。**默认 track_mode=stanley 不变**，
   PP 作为台架 A/B 与备选跟踪律保留（`track_mode: pure_pursuit` 一键切）。
3. **regulated 思想吸收落地**：指令曲率纳入限速
   v ≤ √(a_lat_max / max(|κ_path|, |κ_cmd|))——大偏差修正、末段 homing
   等"路是直的但车要急转"的场景自动降速（对不可原地转向的 Ackermann
   是安全项而非性能项）。
4. **定标过程发现并修复 PP 编织振荡**：初版 L_d=0.15+1.2v（上限 0.50）
   在 K 列直线段出现切角后欠阻尼编织（K9 过线 0.6cm → K8 峰 7.8cm，
   G 列 G5 达 10.8cm，超 6cm 判分圆）。根因 L_d(0.44)≫弯道物理半径
   R(0.272)。增益压到 0.55（上限 0.35）后弯速下 L_d≈R，全雷格 ≤4.4cm。
   **这是"前视距离必须对齐最小转弯半径"的实测定标结论，进参数注释。**

## 2. 实现设计

落点：`src/dznav/dznav/pursuit.py`（dznav 自研执行器，非官方
path_executor）。**不新增模块、不改安全语义**——`_track` 内转向律按
`cfg.track_mode` 二选一，到点双门 / 射击停站 / ARC 机动 / REBUILD 重建 /
看门狗等全部共用不变：

```
track_mode = "stanley"       # 现状默认：ff(κ) + k_h·e_θ − k_c·atan(k_v·cte/(v+v0))
track_mode = "pure_pursuit"  # U2：标准前视弧长律（下述）
```

Pure Pursuit 律（`_pure_pursuit_steer`）：

| 步骤 | 公式 | 说明 |
|---|---|---|
| 前视点 | 路径上 s_prog + L_d 处 | L_d 随速度自适应（regulated 标准做法）；超出路径末端夹到终点，天然退化为终点 homing |
| 前视距离 | L_d = clamp(0.14 + 0.55·v, 0.14, 0.35) | SIL 定标值（见结论 4）；弯速 v≈0.24 时 L_d≈0.27≈R_phys |
| 曲率 | κ = 2·ey / d² | ey=前视点车体系横向偏移，**d=弦长**（车到前视点距离，标准公式分母是弦长平方，非名义 L_d²） |
| 舵角 | δ = servo.command_for_kappa(κ) | ideal 档即 δ=atan(L·κ)；fxxy 不对称档案自动吃到左右差异 |
| 限速 | v ≤ √(a_lat_max / max(\|κ_path\|, \|κ_cmd\|)) | regulated：前窗路径曲率峰值（既有）∪ 指令曲率（U2 新增，开关 pp_cmd_regulate） |

NaN 防护与 stanley 分支同源（κ 出口 isfinite→0，钳位前检），复用
executor `_publish` 出口双检。

配置穿透：`executor_node.DEFAULTS["track_mode"]="stanley"`（默认关）→
`TrackerConfig(track_mode=...)`；`dznav_default.yaml` 同步（键漂移测试
双向把关）；节点就绪日志打印 tracker 模式。
