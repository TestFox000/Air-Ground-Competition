## 采集与标注链路（复用方法）

1. 采集：`python tools/capture_dataset_local.py --duration 0`（AR0234 USB，1920×1200 约 5fps 抽 2fps；按 q 停）
2. 预标注：`python tools/autolabel_yolo.py --weights <最新检测模型> --source <images> --out <labels> --device cpu`
3. 转审标格式：`python tools/convert_capture_to_xanylabeling.py`（改 BASE 指向新批次）
4. X-AnyLabeling 人工审（工具在笔记本任务工作区根目录，`X-AnyLabeling-v4.1.1-CPU.exe` 免安装）
5. 导出清洗 + 并入 v2：改 `tools/build_v2_dataset.py` 的 NEW 路径后重跑
