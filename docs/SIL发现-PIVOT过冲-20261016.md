# SIL 发现：现役 executor PIVOT 调参在终点边沿接近段过冲出界（2026-10-16）

> 来源：循迹软件在环回归（`tests/test_sim_tracking.py`，加载车上现役
> `path_executor.py` 真码，当前 md5 `02c531a113`）。
> 一句话：昨天实车 PIVOT 调参（`CORNER_TRIGGER_M 0.25→0.40`、
> `CORNER_ALIGN_RAD 15°→22°）修好了 22.1° 事故形态，但在"终点边沿接近段"
> 几何下引入过冲回归——SIL 主证明场景从 72.7s 到点变成东向出图、越界急停。

## 1. 复现

场景（`test_align_then_route_arrives`，2026-10-15 起即入库的主证明）：

- 起点 N10、断言 y、真实朝向 158.6°（68.6° 历史事故偏差），align 后发车；
- 路线 `N10 M9 L8 K8 J8 I8 H9 G9 F9 E9* F10 G11 H11 I11 J11 K11 L11 M11 N11,x`；
- 终点 `N11,x` 触发**接近段自动插入**：末段朝南到达、要求朝东（x）停，
  执行器在终点前 0.6m 沿 x 轴回退插接近点——`max(0.05, 0.175-0.6)` 被钳在
  **图缘 x=0.05**；接近点处拐角 ≈110°（>45°，必走 PIVOT）。

## 2. 两版参数对比（同一场景，同一仿真）

| | 旧参数（0.25 / 15°） | 现役参数（0.40 / 22°） |
|---|---|---|
| PIVOT 起转点 | 顶点前 0.25m | 顶点前 **0.40m** |
| 结果 | **72.7s 到点**，终点误差 0.26m | 过冲终点 → 纯追踪无法倒退 → 东向出图 → **越界急停** |

## 3. 轨迹证据（仿真轨迹留痕 trace，每 5s 抽点）

```
t=66.3  (0.09, 0.86) yaw= -89.8°   沿 11 行走廊南下，正常
t=71.3  (0.13, 0.38) yaw= -57.1°   逼近接近点，PIVOT 入口（距顶点 0.40m 即起转）
t=76.3  (0.52, 0.29) yaw= +10.0°   ← 爬行弧已把车带过终点东侧
t=81.3  (1.16, 0.21) yaw= -21.7°   目标在身后，纯追踪不倒退，持续东行
t=86.3  (1.72,-0.17) yaw= -45.3°   东向出图中
t≈96    信念 y=-0.426 < -0.425     越界急停触发（P0-3 兜底生效）
```

机理：PIVOT 相位 2 以满舵 30°、0.08m/s 爬行的转弯半径 ≈ L/tan(30°) ≈ 0.27m。
起转点离顶点从 0.25m 放宽到 0.40m 后，爬行弧的弦长把车顶过顶点约一个弧半径，
落点越过最后一段的终点；`find_nearest_segment` 只向前搜索（投影钳 t=1），
预瞄点即终点本身、位于车身后方（α≈±180°，sin α≈0 舵角≈直行）——
纯追踪几何上不会倒退，车只能越开越远，直到越界急停。

## 4. 影响面评估

- **legacy path_executor（LEGACY_PATH=1）**：凡以 `,x`/`,y` 结尾且末段与终点朝向
  不正交的路线，终点必然产生接近段拐角；顶点点位若靠近图缘（钳到 0.05），
  现役参数下过冲风险高。我们的路线全部带终点朝向，**直接受影响**。
- **dzbrain 新核**：dzbrain 有独立 pursuit（前视自适应 0.36~0.40、曲率限速、
  加速度斜坡）与任务状态机，不走 legacy 的 PIVOT 三相；受影响程度低
  （但其路线若经 legacy 回退执行则同样受影响）。
- 22° 对齐容差本身不是病根（只让出口姿态略歪，纯追踪能救）；
  **病根是 0.40m 起转 + 图缘顶点的组合**。

## 5. 建议处置（车端代码归并发会话/队长裁决，本文只给证据与选项）

1. 起转距离按场景自适应：`min(0.40, 顶点距图缘/障碍的安全余量)`，
   图缘附近回落 0.25m 旧值；
2. 或相位 2 加"过顶点即停爬"条件（投影 t≥1 就退出 PIVOT 交给纯追踪），
   避免弧弦把车顶过顶点；
3. 或给纯追踪加"目标在身后且距离 > 到点阈值"的恢复分支
   （掉头重锁或倒退接管），而非依赖越界急停兜底。
