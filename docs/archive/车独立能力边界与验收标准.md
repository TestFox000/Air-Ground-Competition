# 车的独立能力边界与验收标准（2026-10-01）

> **一句话**：车是**执行器**，不是**侦察器**。
> 它能独立做到的是「按格号走 + 精确到位 + 近距离识别/打击」；
> 「知道该去哪一格」这件事它做不到，也不需要它做——那是无人机的活。
> **验收标准就该写在这一层，不多要求一条。**

---

## 一、车身上到底有什么（客观边界，非推测）

| 能力 | 有无 | 依据 |
|---|---|---|
| 看场地 / 读格号数字 | ❌ | 定位链只有 `编码器 + IMU 死推算`（`logs/_pe_review/path_executor.py` 头部数据流注释）；全仓 grep 无 OCR / 地图识别 / marker / SLAM / AMCL |
| 知道"我在第几格" | ⚠️ **靠断言，不是测量** | `reset:N10,y` 是"我把车摆在这里、朝这个方向"的**断言**；之后纯死推算累加，**无边界、无回正** |
| 靶标识别（蓝/红敌我） | ✅ 自带模型 | `best_new.rknn`（YOLOv8n-pose，双类 + 发光中心关键点） |
| 地雷识别 | ✅ 有模型，链路未接 | `rest_clean.rknn`（YOLO11n，单类 explosive） |
| 桥洞通行标识 | ❌ 物理上看不到 | 规则原文：标识在**桥梁顶部**，地面车视角看不到 |
| 全局规划 / 决定去哪 | ❌ | 格号必须由外部（无人机情报）给出 |

**推论**：车的摄像头是"凑近才看得清"的前视相机，不是全场监视器。让它"自己找目标"等于让它先瞎走全场 154 格——3 分钟做不完。

---

## 二、不需要无人机，车必须自己过硬的（= 真实验收范围）

1. **按格号序列行驶** —— 位置由外部给，运动由车保证
2. **精确到位停靠** —— 判分点全部落在"停在哪"
3. **到位后用自带相机识别 + 打击** —— 敌我判定是车的责任
4. **出界 / 超时自停** —— 车没有感知，防线只能在软件里，必须我们补

---

## 三、必须无人机的（车不该被要求）

| 任务 | 分值 | 为什么必须无人机 |
|---|---|---|
| 排雷 8 颗 | **40** | 8 格随机分布在全场 ~154 格；车只有前视相机、单场 3 分钟扫不完 |
| 桥洞 2 处 | **20** | 规则明文：通行标识在**桥梁顶部**，地面视角看不到 |
| 敌我区定位 | ±15 | 生成位置随机、靶标移动。车**能判敌我**，但不知道去哪找 → 无人机给格号、车自己确认，这正是"协同"的考点 |

**量化结论：车独立的天花板 ≈ 驶离起点 5 + 回终点 5 = 10 / 100**
（自主搜到靶可再拿 ±15，但不稳定，不能当验收项。）

→ 所以"要求车独立完成全场"从规则上就不成立；要求它**把 10 分那部分做得绝对可靠 + 把无人机给的点精确执行**才是正解。

---

## 四、验收标准

### A 档 —— 车独立（无人机未到货，**现在唯一能推进的**）

> 全过 = "车能正常运动"。**没过 A 档，B 档免谈。**

| # | 项 | 判据（可自动判定） | 现状 |
|---|---|---|---|
| **A1** | 不画圆 | 直线走 2 m：**绕路系数 ≤ 1.2**（路径长/净位移）、净转角 ≤ 10° | ✗ **当前在画圆**（实测绕路系数 7.29、净转角 +936°） |
| **A2** | 到位锁存 | 每段末端：距目标 ≤ 1 格（0.35 m）且**速度归零持续 ≥ 1 s** | ✅ 阈值放宽到 0.70 m 时实测已能锁存并彻底停住 |
| **A3** | 连续多段 | 一条 **≥ 5 段**路线一次跑完，全程零人工干预 | ✗ 未验证 |
| **A4** | 停靠精度 | 停稳后与目标格误差 **≤ 0.1 m** —— 地雷圆**直径仅 12 cm**，判定是"小车任意轮中心进入圆内"，这是全场最苛刻的一条 | ✗ 待调（需近目标降速/微调） |
| **A5** | 安全闸 | belief 出场地边界 **或** 单段超时 → **立即停车**并上报 | ✗ 未实现（车无感知，必须软件兜底） |
| **A6** | 情报驱动 | 收到 `FieldIntelMsg` → 生成路线 → 执行 → 上报 `/car/route_status` | 代码已就绪，未实机验 |

### B 档 —— 空地协同（**等无人机到货**）

| # | 项 | 依赖 |
|---|---|---|
| B1 | 收到无人机情报后按情报序列行驶（排雷 40 分） | 无人机链路 |
| B2 | 桥洞通道按情报选择并穿行（20 分） | 无人机链路 |
| B3 | 敌我区：按情报给的格号到位 → 车自己判蓝红 → 打击 | 无人机给点 + 车识别 |
| B4 | 全流程 180 s 内完成，两端终点判定 | 整车联调 |

---

## 五、所以现在该干的（顺序不能乱）

1. **A1 + A2**：把到达阈值调到 **> 最小转弯半径（0.24~0.26 m）** —— 先让车不画圆
2. **A3**：跑一条多段路线，证明能连续执行（"能正常运动"的实证）
3. **A4**：近目标降速 + 微调，把停靠精度从 ~0.3 m 收到 **0.1 m 量级**（排雷的硬门槛，也是全场最难的一步）
4. **A5**：加出界/超时自停
5. 1~4 全过之后，才谈 B 档

> **不要越级**：在 A1 都没过的时候去调情报链路，等于给一辆原地打转的车装导航。
