## 卡 B ｜ 航向通道：`ticksPer2PI` 原地转圈裁决（R4）

**背景**
- 配置现值 **3236.0**（2026-10-11 用户指令：直接用 v1 值；v1 真源 `src_v1\dzactuator\launch\bringup.launch.py:24` `default=3236.0` + `dzactuator.cpp:1234`，注意**不在 v1 path_executor.py**——v1 里程在 C++ 侧算）；被替换的 2309.4 来自 10-03 20:15 另一血统复标（该血统 ticksPerMeter 2776 已实测虚增 17.9% 被推翻，故其 2309.4 同源存疑）`[配置+实测]`。
- 后果量级：若值偏大 42%，"命令转 90° 实际只转约 38°" ⇒ **过桥洞（K 列）会撞侧壁**；本局路线还有 1 处 180° 原地掉头（`G10*:PIVOT`），欠转会直接毁掉掉头。
- **直线数据对该值不可辨识**（直线不激发转圈通道）——必须原地转圈实测。

**30 秒静态先验（不发车，只量一个数）**
```
ticksPer2PI_geo = 2π × 轮距 L(左右轮心距) × ticksPerMeter(3280.0)
```
| 卷尺量到的 L | 几何预期 | 对两个候选值的判读 |
|---|---|---|
| **0.110 m**（`dzactuator.h` `CARW` 定义） | **2267.0** | 2309.4 = ×1.019 ✅ / 3236 = ×1.428 ❌ |
| **0.157 m**（仓库另一尺寸，是**轴距 wheelbase**） | **3235.6** | 3236 = ×1.000 ✅ / 2309.4 = ×0.714 ❌ |

⇒ **所谓"42% 之谜"很可能只是"轮距填成了轴距"**（0.157/0.11 = 1.427）。
⚠️ 原地转时轮胎横向刮擦会把实测值抬高 ⇒ **几何值只当下界参考，最终以 R4 实测为准**。

**任务（全部由队长执行，本卡不提供远程/发车命令）**
1. **卷尺量左右轮心距**（量两侧轮胎触地点中心，**不是轴距**）→ 代入上式得先验。
2. 选**四周各 ≥1 格（建议 2 格）净空的格心**做旋转中心：**避开 K 列桥洞/隔板格、避开雷/障格**；保持 Safety 打开。
3. 每趟=**两个整圈（720°）**，地面贴 0° 基准线 + 车头对齐线；**CW/CCW 各 2 趟**（共 4 趟）⇒ 单侧滑移才暴露。
4. 三源取数：**A** 旋转起止**原始编码器计数**（左右轮取绝对值后平均 `ΔN`）／**B** 陀螺 yaw 序列（复用 `7_path.log` 的 `[T]` 行）／**C** 地面 720° 基准。
5. 回传 → 本机解析（`python _tmp_session\car_calib\capture_stop.py --local --log <回传日志> --tail 0 --json`）。

**判据（比值 `r = 实测每圈计数 / 配置值`）**
| 档位 | 结论 | 唯一动作 |
|---|---|---|
| `\|r−1\| ≤ 2%`（两方向） | 收敛 | **冻结 3236.0，不改配置**，填表留档 |
| `2% < \|r−1\| ≤ 5%` | 噪声/滑移带 | 只**重测该方向 1 趟**，三趟取中位；本档不许改配置 |
| `\|r−1\| > 5%` | 机械/轮距问题 | 先做一次机械核查（轮距/胎径/单侧滑移/地面），结论先于任何改值 |
- 交叉判据：`r_A≈1 且 r_B≈1` ⇒ 收敛；`r_A 偏离而 r_B≈1` ⇒ **正是"编码器配置错"的指纹**，`ticksPer2PI_new = 3236.0 × r_A`（**由队长另开卡**）；CW/CCW 的 `r_A` 差 >5% ⇒ 先治单侧滑移，不谈标定值。
- 改值后**必须**做"命令转 90° ⇒ 实测航向 ≈90°"验证。

**失败处置（现场安全）**：跑偏/靠近 K 列 ⇒ 立刻停、宁可废掉该趟；车被卡住（计数涨车不动）⇒ 停 → 人工扶正 → **重新对 0° 基准线重跑该趟**（半途数据作废）；Safety 锁存 → 查原因、确认车在安全格内再 `clear_safety()`，**本趟作废**。

**落盘**：`_tmp_session/car_calib/data/r4_<通道>_<YYYYMMDD>_<趟次>_<CW|CCW>.<ext>`；汇总 `r4_summary_<日期>.csv`；判定报告 `R4_verdict_<日期>.md`。三通道必须共用同一 `<趟次>_<方向>` 后缀。

## 铁律（本轮标定趟次里踩出来的）

1. **"漂移告警 0 / 吸附 13/13" 不等于里程健康** —— 吸附会把偏差抹平，真值只看**吸附前那一拍**与 `估计 scale`。
2. **先量再改**：配置值只能由"卷尺/基准线实测 + 三源互证"推动改；**改配置必须先备份、记录改前值**，并由队长另开卡。
3. **参数唯一写点是 `config/robot.yaml`**；`src/` 不得硬编码 ticks/scale。
4. **改 `ticksPer2PI` 只改**车端 `~/dzrobot/config/robot.yaml` 的 `/dzactuator` 段（该值在 dzbrain 里 0 处引用，决定航向的是车端 MCU）。
5. **现场安全优先**：旋转/掉头类动作，宁可废一趟数据，不要强行继续。
6. 多会话共改本工作区 ⇒ **动文件前先 `git status --short`**。
