## 0. 你要给我什么

```

├── images/          图片（jpg/png 均可，原始分辨率最好，不要压缩过的截图）

- LabelMe JSON / CVAT XML / VOC XML
- 只有图片没标注 → 我能用旧模型 `best.rknn` 自动预标注，你再抽查修正（半自动，最快）

```

## 2. 标签格式

### 标靶（pose 模型，需要关键点）

每行一个目标：

```
<class> <cx> <cy> <w> <h> <kx> <ky> <vis>
```

- 全部归一化到 0~1（相对图片宽高）
- `kx, ky` = **发光中心**（不是框中心）。这正是无人机云台要瞄的点
- `vis` = 2（可见）
- 只框到发光区域即可，不必框整个靶子

关键点可以自动生成：你桌上的 `标靶打击/auto_center.py` 做的就是这件事
（大津法二值化 → 最大轮廓 → 最小外接圆圆心）。我会把它改成批量处理并接进流程。

### 地雷 / 障碍物（detect 模型，只要框）

```
<class> <cx> <cy> <w> <h>
```

## 3. 类别定义（最重要，错了会扣分）

| id | 类别 | 说明 |
|---|---|---|
| 0 | `blue_glowing_target` | 蓝面 = 敌方 **可以打** |
| 1 | `red_glowing_target` | 红面 = 友方 **绝不能打**（误击 −5/次，最多 −15） |

**类别顺序一旦定下就必须告诉我是哪种**，我会同步写进 `params.yaml` 的
`class_blue` / `class_red`。训练完我还会用真实红面图跑一遍，确认策略返回 `AVOID` 而非 `FIRE`。

地雷/障碍模型的类别顺序同理，给 `classes.txt` 即可。

## 4. 数量与质量（底线要求）

| 项 | 最低 | 建议 |
|---|---|---|
| 每类图片数 | 200 | 500+ |
| 每类实例数 | 400 | 1500+ |
| 负样本（无目标） | 总图 10% | 20%（抑制误检） |
| val 占比 | 15% | 20% |

拍摄要求（决定模型在赛场能不能用）：

- **必须覆盖赛场光照**：场馆顶灯、侧光、逆光、阴影各来一批
- **距离/角度**：无人机高空俯视 + 车端云台平视都要有（本项目两端都用到）
- **发光状态**：靶子点亮/未点亮都要有
- **不要只用渲染图或网图**：域差距会导致实机直接失效
- 图片間に不要太相似（抽帧时隔 5~10 帧取一张）

## 5. 我会做的加工

1. 格式转换（任意标注 → YOLO-pose）
2. 关键点自动生成（复用 `auto_center.py` 的发光中心算法）

4. 划分 train/val + 生成 `data.yaml`

7. 把参数写进 `config/params.yaml`，跑 `run.py demo` 验证闭环

## 8. 缺什么怎么办

| 你缺 | 解决办法 |
|---|---|

| 没有负样本 | 我从比赛场地空景图里补 |
