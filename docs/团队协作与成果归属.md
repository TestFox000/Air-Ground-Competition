## 1. 组织模型与分支拓扑

```
                      main（主干，PR + 人工审核后进）
                     /        \        \        \
   members/yu-binghuan   members/huang-zongqi  ……（其余 6 位队员）
      （协调枢纽）              \
      /       |       \          （队员各自长期分支 → PR → main）
agents/    agents/    agents/
 kimi/*    trae-glm/* qwen/*     （智能体任务分支，成果合入协调枢纽）
```

- **main**：主干。任何人不直接在 main 上开发。
- **`members/<拼音>`**：每位队员一个长期分支，随主干同步，日常成果先落在这里。
- **`agents/<智能体>/<任务>`**：智能体任务分支（kimi / trae-glm / qwen，均挂靠余秉桓协调线）。
- **协调枢纽 = `members/yu-binghuan`**：三个智能体的成果一律先合入该分支，由余秉桓审核后 PR 进 main。
- **其他七位队员**：各自 `members/<拼音>` 分支直接 PR 进 main。
- **`preserve/<来源>`**：档案分支，只增不改，历史工作快照的实物账本。
- 队员日后若自有智能体，照同一模式挂靠自己的 members 分支即可。

## 5. 成员日常接入

**队员（每人一次）**：

```bash
git clone https://gitee.com/circle-of-joy/air_ground.git <工作目录>
git config user.name "余秉桓"          # 换成自己的名字
git config user.email "yu-binghuan@air-ground.team"   # 建议改真实邮箱
git checkout members/yu-binghuan        # 换成自己的 members 分支
```

日常：在成员分支上提交；`git fetch origin` 看他人进展；里程碑发 PR（compare 页选自己的 members 分支 → main）。

一键接入（2026-10-18 起）：下载单文件 `tools/onboard_member.ps1`
（raw 直链：`https://gitee.com/circle-of-joy/air_ground/raw/main/tools/onboard_member.ps1`，
main 合入前暂用 `.../raw/members/yu-binghuan/tools/onboard_member.ps1`），执行：

```powershell
powershell -ExecutionPolicy Bypass -File onboard_member.ps1 -Name <中文姓名>
```

自动完成：克隆/复用仓库 → 本仓署名配置 → 切到自己的 members 分支（名册八人自动解析）→
推送权限自检（dry-run，不上传内容）。前置条件：队员已被队长加为仓库成员（开发者权限）。

> **网页上传禁令（2026-10-18 两次事故后建制）**：Gitee 网页上传文件夹/zip 会损坏全仓路径
> （反斜杠路径 / 全组件回车污染），Windows 端全员无法合并。文件入库一律走 git/脚本；
> 发现污染跑 `python tools/repair_web_upload.py <分支> --push`（blob 零改动，纯路径重建）；
> CI 由 tests/test_repo_paths.py 拦截，agent_sync.ps1 开工自动检测（退出码 4）。详见 AGENTS.md。

**智能体（每个会话开工/收工，2026-10-18 起脚本化；契约文件 `AGENTS.md` 置于仓库根，各 AI 工具自动读取）**：

```powershell
# 开工：fetch 全分支 + 主干/枢纽/canonical/成员/智能体态势表 + 基底过期判定
#       （退出码 0 新鲜 / 2 基底过期必须先同步 / 3 站错分支）+ 创建/切换任务分支
powershell -ExecutionPolicy Bypass -File tools/agent_sync.ps1 -Agent <智能体> -Task <任务名>
# ……干活……
# 收工：只提交指定文件（-Files）或自动收集 docs/ 改动的 .md（-ChangedDocs）
#       → 署名提交（移植他人成果加 -Author 署原作者）→ 推送 → ls-remote 验证
#       → FF 合入枢纽 → 打印可发群的分享链接
powershell -ExecutionPolicy Bypass -File tools/agent_publish.ps1 -Agent <智能体> -Message "<提交标题>" -Files "文件1,文件2"
```

手工等价（脚本不可用时的后备）：

```bash
git clone https://gitee.com/circle-of-joy/air_ground.git <工作目录>
git checkout -b agents/<智能体>/<任务名> origin/members/yu-binghuan   # 枢纽最新（不可用则 canonical → main 链式回退）
# ……干活……
git push -u origin agents/<智能体>/<任务名>
# 推完必须验证：git ls-remote origin 中你的分支 == 本地 HEAD（公约铁律 3，
# 旧 post-commit 钩子带 || true，推失败也显示成功，不验证等于没推）
# 完成后：FF 合入 members/yu-binghuan，等余秉桓审核
```
