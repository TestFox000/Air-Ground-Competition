## 2 标定草案的纠错记录

**R0 的 `motion.md` 第 5 节不能直接转为现场操作单。** 以下是代码口径纠正，现场路线、运行二进制、采样完整性与操作步骤仍需下一张独立卡核验。

| 位置 | 问题 | 应采用的口径 |
|---|---|---|
| `motion.md:283` | 转向计数取左右绝对值平均 | `dzactuator.cpp:1296` 用 `(Right-Left)*2π/ticksPer2PI`。每趟应取左右累计计数增量的有符号差，再取绝对值：`ΔN=abs(ΔR-ΔL)`；每圈计数 `ΔN/turns`。原地等幅反向时，原草案少算一倍。 |
| `motion.md:308` | 从积分角度反算计数漏除 `2π` | 底盘 `:671` 发布 `ω=每帧角增量*50`。完整、唯一、未降采样的每帧可反算 `ΔN_frame=ω*ticksPer2PI/(50*2π)`；有符号求和后取绝对值。时间积分法还要求实测帧间隔与该倍率一致，不能拿丢样数据当原始计数。 |
| `motion.md:234/237/257` | N10→M10 写为六格 2.10 m | `core/geometry.py:9-12`：N10→M10 仅 0.35 m；沿 +Y 六格是 H10。这里只纠正几何，不授权该路线实跑。 |
| `motion.md:257` | 把历史 4 cm 标准直接移给新路线 | `robot.yaml:929` 原为 N10→A10、4.55 m 的复验标准；新实验若采用需明确重新制定验收。 |
| `motion.md:243-247` | 持续非零发布者仍运行时另发一次零 | 后续非零消息会覆盖零。现场操作单必须定义终止唯一运动发布者、确认持续停止的步骤，重新审阅后才可执行。 |
