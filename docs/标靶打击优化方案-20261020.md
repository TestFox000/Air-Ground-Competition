  轨道一格邻域内的静靶判误检剔除）。
- **仍缺的车端保险**（hjy 套件有、主仓 C++ 未见等价物，约半天 C++）：
  1. 红蓝联锁防抖：连续 2 帧同色才采信 + 不确定一律禁火（误击友方 −5/次）；
  2. 冷却 500→3000ms：靶被命中后约 1s 恢复，500ms 会在恢复窗口内浪费弹药；
  3. 击毁联锁（target_hp=3 后停火省弹）、激光红点联锁（依赖 laser_offset 先标定）。
- β 方案方法论：链路延迟应四段实测（曝光 33 + 流水线 267 + 云台 60 + 出光 20
  = 380ms），只按 267ms 算提前量漏掉的 113ms ≈ 1 格距离 5cm 落点偏差。
