# P1 接口约定：循迹闭环四线程

> 前置：P0 已完成（`core/ route/ pursuit/ io/`），测试 `test_geometry` 38 / `test_core` 49 / `test_contract` 56 全绿。
> 目标：**在仿真里跑通"出发 → 全程 → 终点"**，故障注入时安全停车。
> 铁律：每个任务线程只通过 `Blackboard`（高频状态）与 `EventBus`（低频事件）通信；`tick()` 非阻塞。

## 0. 任务统一构造签名

```python
class XxxTask(TaskThread):
    def __init__(self, bridge, bb: Blackboard, bus: EventBus, cfg: Config, *,
                 log=print, group=None) -> None
```
- `bridge`：`RosBridge`（车端）或 `tests/fakes.py::FakeBridge`（测试）——**鸭子类型**，只依赖下面 1 节列出的方法。
- `group`：`TaskGroup`（Safety 用它读各任务健康度）；可空。

## 1. Bridge 接口（任务只许用这些）

读：
| 方法 | 返回 | 说明 |
|---|---|---|
| `pose()` | `Pose \| None` | 米制 + 地图 yaw（换算已在 io 层完成） |
| `pose_age()` | float | 秒；无数据 = inf |
| `vision(max_age_s)` | `OffsetObservation \| None` | 过期返回 None |
| `aim_status()` | int | 0 IDLE / 1 SCAN / 2 TRACK |
| `shoot_count()` | int | 累计发数（只增） |
| `ammo()` | `int \| None` | 裁判回传剩余弹药 |
| `take_hits()` | int | 取走命中确认数（清零） |
| `manual_override()` / `manual_gimbal()` | bool | 遥控接管 |
| `take_drone_messages(n)` | list[str] | 无人机 JSON 原文 |
| `take_waypoint_commands(n)` | list[str] | 外部命令（`reset:` / 单点 / `load:`） |

写：
| 方法 | 说明 |
|---|---|

| `publish_scan_request(mode)` | 0 停 / 1 单趟 / 2 持续 |

## 3. 四个任务的职责与验收

### 3.1 `LocalizationTask`（20 Hz）
- 每拍：`bridge.pose()` → 减 `P_FIX` 修正（P1 阶段修正为 0）→ 写 `P_POSE`、`P_POSE_RAW`、`P_ODOM_AGE`。
- 有路线时：`Path.project(pose)`（带 `s_hint`）→ 写 `P_ROUTE_INDEX`/`P_ROUTE_S`。
- **到位吸附**（`fix.anchor_at_waypoint`）：当下一个航点距车 < `pursuit.arrival_m` 时，把 `P_POSE` 锚到该航点格心（不改 yaw），发 `EV_POSE_ANCHORED`，并记录该段漂移量（锚定前的偏差）。
- 漂移告警：单段漂移 > `pursuit.drift_warn_m` → `EV_DRIFT_WARNING`（限流，不刷屏）。
- 验收：给定一段带比例误差的假位姿序列，断言锚定后偏差被清零、漂移量统计正确、`P_ROUTE_S` 单调。

### 3.2 `TrackerTask`（50 Hz）
- 前置门（任一不满足 → `publish_brake()` 并 return）：无 `P_POSE`；`P_SAFETY` 非 OK；`MissionPhase` ∈ {IDLE, STOP, SHOOT, WAIT_SCAN, FINISH, SAFE_STOP}；`bridge.manual_override()`。
- 主逻辑：`Path.project` → `find_lookahead_point`（`lookahead_distance(v, cfg)`）→ `compute_command(...)` → `publish_command`。
- **桥洞直行保护**：当前航段在保护集合内（由 `route` 的桥洞点 ± `align_straight_before/after` 预计算）→ 关闭纯追踪，改用 `yaw_err × align_kp/10` 限幅 `align_steer_limit_deg`，速度 `align_straight_speed_mps`。
- 倒车段：`path.segment_is_reverse(idx)` → `reverse=True`，并 `publish_motion_state(True)`（仅变化时发）。
- 限速：接近未完成停站点 < `pursuit.approach_m` 时按 `stop_approach_speed_gain` 降速。
- 验收：① 50 Hz 稳定（拍数在容差内）；② 门条件逐条断言"该刹车就刹车"；③ 桥洞段舵角被限在 ±8°；④ 倒车段 linear_x < 0 且 motion_state=1；⑤ `compute_command` 被调用次数与节拍一致。

### 3.3 `MissionTask`（10 Hz）
- 启动：`mission.auto_start` 且延时到 → `reset`（把 belief 设为 `mission.reset` 指定格心与朝向）→ 载入路线（`route.tokens` → `parse_mission`）→ 写 `P_ROUTE` → `EV_ROUTE_LOADED` → 阶段 `DRIVE`。
- 推进：每到点（`pursuit.arrival_m` 内）发 `EV_WAYPOINT_REACHED`；到达 `shoot`/`scan` 停站点 → 写 `P_STOP_POINT`、阶段 `STOP`、发 `EV_ARRIVED_STOP_POINT`。
- 停站点三段（**各有超时，绝不阻塞**）：
  1. `SETTLE`：等底盘停稳（速度或位置连续 `settle_time` 不变）→ 超时降级进入下一段；
  2. `ACQUIRE`：等 `aim_status==TRACK` 且视觉有目标 → 超时（`lock_timeout_s`）→ 放弃本点、放行下一候选；
  3. `FIRE`：发 `publish_fire_gate(True)`，等 `shoot_count` 增量 ≥ `shots_needed` 或超时（`shot_timeout_s`）→ 关闸、放行。
  每段结束发 `EV_STOP_POINT_DONE`，阶段回 `DRIVE`。
- 终点：最后一个航点到达 → 阶段 `FINISH`、刹车、`publish_scan_request(0)`、发 `EV_MISSION_FINISHED`、打结束横幅（用时/漂移/发数）。
- 外部命令：`take_waypoint_commands()` → `reset:xxx` / `load:file` / `单点` 必须支持（调试入口）。
- 验收：① 假 bridge 全流程跑完，阶段序列正确；② 每个等待段注入"永不到达"条件 → 断言超时后仍放行（**不卡死**）；③ 单点命令能重置路线；④ 终点后阶段为 FINISH 且发过刹车。

### 3.4 `SafetyTask`（20 Hz）★ 唯一有权强制停车者
- 检查项（任一触发 → `publish_brake()` + `SAFE_STOP` + `EV_SAFETY_STOP`，**每项限流一条日志**）：
  1. `P_ODOM_AGE > safety.pose_timeout_s`（定位失联）；
  2. 越界 `not geo.in_bounds(x, y, pursuit.map_safety_margin_m)`（★ 顶层生效，修旧版 PIVOT 蠕动无保护的缺口）；
  3. 任一任务 `TaskHealth.state == FAULT` 或心跳年龄 > `safety.task_stall_s`；
  4. 收到 `EV_TASK_FAULT`。
- 恢复：条件全部解除且人工/任务显式 `clear` → `EV_SAFETY_CLEAR` + 写 `P_SAFETY`（P1 先要求显式 `clear_safety()` 调用，避免抖动反复启停）。
- 写 `P_SAFETY`（`SafetyState(ok, reasons, since)`）。
- 验收：① 五项故障逐项注入 → 断言刹车次数 ≥1 且 `P_SAFETY.ok == False`；② 恢复后需显式 clear；③ 越界坐标（旧版 PIVOT 分支那种）也被拦。
