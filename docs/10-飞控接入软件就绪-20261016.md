## 3. 接入路径（按优先级）

**① 主路径：SSH + 仓库工具**（等四件套入库后，在本线仓库副本执行）

```bash
set AG_ORIN_PASS=******     # 见 08 文档，duzhong
python tools/uav_link.py run --host 192.168.55.1 --orin-user duzhong   # 遥测+黑匣子
python tools/flight_console.py --host 192.168.55.1 --user duzhong      # 面板+应急指挥
python tools/uav_link.py ctl stack-status                              # 只读看栈状态
```

注意 `uav_link.py` 默认机载用户是 `nvidia`，本机 Orin 是 `duzhong`，**必须带 `--orin-user duzhong`**。

**② 备用路径：MAVLink 直连**（实机探测后再决定是否可用）

```bash
python mavlink_probe.py                       # 被动监听 UDP 14550，15s
python mavlink_probe.py --active 192.168.55.1 # 主动发 GCS 心跳勾引 PX4 回包
```

收到 HEARTBEAT → 开 QGroundControl（默认自动监听 14550）；无心跳 → 回到路径 ①。
