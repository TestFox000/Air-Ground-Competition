## 最快用法

1. 同机 agent：把 `docs/项目总览_AGENT_20261020.md` 的绝对路径给它，配 `10_提示词模板.md` 模板 B。
2. 网页版 agent：传 `packs/L1_接管包.zip` 里的 7 个文件（或解压后逐个传 .md），配模板 B。
3. 只要“了解一下”：贴 `00_一页纸.md`，配模板 A。
4. 本轮循迹执行：**36文第7节为技术路线；三包已交回，当前先转37文第4节给DeepSeek集成**，入口D:\User\Desktop\交回包。36§6.1/6.5的基线与交回契约、第4节部署要求继续有效。R3已以实车证据不足收口，§6.6续R3及10-20现场时间为历史。31/33/35保留历史，不重开整轮。旧压缩包未重打，不含30–37新派工文，L2阅读包不能直接当完整开发快照。
