# 仿真台（小车插件内）· 交付说明

> 卡 t21。把 dzbrain 离线仿真做成 `dsh-dzrobot-ssh` 插件里的第 5 个工具：一键跑仿真（速度档 + 误差注入）→ 指标 / 路线图 / 历史对比，**不连小车**。
> 宿主半边（`index.js` 路由 + `src/simbench.js`）由队长打好，本卡补齐页面、面板入口、部署与实测（含 t24 §11.2 后的指针改指权威真源）。

## 1. 交付物（源码树 = `dzrobot_v2/dsh-plugin-dzrobot-ssh/`）

| 文件 | 作用 |
|---|---|
| `sim.html` | 自包含页面（纯原生 JS、无外部 import；中文 UI）：参数表单 + 结果指标 + 路线图预览 + 历史两行对比 |
| `src/simbench.js` | 宿主半边（本卡**新增根指针 + 修正指标解析**，见 §5） |
| `client.js` | 面板第 5 行「仿真台」（`mode:'external'`）+ 烧瓶图标 + `store.origin` + 中英字典 |
| `package.json` | `0.3.0 → 0.4.0`，`files` 加 `sim.html` |
| `sim-root.json` | 工作区指针（**三处副本同值**）：`{"root":"D:\\User\\Desktop\\比赛存档\\v1\\dzrobot_v2"}` = 权威真源；根因见 §6-3 |

## 2. 接口表（`GET/POST /api/dzrobot-ssh/...`）

| 方法 | 路径 | 入参 | 出参 |
|---|---|---|---|
| GET | `/sim.html` | — | 页面（`text/html`） |
| GET | `/sim/root` | — | `{root, ok}`：工作区绝对路径 + 是否含 `src/dzbrain` |
| POST | `/sim/run` | JSON：`{label, overrides, inject, maxSteps}` | `{ok, record:{id,at,label,overrides,inject,maxSteps,simRoot,simRootSource,configMd5,mapMd5,status,exitCode,seconds,metrics,files,stderrTail}, stdoutTail}` |
| GET | `/sim/history` | — | `{ok, runs:[record×≤50]}`（台账 `artifacts/sim/run_meta.jsonl`，**追加不覆盖**） |
| GET | `/sim/artifact` | `?path=<run>/<file>` | 产物文件（白名单 `.svg/.csv/.json/.txt`；`..`→403，非白名单→404） |
| POST | `/sim/check` | — | `{ok, results:[{id,name,exitCode,timedOut,tail}]}`（config_selfcheck + route_check） |

> **台账 `run_meta.jsonl` 不可经 `/sim/artifact` 下载**：它是 run 子目录的**兄弟文件**（`artifacts/sim/run_meta.jsonl`），
> 而该路由只服务 `<run>/<file>`。要台账走 `GET /sim/history`（或直接读 `<root>/artifacts/sim/run_meta.jsonl`）。
> 调用形状**只有** `?path=<run>/<file>` 一种：`?run=…&name=…`、`?id=…` 都是别的形状 → **404**（不是"文件不存在"）。

## 3. 参数表（页面字段 → 请求 → `sim_cli` 参数）

| 页面字段 | 请求字段 | 落到命令行 |
|---|---|---|
| 备注名 label | `label` | 台账 `label`（同时进 `run id`） |
| 巡航速度档 0.15/0.35/0.40/自定义 | `overrides["pursuit.cruise_speed_mps"]` | `--set pursuit.cruise_speed_mps=X` |
| 速度比例误差 / 偏航漂移 / 位置噪声 / 指令延迟 | `inject.{speed_scale_err,yaw_drift,pos_noise,latency}` | `--speed-scale-err/--yaw-drift/--pos-noise/--latency` |
| 到位吸附开关 | `inject.anchor:"on"` | `--anchor` |
| maxSteps（留空 = 全程） | `maxSteps` | `--max-steps N` |

> 铁律：**只读 config**（改参数一律 `--set`），产物只落 `<root>/artifacts/sim/<run id>/`（gitignore 内）。

## 4. 部署步骤（本机实测可用；`$S`=源码树、`$I`=`~/.dsh/profiles/desktop/node_modules/dsh-dzrobot-ssh`、`$O`=安装来源树）

```powershell
$S='D:\User\Desktop\比赛存档\v1\dzrobot_v2\dsh-plugin-dzrobot-ssh'; $I="$env:USERPROFILE\.dsh\profiles\desktop\node_modules\dsh-dzrobot-ssh"; $O='D:\User\Desktop\dzrobot_v2\dsh-plugin-dzrobot-ssh'
foreach($f in 'index.js','src\simbench.js','sim.html','client.js','package.json'){ Copy-Item "$S\$f" "$I\$f" -Force; Copy-Item "$S\$f" "$O\$f" -Force }
foreach($p in $S,$I,$O){ '{"root":"D:\User\Desktop\比赛存档\v1\dzrobot_v2"}' | Set-Content "$p\sim-root.json" -Encoding utf8 }  # 三处同值：指权威真源（t24 §11.2）
foreach($p in $S,$I,$O){ foreach($f in 'index.js','src\simbench.js','sim.html','client.js','package.json'){ "{0} {1}" -f (Get-FileHash "$p\$f" -Algorithm MD5).Hash, $f } }  # 三处逐文件 md5 应相等
Invoke-WebRequest -Uri 'http://127.0.0.1:19387/api/dzrobot-ssh/reload' -Method POST        # 宿主热换（不回写源码，不重启 DSH）
```

验收 6 条（实测命令即 `Invoke-WebRequest`）：`GET /sim.html`→200 且含 `<title>dzbrain 仿真台 · dzrobot-ssh</title>`；
`GET /sim/root`→`ok:true`；`POST /sim/run {"label":"smoke","maxSteps":300}`→`exitCode=0` 且 `metrics` 有值；
`POST /sim/check`→两工具 `exitCode=0`；`GET /sim/history`→含该 `label`；`GET /sim/artifact?path=<run>/<file>`→200（形状只有这一种，见 §2 注）。

## 6. 已知边界

1. **页面刷新由用户执行**：面板第 5 行与图标在 `client.js` 里，浏览器刷新后可见 —— 本题**待用户刷新验证**，不是"打开即生效"。
2. **指标键集与形状**：`record.metrics` = `finished`(bool) + `time_s`/`rms_m`/`length_ratio`/`out_of_bounds`（数值，**出现时必须为 0**）；
   `exitCode`/`status` 在 `record` **顶层**，不在 `metrics` 里。**历史对比勿把缺键当 0**：首条历史（`maxSteps` 截断跑）
   **没有** `out_of_bounds` 键 —— 页面按"缺键显示 `—`、不参与 Δ"处理，别当 0（否则会得到"越界 0→0 无变化"的假结论）。
   另：`maxSteps` 冒烟 ≠ 全程 —— 300 拍时 `finished=false`、`rms_m=0`（起步直段）、`length_ratio` 只是局部值；要 6 项指标都有意义须留空 `maxSteps`。
3. **`sim-root.json` 指向权威真源**（`比赛存档\v1\dzrobot_v2`；t24 §11.2 后按队长指令改，改前指 `D:\User\Desktop\dzrobot_v2` 旧副本）。之所以必须改：两份 `robot.yaml`/`map.yaml` **逐位相同**，跑错副本**不会自我暴露**。
   pnpm 重装会丢该文件（届时 `/sim/root` 如实 `ok:false`，不静默）；`DZROBOT_SIM_ROOT` 优先级最高；**改指针须队长明确指令**。
4. **插件自带 `scripts/check-divergence.mjs` 在归档树里 exit=1**（4 条 FAIL 均为"profile/pnpm-lock 声明的是原树"；原树跑 exit=0）：本卡**未改** profile / pnpm-lock（DSH 安装配置，不在边界内），改用"同代码同步三处 + md5 校验"消除"跑的不是我改的那份"的风险。
