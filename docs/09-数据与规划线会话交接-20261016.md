## 7. 关键教训（新会话别再踩）

1. 场地图与代码模型可能脱节数年——**一切拓扑以现场核实为准**（今天的 mb=5→6 就是活例）
2. 合并多副本时先查有没有活跃会话（mtime<10min 的文件），有就只读寄存
3. `git rebase --continue` 卡住时别 `checkout -- .`（会把已应用的提交变空被丢）
4. Dijkstra 边循环里加约束要三个维度想清：进格/出格/转向；测试不止测期望路径，还要测"不期望的路径不存在"
5. 测试场景几何会随物理模型修订失效（口袋测试三次重写），场景注释里必须写清几何前提
