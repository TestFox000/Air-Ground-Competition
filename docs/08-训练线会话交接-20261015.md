## 4. 今日修复的 bug（重要经验，新会话勿再踩）

1. **sweep fn 覆盖 bug**：`fn[c] =` 应为 `fn[c] +=`（每帧覆盖致 FN 全丢、精度虚高 2.5pp）。已修，selftest 单帧用例测不出此 bug
2. **merge 标签路径**：`f.parent.parent/"labels"` 拼出 `images/labels/`（应为 `f.parents[2]/"labels"`）→ 合并集无标签训练秒退
3. **CP 贴图丢背景标签**：多进程版漏保留背景原标签 → 1000 张图原生目标全变假负样本（v2fix 已修+重建）
4. **`rng.randint(1<<30)`**：random.Random.randint 需两参（numpy 才可单参）
5. **yolo11s.pt 损坏**：断续下载残留致 ultralytics 校验失败循环重连 GitHub → 学术加速重下修复
6. **pkill 自匹配**：远端命令行含目标字符串字面时 pkill -f 杀死自己 shell → 用 `pattern[.]py` 正则技巧或拆分连接
7. **paramiko + nohup**：nohup 子进程持有 channel fd 致 read 卡超时 → `(nohup ... &)` 括号脱离 + 短超时容错
8. **PS 5.1**：`&&` 不支持；`$var` 双引号内被本地插值；python -c 单引号传参丢双引号 → 一律用脚本文件
