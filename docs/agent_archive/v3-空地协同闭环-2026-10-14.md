### 4.3 铁律与边界

- **只读 config**：改参数一律 `--set` 或 `--config 副本`；产物只落 `<root>/artifacts/sim/<run id>/`（gitignore 内）；**`config/**` 与 `src/dzbrain/**` 零写入**。
- **改点位三步**：① 写 `map_override/map.yaml`（只替换 mines/obstacles/bridges 三行）+ `robot.yaml` 逐字副本；② `plan_route.py --config 副本 --map override图 --emit json --check --quiet` **只读**重规划；③ sim 用 `--config 副本` + `ROBOT_MAP=override图`。
- **seed 语义**：只影响**含随机源**的仿真（位置噪声/偏航漂移）。默认无注入时**四次跑（seed 7/7/8/留空）traj.csv 哈希全同** = t20 基线。
- **两个现场陷阱**：① `sim_cli` 的路线**文件**解析按空格/逗号切词 ⇒ 末点 `N5,y` 被切成独立 token 报错，故 `route.tokens.txt` 已剥后缀（剥与不剥 traj.csv 逐字节相同）；② 现场 YAML 是 CRLF，解析前必须归一换行。
- **`sim-root.json` 指权威真源**：两份 `robot.yaml`/`map.yaml` 逐位相同，**跑错副本不会自我暴露**；pnpm 重装会丢该文件（届时 `/sim/root` 如实 `ok:false`）；`DZROBOT_SIM_ROOT` 优先级最高；**改指针须队长明确指令**。
- **部署对账口径 = 6 文件 × 3 副本**（源码树 / 安装副本 / 来源树 `D:\User\Desktop\dzrobot_v2\...`）。`scripts/` **不**进 `package.json#files`（加了会让自带 `test-package-files.mjs` 立刻 FAIL，它把"scripts 不被声明"当判别力负样本）。
- **页面刷新由用户执行**：面板第 5 行在 `client.js` 里，t21/t25/t27 都不声称"打开即生效"。

### 4.4 t21 修掉的真 bug（仍在保护中）

### 10.3 新增铁律

- **车侧栈必须最后起，且起之前无人机侧已在线**——顺序反了会让 47 s 等待窗口耗完，车用默认洞出发，误判"情报没生效"。
