## 7. 术语

| 术语 | 含义 |
|---|---|
| token / 点 | 路线上的一个航点（格心序列，可带 `R:` 倒车、`:PIVOT` 原地转、`*` 停站） |
| 停站 | 到点后停车执行动作（mine 压雷 / shoot 射击 / stop 普通停） |
| 双停站 | 靶板两侧各一射击停站；当前 tour 只出单停站 = 缺陷 |
| 穿洞 | 穿过 K 列桥洞；U 形赛道要上下半场各一次、方向相反 |
| layout | 无人机侦察得到的「已知格集合 + 要素」，带版本，154 格为完整 |
| StepLoop | 机侧按段下发、车端逐段规划执行（WAIT_LAYOUT→PLANNING→DRIVING→SEGMENT_DONE） |
| belief | 车端对自身所在格的信念（投影结果） |
| SAFE_STOP | 安全闩锁；部分原因（`yaw_untrusted`）永不复位，必须重启栈 |
| known-red | 已登记已裁决的回归红；名单外任何一红 = 新增红 |
| PIVOT | 原地转向 token；tracker-safe 禁 180°，tour 支持 |
| 三引擎 | `tour`（现役）/ `tracker-safe`（降级候选）/ `global_planner`（仅参考，不得转正） |
