| 层 | 载体 | 管什么 | 周期 |
|---|---|---|---|

## 2. 判定逻辑

1. **端口 19387 无监听** → DSH 进程死了 → `Start-Process` 重启应用。
2. **端口活着，但两个存活源都超过 20 分钟没刷新** → 会话假死 → 聚焦 GUI，先送 `/goal resume`，再敲「继续」。
   - 双源 = `heartbeat.txt` 的 mtime 与**会话日志** `session.v4.jsonl.zstd` 的 mtime，取较新者。
   - 只看心跳文件会把长工具调用误判成假死；v1 实测误报过一次 1096 分钟。
3. **恢复时无条件先送 `/goal resume`**。原因：`dsh-goal` 的 `agent/session-start` 处理函数每次会话启动都强制 `activation='disarmed'`（`dsh-goal/index.js:172-173`），唯一重新武装路径是 `ctx.goals.resume()`（`index.js:276`，命令面即 `/goal resume`）。不 resume 的话「继续」只换来一轮，之后自动续跑永久失效。
   - 无条件送的理由：disarm 不止 session-start 一条路（`agent/error` flush 失败也会 disarm），而目标已武装时 resume 只回一条不发模型的命令错误，零 token 代价。
4. 两次恢复动作至少间隔 **10 分钟**（冷却）。
5. `PAUSE` 文件存在则完全休眠（操作者在场时不打扰）——原在 `.zhiyuan/PAUSE`，已随目录清理归档。

## 3. 四个实测过的坑

| # | 坑 | 后果 | 处置 |
|---|---|---|---|
| 1 | 任务计划被静默禁用 | 第 2 层整层消失且 `watchdog.log` 一行不写（脚本没被调起）。2026-10-16 17:35 实测到 `Disabled`，`NumberOfMissedRuns=2`；TaskScheduler Operational 日志默认关闭且开启需管理员，「谁关的」查不到 | 每次回来先验三项，靠 `poll.ps1` 告警 |
| 2 | `DisallowStartIfOnBatteries` 默认 `true` | 笔记本拔电源后守护器**静默罢工** | 与 `StopIfGoingOnBatteries` 一起置 `False`；新建任务必须显式带 `-AllowStartIfOnBatteries -DontStopIfGoingOnBatteries` |
| 3 | `watchdog.ps1` 存成 UTF-8 **无 BOM** | 任务计划用 `powershell.exe`(5.1)，无 BOM 按 GBK 解码，源码里的「继续」变成乱码 `缁х画` 被 `SendKeys` 原样敲进 GUI —— 叫不醒 | 必须存 UTF-8 **带 BOM**；改完复验 `EF BB BF` |
| 4 | 屏幕锁定 | `AppActivate` 失败，只能重启进程不能敲字，日志写 `RECOVERY UI unavailable` / `RECOVERY_FAILED no channel` | 睡眠/灭屏/休眠（AC 与 DC）全设「从不」；控制台锁屏超时 GUID 本机 `powercfg` 读不出，需手动关动态锁/屏保 |

另：`LastTaskResult` **267009/0x41301 = 正在运行**、**267011/0x41303 = 从未运行**，都不是故障，`poll.ps1` 已排除，否则每 30 分钟报假警。

## 4. 例行自检（三项）

> 以下命令**仅在重建守护器后适用**；两个任务计划已于 2026-10-27 注销，现在执行会报 `No MSFT_ScheduledTask objects found`。

```powershell
$t = Get-ScheduledTask -TaskName '纸鸢心跳守护'
$t.State                                  # 要 Ready，不能是 Disabled
$t.Settings.DisallowStartIfOnBatteries    # 要 False
$t.Settings.StopIfGoingOnBatteries        # 要 False
(Get-ScheduledTaskInfo -TaskName '纸鸢心跳守护').NumberOfMissedRuns   # 该是 0
```

BOM 自检：

```powershell
$b=[System.IO.File]::ReadAllBytes("$PWD\watchdog.ps1"); ($b[0..2] | ForEach-Object { $_.ToString('X2') }) -join ' '   # 应为 EF BB BF
```

手动跑一次守护是安全的：会话日志新鲜时它什么都不做、不写日志。
