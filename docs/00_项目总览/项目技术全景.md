## §0 导读

### 0.1 一句话结论

车端 `dzrobot_v2` 是一个**单进程 8 线程**的决策层（`dzbrain`）驱动的阿克曼小车，跑在 RK3588S 上；机端 `dzsmartscout` 是一个**回放式路径跟随**无人机（人先遥操飞一遍、录轨迹、之后照轨迹飞），跑在 Jetson Orin Nano 上；两者靠 ROS2 DDS（车域号 118 / 机域号 0）通过两条语义相反的话题通道通信。截至本轮审计，**车端能跑单趟但未闭环，无人机从未自主飞行**，空地链路 v1 情报门控真机通过、v2 步进循环仍为离线 + 一次段链路。

## §1 项目是什么

### 1.1 赛事与任务

| 项 | 事实 | 证据 |
|---|---|---|
| 赛事 | 全球校园人工智能算法精英大赛 · 算法应用赛 · **空地协同侦排挑战赛**（北京渡众） | `docs/20_资料索引库/赛事与治理/01_规则与场地.md` |
| 核心赛制支点 | 规则明写「地面机器人视角受限无法识别桥顶标识，**必须由无人机**高空侦察」 | 规则 p8 |

| 计分 | 蓝面得分、红面扣分（队长澄清 + 代码默认） | `core/config.py:273`〔档〕 |

### 1.2 场地

| 项 | 值 | 证据 |
|---|---|---|
| 场地 | 4 m × 5 m，无四周围挡 | 规则 p3-4 |
| 单元格 | **0.35 m**，14 列（A~N）× 11 行 = **154 格** | `core/geometry.py:27-43`〔实〕 |
| 隔板 | 恒在 **6/7 行之间**，横跨 **D~N** ⇒ 只有 A/B/C 可上下 ⇒ 赛道被迫 **U 形** | `geometry.py:37-43`〔实〕 |
| 起 / 终 | 车起 **N10**，车终 **N5** | `config/map.yaml:29-30`〔档〕 |
| 雷 | 随机 8 格，直径 12 cm 彩图平贴格中央，**只能视觉** | 规则 p5-6 |
| 障 | 随机 8 个装水彩桶，格中央；有高度、遮 LOS | 规则 p6 |
| 打击区 | 相连两格，单局仅 1 处，内放红/蓝面移动靶 | 规则 p7 |
| 桥洞 | 2 处，K 列，35 cm 架空；**每局随机指定可通通道，通行状态标在桥顶箭头** | 规则 p8 |

### 1.3 目标（车端任务分解）

1. 读取无人机下发的**布局 layout**（已知格集合 + 要素，known=154 为完整）。
2. 规划一条经过**压雷格、避开障碍、穿过桥洞、停射击站**的路线。
3. 纯追踪循迹执行，到停站执行动作（压雷 mine / 射击 shoot / 普通停 stop）。
4. 到终点 N5。

## §2 系统架构总览

### 2.1 顶层系统图

~~~text
        无人机 dzsmartscout（Jetson Orin Nano + PX4 + Livox MID-360）
        FAST-LIO → 定位；相机 → 格/箭头感知；PX4 ← uXRCE-DDS 921600
                          │ ROS2 DDS（域号是命门：车 118 / 机 0）
      /nav/waypoint（RELIABLE）│ /dzlink/*（BEST_EFFORT）
                          ▼
   小车 dzrobot_v2（RK3588S · ROS2 Humble · 域 118）
     dzbrain 单进程 8 线程：定位/安全/循迹/任务/云台/修正/无人机/遥测
     dzactuator（底盘） dzrknn_dataprocess（云台+开火判据） dzjudgment（激光/裁判） det_node（RKNN 检测）
~~~

### 2.2 车端（`dzrobot_v2`）

- **计算平台**：RK3588S（Orange Pi 5 Pro，aarch64），Ubuntu 22.04，ROS2 Humble，Python 3.10。
- **决策层形态**：`dzbrain` **单进程 8 任务线程 + 4 个 ROS executor 线程**，入口 `python3 -u -m dzbrain.main`（`start_all.sh` 第 7 步）。
- **域号**：`ROS_DOMAIN_ID=118`，唯一真源 `dzros.env`。
- **部署**：唯一入口 `tools/deploy_to_car.py`（probe/backup/push/build/verify/all，sha256 对账）；**刻意不推 `config/map.yaml`**（D-019）。
- 详细见 **A 篇**（决策核心）、**B 篇**（任务层）、**C 篇**（硬件/配置）。

### 2.3 机端（`dzsmartscout`）

- **计算平台**：Jetson Orin Nano（Ubuntu 22.04.5，kernel 5.15.185-tegra，6 核，RAM 7.6 G）。
- **雷达**：Livox MID-360，10 Hz / 19968 点每帧；IMU 200.9 Hz。
- **相机**：LRCP AR0234 UVC（`/dev/video0`）。
- **飞控**：Matek `HKUST_UAV_NxtPX4`；uXRCE-DDS **921600**（ttyACM0/1 有冲突）。
- **软件**：ROS2 Humble + PX4 + FAST-LIO + 4 个自研 C++ 包（约 4742 行）+ 感知 Python。
- **关键事实**：这是**回放式路径跟随**系统，**不是自主飞行**；截至本轮**飞控板从未连接**，**从未自主飞行**；唯一真机闭环的是**无人机 → 小车**链路。
- 详细见 **D 篇**。

### 2.4 空地链路

两条**语义相反**的通道：

| 话题 | 类型/QoS | 方向 | 用途 |
|---|---|---|---|
| `/nav/waypoint` | `std_msgs/String`，**RELIABLE depth 10** | 机 → 车 | 路线 token（`load:`/`reset:`/多点）与段目标 |
| `/dzlink/drone_to_car` | JSON，**BEST_EFFORT depth 10 VOLATILE** | 机 → 车 | 情报、布局版本、心跳 |
| `/dzlink/car_to_drone` | JSON，BEST_EFFORT | 车 → 机 | 车态、ack、覆盖账本 |
| `/aim/fire_gate`、`/nav/scan_request` | — | 车内 | 开火/扫描闸门 |

**铁律**：BEST_EFFORT 发 → RELIABLE 收 = **静默 0 条**，但两端端点计数各为 1。**ack 是唯一硬证据**。心跳超时 **3.0 s**、情报过期 **30.0 s**、桥洞窗口 **2.0 s**。

详细见 **E 篇**。

## §5 核心逻辑速查（公式与判据）

> 以下公式/判据均从代码逐行读出，详细推导与参数表见各篇。**不确定处写「未核实」**。

### 5.1 坐标与几何

- 格 ↔ 米：`block_to_meters` / `meters_to_block`（`geometry.py:54-191`）。
- 越界策略不对称：`index_to_block` **夹紧**到边缘格，`block_to_index` **抛错**（`geometry.py:54-74`）—— F-BUG-10。

### 5.2 纯追踪循迹（`pursuit/controller.py`）

- 舵角：**δ = atan(gain · 2L · sinα / ld)**，L = 轴距 0.157 m。
- 前视距离：**ld = clamp(k_v · v, [lookahead_min, lookahead_max])**，k_v = 1.2。
- 曲率限速：**v = sqrt(a_lat / κ)**。
- 舵角速率限幅：30°/120°/s（`controller.py`）。
- 倒车符号：×0.6 × sign（`controller.py`）。
- 零 Twist = **刹车**（底盘 1 s 看门狗）。

### 5.3 弧长投影与 PIVOT / 倒车（`pursuit/path.py`）

- `Path.project()`：窗口搜索 + 等距裁决四级顺序 + `back_m`/弧长地板 + 顶点前视重投影。
- **PIVOT 判据是车头转角，不是行进夹角**：`corner_turn_deg ≥ 135°`（`path.py:228-241`）。现场路线 PIVOT 永不触发，折返靠 `R:` 倒车段。
- 倒车段车头角 = 行进角 + 180°。
- **投影不是全局最近点**：带 hint 的窗口搜索有吸收态，两套自愈（Localization 卡死自愈 / Tracker relock）是救命绳。

### 5.4 规划器（`route/planner.py`）

- **三引擎**：`tour`（现役）/ `tracker-safe`（降级候选）/ `global_planner`（仅参考，不得转正）。
- 状态机 + A*；时间预算 tour 2.0 s / tracker-safe 10 s（`mission.py:439`）。
- 出发前校验规则 **R001~R014**（`route/validate.py`）。
- 随机图求解率 **43.75%**（tour 28/64）；失败主因是结构约束（穿洞 2/3 次 19 条；无可用射击停站 4 条）。

### 5.5 停站三段式与到达判据（`tasks/mission.py`）

- 到达 = 弧长越过 ∧（横偏 ≤ `pursuit.arrival_m`=0.12 m ∨ 距格心 ≤ 0.24 m）。
- 停站三段：SETTLE 0.8 s / ACQUIRE 18 s / FIRE 30 s（各自独立超时）。
- 到站级硬死线 `mission.stop_deadline_s`（默认 = `mission.shoot_timeout_s` = 30 s）。
- 拐角绕圈兜底：12 s 停滞 或 累计转 360°（PIVOT 期间豁免）。

### 5.6 安全层 SAFE_STOP（`tasks/safety.py`）

- **唯一强制停车者**；五道看门狗。
- `yaw_untrusted` 等原因**永不复位**，必须重启栈。
- 启动竞态修复 = `startup_grace_s` 3 s + `never_had_pose` + inf 持续性（`safety.py:238-289`）。

### 5.7 云台 PID 与开火（`tasks/aim.py` + `dzrknn_dataprocess`）

- **5 套 PID 口径并存**：tuned / v1 / pid 增量式 / 俯仰符号钳位 / 车体前馈；当前 `track_mode: pid` + `pid_enable: true`。
- 开火链路：`det_node → dzrknn_dataprocess → dzjudgment → 激光`；判据含 in_fire_zone + aim_ready + 弹药 + 冷却 + 类别锁 + 连续帧。
- `/LaserShot_Command` 订阅数必须 = 1（少 `dzjudgment` 时激光不亮且**无报错**）。

### 5.8 串口帧协议（→ C 篇 §2.2/§2.4）

- **底盘下行 23B**：`0xA5 0x5A` + 舵角/方向/速度/激光/云台Pos0-1/Spd0-1/Time0-1/Fun/ID/重置/语音/累加和。
- **底盘上行 34B**：`0x7B 0x1F` + 轮速/电池/IMU/云台反馈/rx32。
- **裁判开火帧**：`B5 5B 03 21 01 25`；上行 `0x02/0x03/0x04/0x07`。

### 5.9 配置 SCHEMA（`core/config.py`）

- **本轮实数 205 个键**（`config.py:63-561`）；未登记键会被告警而不是静默忽略。
- 旧键迁移映射 46 条（`config.py:665-724`），方向 = 新键 ← 旧键，迁移**不删旧键**（双向兼容）。
- `/dzbrain` 段映射为**空前缀**（避免顶层裸键让 `--params-file` 解析失败）。

## §11 术语表
