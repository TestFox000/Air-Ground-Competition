## 0. 三十秒决策表

| 情况 | 手段 | 预期结果 |
|---|---|---|
| 任务完成/想收工 | **LAND**：面板按 `L` 输 `y`；或 `python tools/uav_link.py ctl land` | 原地自管降落，落地自动上锁 |
| 掉 OFFBOARD / 漂移 / 定位跳变 / 断流 / 低电 | **不用动手**：机载守卫 1.5s 内自动 LAND（见 §2）；人工可提前按 `K` 停 GOTO 悬停 | 自动落地 |
| **即将撞人/撞物/狂奔** | **KILL**（电机立即停转）：面板按 `!` 输 `kill` 回车；或 `python tools/uav_link.py ctl kill` | 电机停转，坠机止损 |
| 落地后电机还在转 | **DISARM**：面板 `X` 输 `disarm`；或 `ctl disarm`（空中会被状态机拒绝，正常） | 上锁 |
| 软件全失联（SSH 断、面板死） | **物理断电**：先确认桨停或遮挡，再拔电池插头（见 §3） | 全机断电 |
| 遥控器在手且配了急停通道 | RC 急停开关（**待配置核实**，见 §4） | 电机停转 |

原则：**能降落就不 KILL，能 KILL 就不上手拔电**。KILL 和拔电都会摔机——它们的意义是
"撞人之前让电机停转"，不是保飞机。

## 2. 机载自治守卫（不经过笔记本、不受链路抖动制约——最快的一层）

`tools/orin_watchdog.py` 常驻 Orin（tmux `agup:wd` 窗口），10Hz 判定拍，介入命令机上本地发出：

| 规则 | 触发 | 动作 |
|---|---|---|
| BLIND | armed 空中遥测断流 >1.5s | LAND |
| OFFBOARD_LOST | 空中掉出 OFFBOARD 且非降落态，持续 1.5s | LAND（`--no-land-on-offboard-loss` 可关，飞手接管演练时关） |
| POS_JUMP | 位置连续 2 帧水平跳变 >2m | LAND |
| BATT_CRIT | 空中电量 <10% | LAND |
| FAILSAFE | failsafe 置位持续 0.5s | LAND（PX4 自身动作之外的加固） |
| TILT_RUNAWAY | 空中倾角 >60° 持续 0.8s | **KILL——仅在 `--enable-kill` 启动时授权**；否则只告警留痕 |

- **当前在机运行状态：LAND 介入开、KILL 关**（倾覆狂奔会红色告警但不会自动停电机）。
  要授权自动 KILL：`tmux kill-window -t agup:wd` 后重启窗口命令追加 `--enable-kill`。
- 每条介入都写 `~/ag_flight_logs/watchdog/<会话>/watchdog-<pid>.jsonl`（事件级 fsync），
  面板 `!`/`L` 等人工命令由黑匣子审计留痕，两条链互不丢。
- 验证手段：`--dry-run` 只判定不发令；`--check` 只打订阅注册。规则引擎 17 项单测全过
  （`tests/test_orin_watchdog.py`）。

## 3. 物理断电（最后手段）

1. **先喊**："断电！"让全场知道飞机要掉/已失控。
2. **确认桨已停或必然撞人**才靠近：桨在转时人体任何部位不进入旋转平面。
3. 从**机尾方向**接近，蹲低，直拔电池主插头（XT 系列捏插头本体，不拽线）。
4. 若飞机已坠地但电机还转：先用一切手段 KILL/DISARM；无效再上断电，
   接近路径避开桨平面，必要时用硬质物品（木板/灭火毯）覆盖螺旋桨后再拔电。
5. 断电后再查：黑匣子 `~/ag_flight_logs/` + 守卫日志 + `uav_link.py logs` 取回复盘。
