## 3. ★★ 作废结论：「变异测试无法在被测闭包内自证」（1014 版 §4）

**作废。** 该结论基于三次脚手架写法 bug（判据写错 / 变异输入不一致 / 谓词恒假），把**实现问题误判成原理不可能**。

- t7 已落地**可运行的内置自证段**（测试文件尾部「变异自证段」）：可行写法 = 同一谓词 + 同一输入，分别在真实现与内存替换出的退化副本上求值，要求「真实现 true 且退化 false」+ 「锚点命中数恰为 1」护栏。恒真谓词坏在退化侧、恒假谓词坏在真实现侧 ⇒ 两侧堵死。reviewer2 曾实测锚点失配会响亮读红。
- 外部变异手法仍然有效且更强，本队三层各自独立做齐：
  - t1（落盘方）：M-A/M-B/M-C1/M-C2/M-D/M-E 六变异体（%TEMP%\t1_mut\run_mut.mjs，复制插件目录 + `DZROBOT_SIM_ROOT` 指回工作区）；
  - t2（复验方）：M1/M2/M3 独立锚点（%TEMP%\t2_verify\t2_mut_run.mjs）；
  - t3（审查方）：N1/N2/N3/N4 另一套独立锚点（%TEMP%\t3_mut_*）。
  - 三方对照组全绿、变异体红在预期断言，**8 条新断言每条 ≥2 个不同来源的变异体覆盖**。

⇒ 后续约定：**内置自证段管"本文件观测面内"，外部变异管"跨文件调用链 + 真跑才可见的层"**；两者都要，不再是二选一。
