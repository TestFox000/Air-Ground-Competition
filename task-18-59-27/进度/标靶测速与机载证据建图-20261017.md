## 二、最佳打击点与火控模型

### 停靠与预瞄
- 停靠位：**蓝面侧正交邻格**（路由 `shoot_cells` 已有此概念），车头正对轨道端点。
- 云台**预瞄轨道近端端点**：端点是裁判地图已知的固定世界坐标，预瞄不依赖跟踪环路。

### 开火窗口（主策略——端点静止打击）
靶到近端端点时：距离最近（~0.35m，像素尺度最大、激光光斑最小）+ **目标静止** +
零提前量。时序链：车停 → 云台预瞄端点 → 靶进端点区**连续 3 帧确认**（30fps 下
100ms，0.2s 窗口内绰绰有余）→ 开火。周期 7.2s，最多等一个周期必有一次窗口。

### 中段拦截（备选——错过窗口/机构延迟大时）
瞄准点 = 当前位置 + `v_px × t_loop`（t_loop = 检测→云台到位→出光总延迟，需实测）。
匀速段 v 常数，预测误差 <1cm。

### 近大远小韧性模型（核心关系）

```
像素速度 v_px = v_world × f/D        （f/D 随车位变化 ← 近大远小）
靶面像素宽 w_px = W_plate × f/D      （同一个 f/D）
─────────────────────────────────────
不变比值:  v_px / w_px = v_world / W_plate = 常数（与车位无关）
```

- 任意车位预期每秒像素位移 = **RATIO × 当前靶面像素宽**（RATIO=0.138/W_plate）。
- 车端 pose 模型关键点横向跨度即 w_px，逐帧自适应，无需按车位重新标定。
- 例：靶面宽 0.20m → RATIO≈0.69；靶面 300px 宽 → 207 px/s，150px 宽 → 103 px/s。
- 斜视时速度与靶宽同比例缩小，比值一阶不变。

## 三、射击位标定工具 `tools/target_speed_calib.py`

一键实测当前车位下标靶 px/s + 不变比值 + 世界速度校验（对比 0.138 基准，
偏差 >12% 报警）+ 周期/停顿，并打印火控参数。

```bash
# 现场（射击位，车端摄像头 0，卷尺量靶面宽，例 0.20m）
python tools/target_speed_calib.py --source 0 --plate-width 0.20 \
       --duration 30 --no-display --out result.json
# 部署前自检（无需硬件）
python tools/target_speed_calib.py --self-test
```

**六层防护**（每层对应一类现场失效，均有对抗场景自证）：

| 失效条件 | 防护机制 |
|---|---|
| 红桶/蓝色干扰物/海报 | 候选竞标：只有"沿直线持续移动"的色块成为目标 |
| 手持抖动 | Theil-Sen 中值斜率 + 速度门控停顿检测 |
| 光照变化/曝光泵动 | HSV 色域自学习 + 5s 周期内内容素刷新 |
| 遮挡/短暂丢靶 | 惯性保持 ≤1s → 沿轨道线受限重捕 → 全局重捕 |
| 单帧野值 | 门控关联 + 3 帧宽限 + 离群剔除 |
| WiFi 低帧率/断流 | 时间基自适应滑窗 + 打开重试 + Ctrl-C 仍出汇总 |

**验证**：自测 6/6 通过（清洁/干扰+抖动/15% 丢靶/光漂移/10fps/野值）；
真实手机视频回归 v_px=120（真值 119）、周期 7.20s（真值 7.2）、命中率 89%。
回归记录：`标靶标定_回归验证.json`（Trae-CN/default 目录）。

## 四、机载语义证据格地图（方案与实现）

### 这是什么
把无人机从"单帧检测器"升级为"场地地图维护者"：占据栅格建图 + 证据理论
（正/负证据）+ 语义类别层。自动驾驶叫 BEV 在线建图，Nav2 costmap 的
observation/clearing 模型是近亲。现链路（0x4001 单帧下发 → 车端 field_matrix
投票 confirm=2）升级为机载证据积累，最大增量：**负证据清 FP**（D13 mine P 86.8%
的已知短板）+ 覆盖率闭环（分区扫描进度）。

### 核心：锚定配准（绝对定位难题的标准解）
- **关键洞察**：SLAM 小场短会话内**相对几何精确**（cm 级），绝对位姿可漂移；
  用少量已知场地位的锚点解一个 2D 刚体变换 T(x,y,θ)，**一个变换作用于全体
  语义物体**——不需要逐物体定位。
- **锚 vs 载荷**：锚 = 每局固定的已知物（格号标签、挡板 D7~N7、围墙、桥洞结构）；
  载荷 = 每局随机的被定位物（雷/障碍/靶）。
- **双配准源互验**：格号锚（视觉，误读率 ~11% → 必须 RANSAC）+ 结构锚
  （LiDAR 几何直出，可靠但稀疏，权重 2.0）——互相校验，谁残差大谁可疑。
- 数学：加权 Kabsch 2D 闭式解；2 锚定解、3 锚起冗余；**共线锚（θ 病态）显式
  拒绝**；RANSAC 须第三点互证（2 点最小集对自身恒零残差的固有弱点）。

### 负证据纪律（禁火铁律的守门员）
- 画质不足（quality<0.5）的覆盖只计覆盖率，不产生负证据；
- 雷语义（PAPER）负证据**减半**（mine R≈98%，"没看到"≠"没有"）：5 次清不掉
  已确认雷，但能清掉单帧 0.6 的 FP；
- **禁火类（红靶/红桶）单次强观测（conf≥0.73）即粘性确认**，此后任何负证据与
  无限衰减永不击穿（宁可信其有——误击红靶 −5/次）；
- 靶类走**轨道级语义**（set_track D8-E8 双格，相位变化无妨），不落死格。

### 误差预算（落格 <0.1m 的约束）
| 误差源 | 量级 | 对策 |
|---|---|---|
| 外参俯仰角 1° @3m 高 | ≈5cm | 外参标定核心项，标到 0.5° 内 |
| 时间同步 0.1s @2m/s | ≈0.2m | 位姿缓冲单调钟插值 + max_gap 守门 |
| 检测框底边质量 | cm 级 | 底边中心=地面接触点（比框中心稳） |
| 格号误读 11% | 整格 0.35m | RANSAC + 结构锚互验 |

### 已落地模块（src/ag_integrate/ag_integrate/，纯 Python 零新依赖）

| 模块 | 职责 | 关键测试 |
|---|---|---|
| `anchored_registration.py` | RANSAC+Kabsch 锚定配准 | 11% 误读零污染、σ2cm 噪声 <5cm、共线/矛盾拒绝 |
| `ground_projection.py` | 检测框底边反投影→落格 + 位姿插值 + 视野足迹 | 任意斜视往返 <1e-6m、掠射守卫、端到端落格 F5 |
| `evidential_map.py` | 证据格地图（正/负证据/覆盖率/粘性/轨道） | FP 清除、雷保护、禁火粘性、轨道语义、无闪断 |

配套测试 `tests/test_anchored_registration.py`、`test_ground_projection.py`、
`test_evidential_map.py` 共 **30 项全绿**；全量回归 **345 passed / 0 failed**。

**关键参数**（`EvidenceParams` 默认值）：confirm_logit=2.5（单帧 0.9 不进门、
两帧确认）、sticky_confirm_logit=1.0（禁火类单次强观测粘性）、neg_gain=0.7、
PAPER 负证据权重 0.5、half_life=600s。
