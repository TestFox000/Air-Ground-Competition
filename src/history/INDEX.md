# src/history 项目资料索引

**本目录用途**：存放项目进展与资料，分两类：
- `log/` —— **进展快照（时间线）**：每次"总结项目 / 生成 log"产出的日志，按时间顺序反映项目演进。
- `book/` —— **技术文档（已归档）**：唯一一篇《项目技术文档 2026-10-03》已于 2026-10-23 移入 `docs/history_cache/01_旧文档归档/dzrobot_v2_src/history/book/`；现行提炼见 `docs/20_资料索引库/历史/04_旧核技术手册_20261003.md`。

---

## 1. 阅读顺序（新 agent 接手）

1. 先看本文件 `INDEX.md`，了解资料分布；**只想快速了解演进 → 直接读 [大事记.md](大事记.md)（35 份日志的一页时间线，截至 2026-10-23）**。
2. **先读 `docs/README.md`（唯一入口）→ `docs/20_资料索引库/`**（车端 / 无人机 / 空地链路 / 视觉与云台 / 赛事与治理 / 历史六册）。旧的 `docs/agent_archive*` 已于 10-21 迁入 `docs/history_cache/`，本目录的 `log/` 是它们的原始素材。
3. 看 `docs/20_资料索引库/历史/04_旧核技术手册_20261003.md` 建立旧核系统认知（架构/算法/参数/命令）；book/ 原件已归档至 history_cache。
4. 看 `log/` 下**最新一份**日志了解当前状态、待办、坑清单。
5. 需追溯某决策原因时，翻 `log/` 对应日期的日志。

> **2026-10-14 更新**：本工作区顶层为「两项目 + 两会话归档」，`dzsmartscout/`（无人机）与两份 `*.zip` 的内容已在 v2 档案 §8/§9 归档；**最近两天的增量（空地协同闭环、仿真台插件、第六张图）见 v3 档案**。`log/` 是档案的原始素材，读档案优先。

## 2. 文件命名与存放规范

```
src/history/log/log_YYYY-MM-DD_HHMM.md     # 日志：log_ + 生成日期(精确到分钟)
# （旧）src/history/book/<主题>.md —— 2026-10-23 起不再新增，原件已移入 docs/history_cache/
```

- 日志文件**只新建不覆盖**——历史是不可变的进展记录。
- 统一 `.md`，便于结构化展示。

---

## 3. 新增资料的操作规范

**新增日志（"总结项目 / 生成 log"时）**：
1. 在 `log/` 下新建 `log_YYYY-MM-DD_HHMM.md`（HHMM 取生成时刻，精确到分钟）。
2. 内容含固定六项：项目概述 / 主要模块 / 当前完成情况(带证据) / 最近运行状态 / 待办(P0~P2) / 关键说明（坑清单）。
3. 补一节"相对上一份的变化"（只写增量）。
4. 在本 `INDEX.md` 的「日志清单」表追加一行。

**技术文档（"写技术文档"时）**：
- **定位**：**唯一权威文档**，**全面概括整个项目**（物理/组成/代码结构/命令/更新/问题）。
- **更新方式（2026-10-23 起）**：长期文档一律进 `docs/20_资料索引库/`（AGENTS §8.1）；`book/` 已停止使用，只读留档。
- 仅在首次建立或文档定位变化时才改动下方「技术文档清单」对应行。
